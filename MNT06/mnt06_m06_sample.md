# [MNT06_M06] 시간/비용 대시보드 및 XAI 설명 실습 가이드

## 1. 미션 개요
부품별 제작 소요 시간, 비용, 신뢰성 점수, 폐기 손실을 한눈에 비교하는 대시보드를 구축하고, 모델 예측 근거를 자연어로 설명하는 XAI(설명가능 AI) 설명 모듈을 구현합니다.

## 2. 주요 데이터셋 안내 (`mnt06_m06_dataset.json`)
- `sample_shap_waterfall`: P282 부품의 점수 형성 요인 분해 및 상위 3대 감점 인자
- `evaluated_parts_count`: 300종 전체 부품 대상 상위 3개 인자 산출 성공률 100%

## 3. 핵심 수행 단계
1. **대시보드 6대 뷰 구현**: 비용-시간, 조달 절감액, 점수 분포, 파레토, 추천 5종, 워터폴
2. **국소 기여도(XAI) 분해**: SHAP 근사 방식을 통한 부품별 점수 하락 요인 자동 추출
3. **자연어 조치문 생성**: 정비기술관이 현장에서 즉각 실행 가능한 공학 조치 매핑
4. **심화 튜닝**: 고위험 부품 경보 배너 및 폰트/레이아웃 인터페이스 최적화

## 4. 핵심 판정 기준
- 300종 부품 상위 3개 인자 산출 성공률 100%
- 자연어 설명문을 통한 구체적 조치안 4건 도출
- 산출물: `src/explainability/mnt06_xai_explainer.py` 및 XAI 리포트
