# [MNT06_M05] 군사 규격 신뢰도 점수 산출 앙상블 엔진 실습 가이드

## 1. 미션 개요
안전율, 피로 수명, 형상 위험도, 소재 인증 여부를 종합 평가하여 야전 제작 부품의 군사 규격 부합성을 0~100점 척도로 환산하는 앙상블 신뢰도 점수 산출 엔진을 구축합니다.

## 2. 주요 데이터셋 안내 (`mnt06_m05_dataset.json`)
- `model_comparison`: LightGBM + RF 앙상블의 R² 0.956 및 MAE 75.2% 개선 지표
- `score_bins_calibration`: 4개 점수 구간별 실제 부합률의 단조 증가(0.00 -> 0.98) 검증표
- `pending_filter_rules`: 모델 간 편차 15점 이상 및 인증서 누락 부품 격리 규칙

## 3. 핵심 수행 단계
1. **앙상블 회귀 구현**: LightGBM과 Random Forest 가중 결합 모델 학습
2. **구간 단조성 검증**: 점수 등급 상승에 따른 실제 부합률의 일관된 증가 입증
3. **불확실성 방어 로직**: 예측 불일치 및 인증서 결측 부품의 '판정 보류' 격리
4. **심화 튜닝**: 앙상블 가중치 그리드 탐색을 통한 최적화

## 4. 핵심 판정 기준
- Hold-out 평가 R² 0.85 이상(달성치 0.956)
- 점수 구간별 부합률 단조 증가성 확인 및 인증 결측 부품 통제
- 산출물: `src/models/mnt06_advanced_model.py`
