# [K08_M08] 생성형 AI용 질문 묶음 만들기 실습 가이드 및 작성 서식

## 1. 실습 개요 및 목표
- **과제명**: K08 군 규정 검색 AI - 생성형 AI용 질문 묶음 만들기
- **핵심 목표**: 검색된 상위 3개 조항 원문과 환각 차단 4대 답변 규칙을 조립하여 LLM에 전달할 RAG 프롬프트를 자동 생성하고 무결성을 검증합니다.

## 2. 생성된 RAG 프롬프트 샘플
```text
[역할 정의] 당신은 한빛대대 규정 안내 도우미입니다.
[질문] 생활관에서 전기난로를 써도 되나요?

[규정 발췌]
1. 제5조(전열기 사용): 생활관 내 개인 전열기 사용을 금지한다. 공용 난방기 이상은 즉시 중대 행정반에 신고한다.
2. 제6조(개인정비 시간): 평일 18시부터 21시까지를 개인정비 시간으로 한다...
3. 제4조(생활관 청결): 생활관 청소는 매일 아침 점호 후 20분간 실시한다...

[답변 준수 4대 규칙]
1. 발췌된 규정 내용에만 근거하여 답변할 것
2. 반드시 근거 조항(제O조)을 명시할 것
3. 규정에서 답을 찾을 수 없으면 지어내지 말고 '규정에서 찾을 수 없음'을 밝힐 것
4. 날짜, 시간, 금액 등 숫자를 절대 임의로 날조하지 말 것
```

## 3. 프롬프트 무결성 4개 항목 자동 검증 결과
- 15개 프롬프트 전건 대상 검사:
  1) 4대 준수 규칙 포함: [ PASS / FAIL ]
  2) 상위 3개 조항 발췌문 포함: [ PASS / FAIL ]
  3) 사용자 질문 삽입: [ PASS / FAIL ]
  4) 발췌 구분 서식 준수: [ PASS / FAIL ]
- 종합 판정: (   )/15 PASS (기준: 15/15 전건 통과)
