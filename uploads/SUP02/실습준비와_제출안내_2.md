# 실습 준비·보안·제출 안내

제공된 교육용 가상자료만 사용합니다. 비공개 업무자료, 실습에는 제공된 가상자료만 사용하고, 실제 이름·연락처 같은 개인정보는 AI 도구나 노트북에 넣지 않습니다. 실습을 위한 조직 내 촬영은 하지 않습니다. 조직 보안 지침과 서비스 이용 허용 여부를 먼저 확인합니다.

이 자료는 교육용 가상 실습입니다. 실제 업무·정비·재보급 승인 기준이나 자동 결정에 사용하지 않습니다.

AI에게 문서 초안을 요청할 수 있습니다. 사실·숫자 확인과 최종 수정은 본인이 합니다. 실제 실행·계산·자료 대조·최종 판단은 직접 하고 요청문·실제 응답·채택 이유를 기록합니다. 불일치·기각·성능 향상을 억지로 만들지 않습니다.

종료 전 허용된 저장 위치에 저장하고 다시 열어 확인한 뒤 사용한 교육장 계정에서 로그아웃합니다. 공용 PC에 비밀번호를 저장하지 않으며 로컬 사본은 조직 규정에 따라 정리합니다.

AI 접속과 사람 협업이 모두 불가능하면 개인 판단·계산·초안을 먼저 저장하고 협업 항목은 미수행으로 표시합니다. 교육 담당자에게 동료 검토 또는 허용 접속 시간의 보완 일정과 필요시 기한 조정을 요청합니다. 보완 전에는 협업 완료로 표시하지 않습니다.

제출처·마감 일시·시간대는 miliai.kr 해당 과제 공지를 확인하고, 표시가 없으면 제출 전에 교육 담당자에게 확인합니다. 플랫폼 학습기간은 계획값이며 마감일을 뜻하지 않습니다. 별도 공지가 없으면 미션마다 그 미션 산출물을 ZIP 하나로 묶어 해당 미션 제출란에 첨부합니다. 통합 문서는 미션별 제목·위치를 적고 각 해당 제출란에 같은 파일을 첨부합니다. 파일명은 과제ID_미션번호_산출물명으로 작성하고 실제 형식의 확장자를 붙입니다. 실명·개인 식별번호는 파일명에 넣지 않습니다.

Python 3.12와 requirements.txt 기준으로 준비된 환경을 사용합니다. 제한 환경에서는 관리자가 준비한 로컬 Jupyter를 사용하며 설치 명령을 실행하지 않습니다. 환경 셀은 버전을 확인하고 실습 파일을 준비합니다. 버전이 맞지 않으면 안내 메시지와 함께 멈추며, 그때는 requirements.txt 기준으로 교육 담당자가 안내한 방법으로 설치한 뒤 다시 실행합니다. 환경 셀은 건너뛰지 마세요.

노트북 사본과 reports·직접 작성한 docs·work·outputs를 원래 폴더 구조대로 저장합니다. docs/원문_제출경로_연결표.md의 현재 실행 파일을 제출합니다.

최종 실행 재현 확인은 필수 미션만 선택하여 실행합니다: `python -m pytest tests/test_missions.py -k "not [4] and not [6] and not [8]"`. 전체 미션 검사는 선택 미션까지 실행한 경우의 추가 확인이며 최종 PASS 조건이 아닙니다.

미리보기의 source_sha256 및 검증 메타데이터는 제공 파일의 생성 근거를 확인하는 해시이며 학습 데이터 필드나 제출할 정답이 아닙니다. 실행 기록의 해시는 코드 변경 여부를 확인하므로 그대로 보존하세요.
