# 미션6 — 검수 결과를 빠짐없이 전달하기

## 이번에 할 일
다른 담당자가 이어서 처리할 수 있도록 물자 카드와 수령증을 비교해 부족·훼손·기한 임박을 찾습니다. 가상 등록표를 작성하고, AI 인수자가 전달 내용을 이해했는지 질문으로 확인합니다.

**익힐 AI 활용:** AI를 인수자 역할로 활용해 문서와 설명의 누락을 찾아내는 방법

**준비 자료:** 4종 물자 카드, 교육용 참조번호·가상 등록 서식, 인수자 퀴즈

**완성할 것:** 검수표·품목별 8필드 등록표·SBAR·실제 인계 대화·퀴즈 기록

**용어 도움:** SBAR=상황(S)·배경(B)·평가(A)·요청(R) 순서로 전달하는 틀. 가상 등록표 입력은 실제 시스템 등록이 아닙니다.

**시작하기 전에:** 등록표를 작성하기 전에 수령증에 적힌 수량과 표지 카드에서 확인한 수량을 나란히 적으세요. 차이는 확인 수량에서 수령증 수량을 뺀 값입니다. 수량이 맞더라도 상태 이상은 따로 남깁니다. 이후 8개 열을 품목별로 채우고, AI 인수자에게 이 표와 인계문만 전달해 빠진 설명이 있는지 확인합니다. SBAR는 상황·배경·평가·요청을 차례로 설명하는 짧은 인계문입니다.


## 처음 시작하는 순서와 용어

미션 안내와 제공 자료를 읽은 뒤 학생용 Workbook의 미션6 작성란을 여세요. 이 미션의 빈 양식은 forms/LOG07_M06_forms.md이며, Workbook에 같은 항목이 준비되어 있습니다. 따로 같은 내용을 두 번 작성할 필요는 없습니다.

검수는 받은 물자의 기록상 수량·상태·기한을 비교하는 일입니다. 필드는 표의 한 칸을 뜻합니다. 품목마다 8개 항목을 쓰므로 네 품목을 합치면 32필드입니다. SBAR는 상황·배경·평가·요청 순서로 설명하는 틀입니다. 이 실습의 등록표는 가상 문서이며 실제 군 시스템에 입력하지 않습니다.

- 활동1: 「검수」에 판단과 근거를 기록합니다.
- 활동2: 「등록표 8필드×4」에 판단과 근거를 기록합니다.
- 활동3: 「SBAR」에 판단과 근거를 기록합니다.
- 활동4: 「인계 후 퀴즈」에 판단과 근거를 기록합니다.

AI 답변을 받으면 먼저 기록 번호와 원문 값을 찾고, 답변의 어느 부분을 채택하거나 고쳤는지 남기세요. 원문에 없으면 확인 불가로 표시하고 필요한 자료를 적습니다. 문서는 작성 내용 저장, 대화는 원문 저장으로 각각 보관합니다. HTML에서는 작성 JSON을 내려받습니다.

## 작성할 때 알아두세요
제공 자료를 읽고 내 생각을 먼저 짧게 적은 뒤 AI에 초안을 요청하세요. 표 전체의 초안을 한 번에 요청해도 됩니다. 같은 내용을 칸마다 AI에 다시 묻지 않아도 됩니다. 답변을 원자료와 비교해 고친 후 각 입력칸에 옮깁니다.

실제 대화는 아래 대화 기록란에 목적·실제로 보낸 요청 전체·실제로 받은 답변 전체를 한 묶음으로 저장합니다. 보완 대화는 새 묶음으로 추가하므로 파일명이 달라지는 것이 정상입니다. ‘실제 AI 사용·최종 결정’에는 원문 파일 위치와 본인의 채택·수정·보류 이유를 적습니다.

작성 내용 저장은 현재 미션 문서를 저장합니다. 대화 저장은 대화 원문을 별도로 저장합니다. 마지막 ‘진행 확인·내려받기’의 show_submission() 셀을 실행하면 ‘확인하고 ZIP 만들기’ 버튼이 나타납니다. 작성 중이면 ‘미완료 상태로 검토용 ZIP 저장’을 선택해 보관합니다.

한 번 작성한 내용은 저장해 두고 이어서 사용하세요. 이 미션에서 요구한 수행 내용과 판단 근거를 남기되, 아직 하지 않은 활동은 이유와 다음 할 일을 적습니다. 저장 성공과 과제 통과는 별개입니다.

**AI 요청 예시 — 대괄호에는 내 자료를 넣으세요:**

**확인할 점:** 총 수량과 상태 이상 수량을 구분하고 차이 계산의 방향·단위를 원자료와 대조합니다. 실제 물자를 취급하지 않습니다.
