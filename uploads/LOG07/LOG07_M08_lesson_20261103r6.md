# 미션8 — 기록을 비교해 개선안 만들기

## 이번에 할 일
같은 일을 다르게 기억할 수 있습니다. 제공 기록 6건과 진술을 비교하고, AI가 제안한 원인이 사실인지 가설인지 확인해 절차 개선안을 만듭니다.

**익힐 AI 활용:** AI와 자료를 분석하고 근거 있는 개선 문서를 만드는 방법

**준비 자료:** L-01~L-06 가상 요약, 자신의 실제 실행 기록은 별도로 추가 가능

**완성할 것:** 사후 검토 회의록·사례 분석·개선 5건 이상·수정 절차

**용어 도움:** AAR=계획·실제·차이·원인·개선을 살펴보는 사후 검토. 가상 요약은 본인의 실측 결과가 아닙니다.


## 처음 시작하는 순서와 용어

미션 안내와 제공 자료를 읽은 뒤 학생용 Workbook의 미션8 작성란을 여세요. 이 미션의 빈 양식은 forms/LOG07_M08_forms.md이며, Workbook에 같은 항목이 준비되어 있습니다. 따로 같은 내용을 두 번 작성할 필요는 없습니다.

사후 검토(AAR)는 계획과 실제 기록을 비교해 다음에 바꿀 점을 찾는 활동입니다. 진술은 누군가의 설명이고, 가설은 아직 확인하지 못한 원인 추정입니다. L-01~L-06의 요약값과 본인의 실제 실행값을 구분하세요. 근거 연결은 번호만 적는 대신 어떤 기록의 어떤 내용이 판단을 뒷받침하는지 쓰는 것입니다.

- 활동1: 「사실·진술·원인」에 판단과 근거를 기록합니다.
- 활동2: 「실제/AI모의 토의 기록 위치」에 판단과 근거를 기록합니다.
- 활동3: 「개선5건 이상」에 판단과 근거를 기록합니다.
- 활동4: 「회의록·실제 AI 사용·최종 결정」에 판단과 근거를 기록합니다.

AI 답변을 받으면 먼저 기록 번호와 원문 값을 찾고, 답변의 어느 부분을 채택하거나 고쳤는지 남기세요. 원문에 없으면 확인 불가로 표시하고 필요한 자료를 적습니다. 문서는 작성 내용 저장, 대화는 원문 저장으로 각각 보관합니다. HTML에서는 작성 JSON을 내려받습니다.

## 작성할 때 알아두세요
제공 자료를 읽고 내 생각을 먼저 짧게 적은 뒤 AI에 초안을 요청하세요. 표 전체의 초안을 한 번에 요청해도 됩니다. 같은 내용을 칸마다 AI에 다시 묻지 않아도 됩니다. 답변을 원자료와 비교해 고친 후 각 입력칸에 옮깁니다.

실제 대화는 아래 대화 기록란에 목적·실제로 보낸 요청 전체·실제로 받은 답변 전체를 한 묶음으로 저장합니다. 보완 대화는 새 묶음으로 추가하므로 파일명이 달라지는 것이 정상입니다. ‘실제 AI 사용·최종 결정’에는 원문 파일 위치와 본인의 채택·수정·보류 이유를 적습니다.

작성 내용 저장은 현재 미션 문서를 저장합니다. 대화 저장은 대화 원문을 별도로 저장합니다. 마지막 ‘진행 확인·내려받기’의 show_submission() 셀을 실행하면 ‘확인하고 ZIP 만들기’ 버튼이 나타납니다. 작성 중이면 ‘미완료 상태로 검토용 ZIP 저장’을 선택해 보관합니다.

한 번 작성한 내용은 저장해 두고 이어서 사용하세요. 이 미션에서 요구한 수행 내용과 판단 근거를 남기되, 아직 하지 않은 활동은 이유와 다음 할 일을 적습니다. 저장 성공과 과제 통과는 별개입니다.
