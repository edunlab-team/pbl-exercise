# 미션10 — 다른 사람도 사용할 수 있는 안내서 완성하기

## 이번에 할 일
앞서 만든 자료를 5개 장(개요·절차·시나리오·평가·AAR)으로 구성합니다. 페이지 수는 제한하지 않습니다. 다른 사람이 준비물과 진행 방법을 찾을 수 있도록 정리하고, AI 검토 의견을 반영해 배포할 파일을 완성합니다.

**익힐 AI 활용:** AI로 문서를 통합하고 검토·수정·배포까지 마무리하는 방법

**준비 자료:** 자신의 미션1~9 결과·자료·버전·실제 수행 상태

**완성할 것:** 5장 지침서·운영 안내 6항목·검토 반영표·연간 계획·배포본

**용어 도움:** 루브릭=결과를 무엇으로 평가할지 정한 기준. 배포본=실제로 읽고 사용할 수 있도록 묶은 파일입니다.


## 처음 시작하는 순서와 용어

미션 안내와 제공 자료를 읽은 뒤 학생용 Workbook의 미션10 작성란을 여세요. 이 미션의 빈 양식은 forms/LOG07_M10_forms.md이며, Workbook에 같은 항목이 준비되어 있습니다. 따로 같은 내용을 두 번 작성할 필요는 없습니다.

여기서 5장은 다섯 페이지가 아니라 내용의 다섯 구분입니다. 평가 루브릭은 어떤 결과와 근거를 보고 채점할지 정한 표이며, AAR는 사후 검토입니다. 배포본은 다른 사람이 실제로 열어 사용할 파일 묶음입니다. 선택 미션을 하지 않았다면 그 결과를 꾸미지 말고 빈 양식·제공 자료·운영 방법과 미실시 사유를 구분해 넣으세요.

- 활동1: 「1장 개요~5장 AAR에 넣을 자료 목록」에 판단과 근거를 기록합니다.
- 활동2: 「1장 개요~5장 AAR·운영 안내6항목」에 판단과 근거를 기록합니다.
- 활동3: 「실제 모의 검토·반영」에 판단과 근거를 기록합니다.
- 활동4: 「계획·배포」에 판단과 근거를 기록합니다.

AI 답변을 받으면 먼저 기록 번호와 원문 값을 찾고, 답변의 어느 부분을 채택하거나 고쳤는지 남기세요. 원문에 없으면 확인 불가로 표시하고 필요한 자료를 적습니다. 문서는 작성 내용 저장, 대화는 원문 저장으로 각각 보관합니다. HTML에서는 작성 JSON을 내려받습니다.

## 작성할 때 알아두세요
제공 자료를 읽고 내 생각을 먼저 짧게 적은 뒤 AI에 초안을 요청하세요. 표 전체의 초안을 한 번에 요청해도 됩니다. 같은 내용을 칸마다 AI에 다시 묻지 않아도 됩니다. 답변을 원자료와 비교해 고친 후 각 입력칸에 옮깁니다.

실제 대화는 아래 대화 기록란에 목적·실제로 보낸 요청 전체·실제로 받은 답변 전체를 한 묶음으로 저장합니다. 보완 대화는 새 묶음으로 추가하므로 파일명이 달라지는 것이 정상입니다. ‘실제 AI 사용·최종 결정’에는 원문 파일 위치와 본인의 채택·수정·보류 이유를 적습니다.

작성 내용 저장은 현재 미션 문서를 저장합니다. 대화 저장은 대화 원문을 별도로 저장합니다. 마지막 ‘진행 확인·내려받기’의 show_submission() 셀을 실행하면 ‘확인하고 ZIP 만들기’ 버튼이 나타납니다. 작성 중이면 ‘미완료 상태로 검토용 ZIP 저장’을 선택해 보관합니다.

한 번 작성한 내용은 저장해 두고 이어서 사용하세요. 이 미션에서 요구한 수행 내용과 판단 근거를 남기되, 아직 하지 않은 활동은 이유와 다음 할 일을 적습니다. 저장 성공과 과제 통과는 별개입니다.
