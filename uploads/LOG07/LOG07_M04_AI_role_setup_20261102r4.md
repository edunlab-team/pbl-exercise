# LOG07 M04 — AI 상대 역할 시작 안내

이 파일은 개인 문서·카드 모의실습의 시작을 돕는 교육용 운영 설정입니다. 실제 시스템을 실행하거나 물자를 움직이지 않습니다. 역할 회신은 AI가 대화에서 모의하고 학습자는 확인·판단·보고·기록을 수행합니다.

## 1. 시작 전에 준비할 것

- M04 Forms 복사본과 [공통 증빙 작성 양식](/uploads/LOG07/LOG07_공통_증빙작성양식_20261102r2.md) 요청별 복사본.
- 사용할 미션2 절차와 미션3 인계 조건. 미션3의 전체 기대 행동·교관 해설은 입력하지 않습니다.
- 제공 자료 4-1의 요청 3건, 자료 4-2의 역할, 자료 4-3의 교육용 상태 카드.
- 제공 자료 4-7의 실행 식별값·로트·봉인·카드·가상 계획 시각. 모두 교육용 설정입니다.
- 학습자가 직접 볼 실제 타이머. AI는 실제 시각·경과 시간을 관측했다고 주장하지 않습니다.

기존 미션1의 완료 증빙은 이번 세 건의 완료 기록이 아닙니다. 새 번호를 쓰고 초기 상태는 모두 ‘요청·승인·불출·수령·등록 인계를 아직 수행하지 않음’으로 둡니다. 시작 전에 필요한 교육용 승인 역할·확인 조건을 합의하고 실제 군 권한으로 주장하지 않습니다.

## 2. 새 AI 대화에 입력할 시작 요청

아래 실행 틀을 복사하고 빈 부분을 채운 뒤, 준비한 **역할·요청·절차·상태 자료**를 함께 붙입니다. 이 시작 틀 자체의 복사 여부를 프롬프트 설계 점수로 평가하지 않습니다. 실행 후 분석 요청은 학습자가 목적·범위·근거 요구를 직접 설계합니다.

> 교육용 가람중대 보급 업무를 대화로 모의하겠습니다. 나는 김가온 하사 역할로 확인·보고·기록을 수행합니다. 나래중대 요청에서는 별도 역할로 구분하겠습니다.
>
> 당신은 승인자 이도윤, 불출자 박새론, 수송자 최다온, 수령자 정하람과 이름 없는 운전병·나래중대 담당·대대 군수과 역할을 필요할 때 모의해주세요. 역할과 부대를 바꾸거나 없는 인물 이름을 만들지 마세요.
>
> 적용 절차·인계 조건: [사용하는 미션2·미션3 자료]
> 요청 카드·상태 카드: [제공 자료 4-1~4-3]
> 이번 실행의 추가 식별값·가상 시간표: [제공 자료 4-7 설정값과 변경 사항]
>
> 내가 지정한 요청·단계·수신 역할에만 답하고 전체 훈련을 한 번에 완료하지 마세요. 처음에는 설정의 부족한 정보를 확인한 뒤 ‘준비됨’이라고 답하고 기다려주세요. 실행 시작은 내가 알립니다.
>
> 각 회신에 역할, 요청 번호, 확인한 근거, 결과·다음에 필요한 정보, 가상 기록을 구분해주세요. 필요한 승인·인계 확인이 없으면 완료 상태로 넘어가지 말고 질문하세요. 내 보고서·판단·체크 결과·실제 시간을 대신 작성하지 마세요.
>
> 요청 3의 초기 승인 상태는 ‘수량 확인 대기’입니다. 불출 전 재고 대조에서 부족 메시지를 제공하고, 학습자 보고를 받은 뒤 부분 불출을 승인하세요. 승인 전 실제 불출은 진행하지 마세요. 요청 3의 부족 상황은 불출 수량 대조 단계에 메시지로 전달하고, 승인 역할은 학습자 보고와 결정 요청을 받은 뒤에만 회신해주세요. 필요한 정보가 누락되면 정정을 요청하고 기다려주세요. 교육용 승인 역할은 확인된 재고 10상자의 부분 불출과 잔여 2상자의 후속 확인을 승인할 수 있습니다. 승인 회신은 실제 보고를 받은 뒤 제공하고 원 요청 12상자를 바꾸지 마세요. 남은 2상자를 공급 완료로 처리하지 마세요. 원 요청과 실제 불출·수령·잔여를 구분해주세요.
>
> 가상 출발·도착·수령 상태는 내가 해당 단계 진행을 요청한 뒤 제공된 카드와 합의한 시간표에 따라 모의하세요. 새로운 상태가 필요하면 교육용 추가 설정인지 먼저 확인하세요. 실제 물자가 도착하거나 실제 전산에 등록됐다고 주장하지 마세요.
>
> 모든 서명·확인은 ‘AI 역할의 교육용 확인’으로 표시하세요. 실제 타이머 기록은 내가 제공합니다. 교관 정답·채점·병목 분석은 실행 중 제공하지 말고 실행을 끝낸 뒤 내가 요청할 때만 진행하세요.

## 3. 학습자가 실제로 할 행동

1. ‘준비됨’과 설정을 확인하고 타이머를 시작합니다.
2. 요청 1부터 청구서를 작성해 수신 역할을 지정하여 전달합니다. 요청 2·3도 같은 10단계 기준으로 수행합니다.
3. AI 회신의 품목·수량·단위·연결 번호·확인 조건을 자료와 대조하고 다음 요청·보류·보고를 직접 결정합니다.
4. 불출·적재·수송·도착·수령은 상태 카드와 기록 대화로 모의합니다. 양쪽 역할 확인 근거를 남깁니다.
5. 이상 메시지를 읽은 실제 타이머 시각과 보고를 보낸 실제 시각을 직접 기록합니다. AI 답변을 기다려야 보고가 완료되는 것은 아닙니다.
6. 수령 자료를 군수과 역할에 전달해 인수·대기 상태를 확인합니다. 등록 완료는 따로 실행·확인하지 않았다면 표시하지 않습니다.
7. 요청별 증빙·30단계·보고 기록을 보존한 뒤 분석용 대화에서 근거를 제공해 AI 검토를 요청합니다.

요청 3의 부족 상황은 자료에 공개되어 있으므로 이것을 처음 보는 돌발 상황에 대한 맹검 평가라고 주장하지 않습니다. 알려진 상황에서도 실제 보고·승인 확인·잔여 추적을 수행하는 연습입니다.

## 4. AI가 자동 완료하거나 근거 없이 회신할 때

전체 완료를 답해도 그대로 받아 적지 않습니다. 마지막으로 확인된 상태까지 돌아가 필요한 근거를 요구하고 수정 요청과 이유를 남깁니다. 실제 최초 기록은 지우지 않습니다. 역할 응답의 오류를 해결할 수 없으면 ‘추가 확인·실행 중단’을 기록하고 재실행을 별도로 구분합니다.

AI는 확정된 프로그램이 아니므로 역할 조건을 잘못 따를 수 있습니다. 그 응답도 검증 대상이며, 교관 승인이나 실제 행위를 증명하는 자료가 아닙니다.
