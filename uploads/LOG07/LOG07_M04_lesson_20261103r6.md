# 미션4 — AI 상대 역할과 보급 요청 3건 처리하기

## 이번에 할 일
가상 요청 3건을 실제 대화로 처리해 봅니다. 학습자가 확인·보고를 하고 AI는 다른 담당자의 역할을 맡습니다. 작성한 절차가 실제로 도움이 되는지 살펴봅니다.

**익힐 AI 활용:** AI의 역할과 응답 범위를 정하고 실제 사용 결과를 확인하는 방법

**준비 자료:** 미션2·3 결과, DR-01~03 요청·상태 카드, 역할 시작 안내

**완성할 것:** 3건 처리 기록·30단계 확인표·보고 시간·개선점 2곳 이상

**용어 도움:** Dry-run=절차를 시험해 보는 모의 실행. 가상 D일 시각과 실제 타이머 시간은 서로 다릅니다.

**시작하기 전에:** 이번에는 앞에서 만든 절차를 실제 대화에 사용해 봅니다. DR-01부터 청구서 한 건을 작성하고 해당 역할에 확인을 요청하세요. 회신을 받은 뒤 다음 단계로 넘어가며, 문서번호가 미리 있다는 이유로 승인이 끝났다고 쓰지 않습니다. DR-03에서 수량 차이를 알게 된 순간과 보고를 보낸 순간을 직접 기록합니다. AI에게는 현재 단계의 확인만 요청하세요. 이 기록은 미션9의 비교 출발점이므로 원본을 따로 보관합니다.


## 처음 시작하는 순서와 용어

미션 안내와 제공 자료를 읽은 뒤 학생용 Workbook의 미션4 작성란을 여세요. 이 미션의 빈 양식은 forms/LOG07_M04_forms.md이며, Workbook에 같은 항목이 준비되어 있습니다. 따로 같은 내용을 두 번 작성할 필요는 없습니다.

DR-01~DR-03은 이번에 처리할 세 요청의 이름입니다. 한 요청을 10단계로 확인하므로 세 요청을 합치면 30단계입니다. 증빙은 처리 내용을 확인할 기록이며, 병목은 기다림이나 반복 작업으로 진행이 늦어지는 곳입니다. 가상 D일 시각은 사례 속 시각이고, 타이머는 지금 수행에 걸린 실제 시간을 잽니다.

- 활동1: 「실행 조건」에 판단과 근거를 기록합니다.
- 활동2: 「30단계 실제 수행」에 판단과 근거를 기록합니다.
- 활동3: 「부족 보고」에 판단과 근거를 기록합니다.
- 활동4: 「미션9용 최초 지표·실제 AI 사용·최종 결정」에 판단과 근거를 기록합니다.

AI 답변을 받으면 먼저 기록 번호와 원문 값을 찾고, 답변의 어느 부분을 채택하거나 고쳤는지 남기세요. 원문에 없으면 확인 불가로 표시하고 필요한 자료를 적습니다. 문서는 작성 내용 저장, 대화는 원문 저장으로 각각 보관합니다. HTML에서는 작성 JSON을 내려받습니다.

## 작성할 때 알아두세요
제공 자료를 읽고 내 생각을 먼저 짧게 적은 뒤 AI에 초안을 요청하세요. 표 전체의 초안을 한 번에 요청해도 됩니다. 같은 내용을 칸마다 AI에 다시 묻지 않아도 됩니다. 답변을 원자료와 비교해 고친 후 각 입력칸에 옮깁니다.

실제 대화는 아래 대화 기록란에 목적·실제로 보낸 요청 전체·실제로 받은 답변 전체를 한 묶음으로 저장합니다. 보완 대화는 새 묶음으로 추가하므로 파일명이 달라지는 것이 정상입니다. ‘실제 AI 사용·최종 결정’에는 원문 파일 위치와 본인의 채택·수정·보류 이유를 적습니다.

작성 내용 저장은 현재 미션 문서를 저장합니다. 대화 저장은 대화 원문을 별도로 저장합니다. 마지막 ‘진행 확인·내려받기’의 show_submission() 셀을 실행하면 ‘확인하고 ZIP 만들기’ 버튼이 나타납니다. 작성 중이면 ‘미완료 상태로 검토용 ZIP 저장’을 선택해 보관합니다.

한 번 작성한 내용은 저장해 두고 이어서 사용하세요. 이 미션에서 요구한 수행 내용과 판단 근거를 남기되, 아직 하지 않은 활동은 이유와 다음 할 일을 적습니다. 저장 성공과 과제 통과는 별개입니다.
