## 3. 제공 자료 및 측정 규칙

### 자료 9-1 — 1차 훈련 기준값 예시 

| 지표 | 측정 방법 | 1차 기준값(예시) |
| --- | --- | --- |
| 평균 조치 시간 | 요청 접수 ~ 전산 등록 인계, 요청 3건 평균 | 42분 |
| 증빙 오류 발생률 | 오류가 있는 증빙 수 / 전체 증빙 수(요청 3건 x 5종 = 15장) | 5 / 15 = 33.3% |
| 비상 전환 평균 시간 | 미션7 주입 7건 평균 | 58초 |

제공된 예시값은 계산 연습용이다. 실제 미션4·미션7 값이 있으면 그 값을 쓴다. 실제값이 없으면 먼저 기준 실행·증빙 재검토를 진행한다. 예시를 사용한 결과는 ‘가상 기준에 대한 계산 연습’으로 표시하며 실제 개선 검증 완료로 판정하지 않는다.

AI 모의 방식은 가능하면 같은 도구·역할 설정·자료 제공 범위를 유지한다. 응답 대기·숙련·학습 효과는 완전히 같게 통제하기 어려우므로 차이를 기록한다. 한 번의 전후 비교만으로 개선이 SOP 변경 하나 때문이라고 확정하지 않는다.

### 자료 9-3 — 처리 시간·SOP 준수율

**처리 시간**

이번 실행의 실제 접수는 해당 요청 카드의 처리를 개시하며 접수 기록을 남긴 시점입니다. 준비 단계에서 사례를 읽은 시점과 구분하고 미션4·미션9에 같은 정의를 적용합니다.

- 요청별 실제 접수→등록 인계 완료의 경과 시간을 측정한다. 등록 인계 완료는 필요한 증빙·미완료/잔여 상태·담당 정보가 군수과 역할에 전달되고 인수 확인이 기록된 시점이다.
- 이번 실습의 끝점은 **군수과 역할의 등록 인계 인수 확인**입니다. 실제 군수정보체계에 접속하지 않습니다. 1차·재훈련 모두 같은 끝점을 적용하세요.
- 세 요청의 시간 합계÷3이 평균 조치 시간이다. 전체 실습 시작→종료 시간과 다르다.
- 동시 처리면 요청별 시작/종료를 각각 기록한다. 미완료 요청을 빼고 평균을 내지 않는다. 미완료가 있으면 그 사실과 완료까지의 추가 기록을 남기고 완전한 비교가 가능한지 판정한다.
- 타이머·실제 로그로 측정한다. AI 생성 시각·가상 D일 시각은 실측이 아니다. AI 도움·승인 회신 대기 등 기준 실행에 포함했던 시간은 같은 방식으로 포함한다.

**SOP 준수율**

미션4의 제시된 10단계×3요청, 총30단계를 그대로 평가한다. O합계÷30×100, 전후 차이는 재훈련%−1차%의 **퍼센트포인트(%p)**다. 단계 수를 줄여 시간·준수율을 좋게 보이게 하지 않는다. 정량 목표 ‘향상’은 실제 결과와 유지/감소를 구분해 표시한다.

### 자료 9-4 — 증빙 오류율 

이번 비교에서는 **청구 기록·승인 기록·불출/적재 기록·수송 인계 기록·수령 기록**을 5개 논리 증빙 단위로 정한다.  등록 인계의 누락은 별도 완료/품질 항목으로 확인한다.

- 각각 필수값·수량·단위·연결·시각·확인/서명과 미션2·미션3 기준을 대조한다.
- 하나의 논리 증빙에 여러 오류가 있어도 ‘오류가 있는 증빙 수’에서는 1개로 센다. 오류 항목 수는 별도로 기록한다.
- 있어야 할 증빙이 없으면 그 단위를 오류로 센다. 작성된 문서만 분모에 넣지 않는다.
- 양식을 통합해 물리 파일 수가 줄어도 같은 15개 논리 증빙 단위로 평가한다. 하나의 파일에 여러 단위가 있으면 각각 대조한다.
- 사진 기록·상태 카드가 수령 근거로 필요하면 수령 단위 안에서 확인한다. 기준·재훈련에 같은 범위를 적용한다.
- 부분 불출 승인·실제 10상자 수령·잔여2 추적이 정확하면 원 요청12와 실제10의 차이 자체는 오류가 아니다. 미승인 변경·잔여 삭제·거짓 수령 완료 등은 오류다.
- 미션4 기록에 이 지표가 없었다면 **보존한 원본 증빙을 같은 15개 기준으로 재검토**한다. 당시의 문서를 고쳐 오류를 없애지 않는다. 원본 증빙이 없으면 오류율 기준은 확보 불가다.

### 자료 9-5 — 계산·0 기준값·판정

- 시간 단축률 = (1차 평균−재훈련 평균)÷1차 평균×100.
- 오류율 감소율 = (1차 오류율−재훈련 오류율)÷1차 오류율×100. 퍼센트포인트 차이와 다르다.
- 원자료 수치로 계산하고 표시만 반올림한다. 33.3% 같은 표시값으로 계산해 경계 판정을 바꾸지 않는다.
- 1차 평균 시간이0 또는 누락이면 시간 단축률을 계산하지 않고 원 기록을 확인한다. 0분을 임의의 작은 수로 바꾸지 않는다.
- **1차 오류율0%:** 재훈련도0%면 ‘오류0건 유지·상대 감소율 산출 불가’, 새 오류가 있으면 ‘악화·상대 감소율 산출 불가’다. 50% 감소했다고 표시하지 않는다.
- 필수 목표가 ‘50% 감소’이므로 0% 기준에서 ‘0건 유지’를 대체 통과 조건으로 자동 적용하지 않는다. 검증 수행은 기록하되 목표 판정은 ‘산출 불가·교관 기준 확인 필요’로 둔다.
- 실제로 목표에 미달하면 ‘검증 수행 완료/목표 미달’로 보고한다. 정량 목표 PASS 조건을 달성한 것으로 바꾸지 않는다. 추가 수정·재실행은 이전 기록과 구분한다.

### 자료 9-6 — 미션7 전환 지표의 비교 범위

제공된 비교표의 비상 전환 평균은 미션7의 7주입 별도 지표다. 비교하려면 같은 7개 사건·관측 정의로 재실행한다. 평균뿐 아니라 **주입별60초 이내·성공7/7·안전 위반0건**을 유지하는지도 함께 확인한다. 평균58초만으로 모든 주입이60초 이내였다고 판단하지 않는다.

이번 실행이 미션4 재훈련만 포함하면 해당 칸은 ‘미션7 재측정 미실시’로 표시하고 58초 예시를 실측 재훈련 값으로 복사하지 않는다. 미션7까지 재실행할 경우 추가 시간과 비교 조건을 명시한다. 미션7 재실행까지 포함하면 추가 소요를 별도로 기록하세요.

4. 같은 조건에서 재실행하고 기존 계산·평가 기준으로 비교합니다. 이 준비 경로는 미션9에 포함되므로 별도 추가 소요를 기록합니다. 정량 목표·오류 분모·평가 기준은 바뀌지 않습니다.
