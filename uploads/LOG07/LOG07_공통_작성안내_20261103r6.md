# LOG07 처음 시작하기

가상 보급 기록을 다음 사람이 이해하고 이어받을 수 있도록 정리하는 연습입니다. AI에게 표와 문서 초안을 부탁하고, 직접 원자료와 비교해 고칩니다. 실제 군 규정이나 장비 취급을 배우는 과정은 아닙니다. 부대·인물·물자·권한은 모두 가상 설정입니다.

## 무엇을 만들까요?
기록을 읽고 확인 항목을 만듭니다(미션1~3). 만든 절차를 AI 상대 역할과 사용하고 검토합니다(미션4~8). 같은 조건으로 다시 해 본 결과를 비교한 뒤, 다른 사람이 쓸 안내서로 묶습니다(미션9~10). SOP는 확인·처리 순서를 적은 절차, 증빙은 처리 내용을 확인할 기록, AAR는 끝난 뒤 계획과 실제를 비교하는 사후 검토입니다.

## 파일을 열고 시작하기
1. CMS 프로젝트 개요의 참고자료에서 ‘이번에 사용할 최신 학생용 자료’ 링크를 찾습니다. 이전 버전은 보존용이므로 새로 시작할 때 사용하지 않습니다. 이미 작성 중인 파일은 버전을 바꾸기 전에 결과와 대화를 내려받아 보관하세요.
2. 두 작성 도구 중 하나를 선택합니다. Notebook(.ipynb)은 Colab의 파일 → 노트북 업로드로 열고 준비 셀부터 실행합니다. 다음에 원하는 미션 셀의 실행 버튼을 누릅니다. 자료는 내장되어 있으므로 ZIP을 따로 선택하지 않습니다. Google 로그인은 Colab 화면에서 직접 진행합니다. 코드를 고치거나 주석을 해제하지 않습니다.
3. Colab을 사용할 수 없다면 학생용 HTML 파일을 내려받아 브라우저에서 엽니다. HTML의 미션 번호를 누르면 해당 작성란으로 이동합니다. 두 도구에 같은 내용을 두 번 입력할 필요는 없습니다. 별도 실습 ZIP은 자료·빈 양식을 폴더로 확인하려는 경우에 사용하며 압축을 풀고 materials(읽을 자료), forms(빈 양식)를 엽니다.
4. 해당 미션의 진행 안내를 읽고 제공 자료를 펼칩니다. ‘AI에게 요청하기 전 내 생각’에 확인한 사실과 아직 모르는 점을 짧게 적습니다. 다음으로 활동의 AI 요청 예시를 참고합니다.

## AI에게 질문하고 답변 고치기
허용된 AI의 새 대화에 질문과 필요한 가상 자료를 함께 붙입니다. 예시의 [내 자료]는 해당 내용으로 바꾸고, 질문에 적힌 자료도 실제로 붙여야 합니다. 표 전체의 초안은 한 번에 요청해도 됩니다. 답변의 숫자·기록 번호·역할·완료 판단을 원문과 비교하세요. 근거가 맞으면 채택하고, 다르면 수정하거나 AI에 다시 질문합니다. 자료가 없으면 ‘확인 불가’와 필요한 추가 자료를 적습니다.

실제로 보내지 않은 요청, 받지 않은 답변, 측정하지 않은 시간, 없는 승인·완료를 만들지 않습니다. 실제 민감정보와 교관용 정답을 AI에 넣지 않습니다. AI가 제안한 역할이나 절차는 본인이 이유를 검토해 결정합니다.

## 어디에 쓰고 저장하나요?
미션별 활동의 ‘기록할 곳’에 적힌 제목을 Workbook에서 찾아 입력합니다. Notebook에서 ‘작성 내용 저장’은 그 미션 문서를 저장하며, docs·sop·logs 등은 도구가 정하는 폴더 이름입니다. 따로 폴더나 코드를 만들 필요가 없습니다. AI 원문은 대화 목적·실제로 보낸 요청 전체·받은 답변 전체를 한 묶음씩 ‘이 대화 저장’으로 보관합니다. 보완 대화는 새 묶음이므로 파일명이 달라집니다. ‘실제 AI 사용·최종 결정’에는 대화 파일 위치와 채택·수정·보류 이유를 씁니다.

HTML은 입력을 같은 브라우저에 임시 보관하므로 ‘작성 JSON 내려받기’로 별도 저장합니다. 이어 쓸 때 ‘저장한 JSON 이어쓰기’를 선택합니다. Notebook은 Colab 임시 저장이므로 런타임 종료 전에 마지막 ‘진행 확인·내려받기’의 show_submission() 셀을 실행하고 ‘확인하고 ZIP 만들기’를 누릅니다. 미완료라면 검토용 ZIP 선택을 유지합니다. 내려받은 ZIP에 작성 문서와 AI 대화가 있는지 확인하세요.

## 선택 미션과 시간
원본 필수는 미션1·2·3·5·7·9·10, 선택은 미션4·6·8입니다. 선택 미션은 실제로 수행한 경우에만 완료로 기록합니다. 미션7에서 미션6 결과가 없으면 공통 증빙 양식으로 인계를 준비합니다. 미션9에서 미션4·8 결과가 없으면 제공 자료의 ‘기준 자료가 없는 경우’에 따라 첫 실행과 개선안을 먼저 작성합니다. 미션10에는 미수행 선택 미션의 성과를 만들지 않습니다. 원본 예상 27시간과 CMS 편성 29시간(2/2/3/3/3/3/4/3/3/3시간)은 예상값이며 실제 소요는 별도 기록합니다. 선택 가점 배점은 제공되지 않아 임의로 정하지 않습니다.

## 보관과 사용 환경
파일 저장은 학습 통과나 실제 교관 승인이 아닙니다. 하지 않은 활동은 미실시, 재지 않은 값은 미측정으로 적습니다. 가상 D일/T 시각을 실제 타이머 시간으로 쓰지 않습니다. 정답은 평가 제출 후 교관에게 요청하며, 학생용 배포 자료에 넣지 않습니다.

HTML 자체는 외부 연결 없이 작성할 수 있지만 AI 역할 대화에는 기관에서 허용한 별도 AI가 필요합니다. 폐쇄망에서 Colab이나 외부 AI에 접속할 수 있다고 가정하지 않습니다. Colab 런타임이 삭제되면 Notebook 파일만으로 결과·대화가 복원되지 않습니다. 현재 도구는 검토용 ZIP 재가져오기를 지원하지 않으므로 기존 문서·대화를 보관하고 복구가 필요하면 제작자에게 요청하세요. HTML에서 받은 작성 JSON은 Notebook의 ‘선택: HTML에서 작성했다면’ 셀로 가져올 수 있습니다.
