# 미션7 — 예상 밖 상황에서 AI와 기록 이어가기

## 이번에 할 일
통신 두절·차량 고장 등 7개 사건을 하나씩 받아 대응합니다. 안전과 확인을 생략하지 않고, 임시 기록과 다음 담당자에게 넘길 일을 연결합니다.

**익힐 AI 활용:** AI 상대 역할의 답변을 확인하면서 상황 변화에 대응하는 방법

**준비 자료:** 미션2 긴급 카드·미션3 책임표·공통 증빙 작성 양식(미션6 미수행 시에도 사용 가능), I-1~I-7·가상 위임표

**완성할 것:** 사건별 실제 조치·전환 시간·안전 확인·등록 인계 목록

**용어 도움:** 주입=연습 중 사건 메시지를 제시하는 것. 위임표는 이번 가상 연습의 조건이며 실제 군 규정이 아닙니다.

**시작하기 전에:** 여기서 전환 시간은 모든 문제를 해결하는 시간이 아니라, 사건을 읽고 첫 구체적인 행동을 시작할 때까지의 시간입니다. 예를 들어 기록을 실제로 쓰기 시작하거나 확인 요청을 보내는 행동입니다. 한 사건씩 받은 뒤 직접 타이머로 기록하고, 그 다음 AI 역할과 필요한 확인을 주고받으세요. 종이에 적은 대응안만으로 실제 대응을 끝낸 것으로 표시하지 않습니다.


## 처음 시작하는 순서와 용어

미션 안내와 제공 자료를 읽은 뒤 학생용 Workbook의 미션7 작성란을 여세요. 이 미션의 빈 양식은 forms/LOG07_M07_forms.md이며, Workbook에 같은 항목이 준비되어 있습니다. 따로 같은 내용을 두 번 작성할 필요는 없습니다.

사건 주입은 연습 중 새 상황 메시지를 받는 것입니다. 위임은 정해진 조건 안에서 다른 역할이 일을 대신 맡는다는 뜻입니다. 첫 대응 시간은 메시지를 알아차린 때부터 첫 구체적인 확인·보고까지이며, 전체 문제를 해결하는 데 걸린 시간과 다릅니다. 권한은 제공된 가상 위임표만 사용합니다.

- 활동1: 「실행 준비」에 판단과 근거를 기록합니다.
- 활동2: 「7개 사건」에 판단과 근거를 기록합니다.
- 활동3: 「후속 확인」에 판단과 근거를 기록합니다.
- 활동4: 「7개 사건·후속 확인·실제 AI 사용·최종 결정」에 판단과 근거를 기록합니다.

AI 답변을 받으면 먼저 기록 번호와 원문 값을 찾고, 답변의 어느 부분을 채택하거나 고쳤는지 남기세요. 원문에 없으면 확인 불가로 표시하고 필요한 자료를 적습니다. 문서는 작성 내용 저장, 대화는 원문 저장으로 각각 보관합니다. HTML에서는 작성 JSON을 내려받습니다.

## 작성할 때 알아두세요
제공 자료를 읽고 내 생각을 먼저 짧게 적은 뒤 AI에 초안을 요청하세요. 표 전체의 초안을 한 번에 요청해도 됩니다. 같은 내용을 칸마다 AI에 다시 묻지 않아도 됩니다. 답변을 원자료와 비교해 고친 후 각 입력칸에 옮깁니다.

실제 대화는 아래 대화 기록란에 목적·실제로 보낸 요청 전체·실제로 받은 답변 전체를 한 묶음으로 저장합니다. 보완 대화는 새 묶음으로 추가하므로 파일명이 달라지는 것이 정상입니다. ‘실제 AI 사용·최종 결정’에는 원문 파일 위치와 본인의 채택·수정·보류 이유를 적습니다.

작성 내용 저장은 현재 미션 문서를 저장합니다. 대화 저장은 대화 원문을 별도로 저장합니다. 마지막 ‘진행 확인·내려받기’의 show_submission() 셀을 실행하면 ‘확인하고 ZIP 만들기’ 버튼이 나타납니다. 작성 중이면 ‘미완료 상태로 검토용 ZIP 저장’을 선택해 보관합니다.

한 번 작성한 내용은 저장해 두고 이어서 사용하세요. 이 미션에서 요구한 수행 내용과 판단 근거를 남기되, 아직 하지 않은 활동은 이유와 다음 할 일을 적습니다. 저장 성공과 과제 통과는 별개입니다.
