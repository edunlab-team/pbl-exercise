# LOG07 워크북 실행 안내

1. LOG07_workbook.ipynb를 Colab에서 엽니다. LOG07_실습프로젝트.zip을 준비 셀에서 올립니다. 전체제작본ZIP과 구분합니다.
2. 준비 셀의 ROOT=/content/LOG07_project를 확인합니다. 제공 도구는 Python표준 라이브러리만 사용합니다.
3. 미션별 Lesson을 읽고 별도 AI 창에서 분석·상대역할 실습을 합니다. 실제 요청·답변을 저장하고 자료·로그와 대조합니다. 외부AI 로그인/실제 대화는 학습자가 수행합니다.
4. RESULT 문자열의 양식 빈칸을 채우고 save_result의 주석을 해제해 저장합니다. 또는 같은 제출 경로의 문서를 외부 편집기로 작성합니다. lesson/form 중한 곳만 작성합니다. 빈양식을 그대로 저장하면 도구가 거부합니다.
5. save_ai_dialogue로 실제 대화 원문을 보존합니다. 처음/보완/역할 대화를 구분합니다. 제공 도구는 대화의 진위를 자동 확인하지 않습니다.
6. M4·M7은 해당 AI_role_setup을 별도 역할 대화에 사용합니다. 학습자가 확인·보고·다음단계를 직접 선택하고 실제타이머 원값을 양식에 기록합니다. mark_actual_time은 실제 셀 실행 시각입니다.
7. M9에서 같은 조건·분모로 재훈련을 비교합니다. 도구의 상대변화율None은 기준0으로 산출불가라는 뜻이며 유지·악화 여부를 원값으로 판단합니다.
8. 모든10미션의 작성본과 실제AI기록을 보존한 뒤 마지막셀에서 uploads/LOG07.zip을 내려받습니다. 런타임 초기화 전에 저장합니다. 파일검사는 학습 성과·실제교관 승인을 대신하지 않습니다.

준비셀 재실행은 기존 폴더를 재사용합니다. 새 실습 전에는 기존 작성자료를 내려받아 별도로 보관하세요. 실제 Colab/CMS 서비스 검증은 별도입니다.
