# 미션1 — 보급 기록을 읽고 확인 항목 만들기

## 이번에 할 일
요청서·불출증·수령증에는 같은 보급 건의 서로 다른 단계가 적혀 있습니다. 이 기록이 제대로 연결되는지 알아보기 위해 식량 12상자를 요청한 기록부터 읽습니다. AI와 함께 누가 어떤 기록을 남기는지 정리하고, 기록만으로 알 수 없는 내용도 찾아봅니다.

**익힐 AI 활용:** AI에 자료를 설명하고, 답변을 원문과 비교하는 방법

**준비 자료:** 제공 자료의 흐름표와 E01~E06 기록

**완성할 것:** 6단계 흐름표·30칸 역할표·기본 확인 항목 15개 이상·환경별 추가 항목

**용어 도움:** 증빙=처리 내용을 확인할 기록. 불출=창고에서 물자를 내보냄. R=수행, A=최종 책임, C=협조, I=통보.


## 처음 시작하는 순서와 용어

미션 안내와 제공 자료를 읽은 뒤 학생용 Workbook의 미션1 작성란을 여세요. 이 미션의 빈 양식은 forms/LOG07_M01_forms.md이며, Workbook에 같은 항목이 준비되어 있습니다. 따로 같은 내용을 두 번 작성할 필요는 없습니다.

흐름표는 요청부터 등록까지 누가 무엇을 받고 남기는지 정리한 표입니다. 역할표(RACI)는 같은 단계에서 누가 일을 하고(R), 최종 책임을 지며(A), 의견을 주고(C), 결과를 전달받는지(I) 구분합니다. 한 사람이 R과 A를 함께 맡는 제안에는 이유를 적으세요. 검증 포인트는 AI 답변을 원문과 다시 비교할 부분이라는 뜻입니다.

- 활동1: 「AI에게 요청하기 전 내 생각」에 판단과 근거를 기록합니다.
- 활동2: 「흐름표·역할표·기본 체크 항목 15개 이상」에 판단과 근거를 기록합니다.
- 활동3: 「실제 AI 주장3종류와 제공 예시3문장 검토」에 판단과 근거를 기록합니다.
- 활동4: 「환경별 추가 항목」에 판단과 근거를 기록합니다.
- 활동5: 「실제 AI 사용·최종 결정·확인 상태」에 판단과 근거를 기록합니다.

AI 답변을 받으면 먼저 기록 번호와 원문 값을 찾고, 답변의 어느 부분을 채택하거나 고쳤는지 남기세요. 원문에 없으면 확인 불가로 표시하고 필요한 자료를 적습니다. 문서는 작성 내용 저장, 대화는 원문 저장으로 각각 보관합니다. HTML에서는 작성 JSON을 내려받습니다.

## 작성할 때 알아두세요
제공 자료를 읽고 내 생각을 먼저 짧게 적은 뒤 AI에 초안을 요청하세요. 표 전체의 초안을 한 번에 요청해도 됩니다. 같은 내용을 칸마다 AI에 다시 묻지 않아도 됩니다. 답변을 원자료와 비교해 고친 후 각 입력칸에 옮깁니다.

실제 대화는 아래 대화 기록란에 목적·실제로 보낸 요청 전체·실제로 받은 답변 전체를 한 묶음으로 저장합니다. 보완 대화는 새 묶음으로 추가하므로 파일명이 달라지는 것이 정상입니다. ‘실제 AI 사용·최종 결정’에는 원문 파일 위치와 본인의 채택·수정·보류 이유를 적습니다.

작성 내용 저장은 현재 미션 문서를 저장합니다. 대화 저장은 대화 원문을 별도로 저장합니다. 마지막 ‘진행 확인·내려받기’의 show_submission() 셀을 실행하면 ‘확인하고 ZIP 만들기’ 버튼이 나타납니다. 작성 중이면 ‘미완료 상태로 검토용 ZIP 저장’을 선택해 보관합니다.

한 번 작성한 내용은 저장해 두고 이어서 사용하세요. 이 미션에서 요구한 수행 내용과 판단 근거를 남기되, 아직 하지 않은 활동은 이유와 다음 할 일을 적습니다. 저장 성공과 과제 통과는 별개입니다.

## 차례대로 해보기

### 활동1. 자료를 먼저 읽고 분석 요청을 설계한다
먼저 E01의 요청과 E03의 불출 기록을 직접 읽고 품목·수량을 찾으세요.

**AI 요청 예시 — 대괄호에는 내 자료를 넣으세요:**
> E01과 E03을 붙입니다. 요청번호·품목·단위·수량을 표로 옮기고 각 값의 기록 번호를 달아줘. 서로 다른 번호가 같은 보급 건을 연결하는지 설명하고, 아직 확인할 수 없는 항목도 따로 적어줘.

**확인할 점:** R-301·12상자, 가람-D-017·보-D-102를 원문과 대조합니다. 불출 기록만으로 수령·등록 완료를 판단하지 않습니다.

**기록할 곳:** Workbook 미션1의 「AI에게 요청하기 전 내 생각」.

### 활동2. AI와 대화하여 분석 초안을 만든다
6단계 흐름표와 5개 역할의 역할표 초안을 한 번에 요청한 뒤 항목별로 검토하세요.

**AI 요청 예시 — 대괄호에는 내 자료를 넣으세요:**
> E01~E06과 내 생각을 붙입니다. 요청·승인·불출·수송·수령·등록의 흐름표를 담당/받는 기록/남길 기록/확인 근거로 작성해줘. 이어 6단계×5역할의 R/A/C/I 제안표와 기본 체크 항목 15개 이상을 만들어줘. 기록에 있는 역할과 네가 제안한 역할 배분을 구분해줘.

**확인할 점:** 역할표 30칸, 단계별 A 1명과 수행 R을 확인합니다. E06은 참고 카드이며 등록 완료 증거가 아닙니다. R/A 겸임 제안에는 이유를 붙입니다.

**기록할 곳:** Workbook 미션1의 「흐름표·역할표·기본 체크 항목 15개 이상」.

### 활동3. AI의 주장을 근거와 대조하고 보완을 요청한다
실제 AI 답변의 사실·역할 배분·완료 판단을 하나씩 고르고, 제공된 예시 3문장도 따로 검토하세요.

**AI 요청 예시 — 대괄호에는 내 자료를 넣으세요:**
> 앞의 답변과 E01~E06을 다시 붙입니다. 주장/근거 기록과 값/근거로 말할 수 있는 범위/수정문 표를 만들어줘. 재고 수치·내용물 상태·유효기간·전산 등록 완료를 추정하지 말고, 확인 불가를 미완료로 단정하지 마. 사진 기록 카드는 실제 사진이 아닌 텍스트 자료라는 점을 반영해줘.

**확인할 점:** 원자료에 없는 총재고·완료·확신도 수치를 삭제합니다. 실제 AI 주장 검토와 교육용 예시 3문장 검토를 구분합니다.

**기록할 곳:** Workbook 미션1의 「실제 AI 주장3종류와 제공 예시3문장 검토」.

### 활동4. 환경 변화에 맞춰 업무 기준을 보완한다
야전·기지·의무의 세 조건을 읽고 기존 체크 항목에 필요한 확인을 덧붙이세요.

**AI 요청 예시 — 대괄호에는 내 자료를 넣으세요:**
> 자료 1-3과 내 체크리스트를 붙입니다. 야전·기지·의무별 추가 확인 2개 이상을 환경/추가 항목/필요 자료/담당과 남길 기록으로 제안해줘. 식량 사례를 의약품에 그대로 적용하지 말고 자료가 필요한 부분은 질문으로 남겨줘.

**확인할 점:** 각 환경 2개 이상인지 확인합니다. 냉장·유효기간의 구체 기준을 새로 만들어 공식 기준처럼 쓰지 않습니다.

**기록할 곳:** Workbook 미션1의 「환경별 추가 항목」.

### 활동5. 최종 정의서를 통합하고 검토·승인을 추적한다
초안·보완 답변·본인 판단을 보존하고 미션2에서 사용할 최종 항목 번호를 정하세요.

**AI 요청 예시 — 대괄호에는 내 자료를 넣으세요:**
> 내 최종 흐름표·역할표·체크리스트와 수정 이유를 붙입니다. 6단계/30칸/기본15개 이상/환경별2개 이상/근거 한계의 누락을 표로 점검해줘. 다음 미션에서 참조할 항목 번호의 중복도 찾아줘. 실제 교관 검토 상태는 내가 제공한 값만 적어줘.

**확인할 점:** AI 검토 의견을 본인이 채택·수정·보류한 이유를 기록합니다. 저장 완료를 학습 통과로 바꾸지 않습니다.

**기록할 곳:** Workbook 미션1의 「실제 AI 사용·최종 결정·확인 상태」.
