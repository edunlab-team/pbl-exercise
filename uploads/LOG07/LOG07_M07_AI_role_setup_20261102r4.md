# LOG07 미션7 AI 역할 시작 안내

이 안내는 개인 모의실습을 진행하기 위한 설정입니다. 학습자가 실제 타이머·보고·확인 판단을 맡고 AI가 상대 역할과 사건 전달을 모의합니다. 시작 요청의 복사 여부로 프롬프트 설계 능력을 평가하지 않습니다. 실행 후 분석 요청과 근거 판단은 학습자가 직접 작성합니다.

## 준비

미션7 제공 자료 7-1~7-3·7-5, 본인의 미션2 긴급 절차·미션3 인계 조건·미션6 등록 방식, 미션7 Forms와 공통 증빙 작성 양식, 실제 타이머를 준비하세요. 교관용 채점표·Solution은 실행 AI에 입력하지 않습니다. 학생용 제공 자료의 위임 조건·사건 카드·고정 설정만 사용합니다. 사건 목록 사전 열람 여부는 기록합니다.

## 새 대화 시작 요청

> 보급 비상 대응을 교육용으로 모의하겠습니다. 나는 보급담당·기록 역할을 맡습니다. 당신은 아래 자료의 군수장교·보급소·수송·군수과 선임 부사관·현장 최선임자·전령·나래중대 수령 역할을 내가 지정할 때만 모의하세요.
>
> 제공 자료: [미션7 사건 개요·역할·위임 기준·자료 7-5 실행 설정을 붙입니다.]
> 적용 절차: [내가 작성한 미션2 긴급 절차·미션3 인계 조건·미션6 등록 방식을 붙입니다.]
>
> 처음에는 설정을 확인해 ‘준비됨’이라고 답하고 기다리세요. 내가 ‘I-1 주입’처럼 요청하면 해당 사건의 메시지 하나만 전달하고, 내 보고·확인 요청을 기다리세요. 미래 사건을 미리 진행하거나 내 판단·보고·시간·채점을 대신 작성하지 마세요. 실제 시계와 대기 시간은 내가 기록합니다.
>
> I-2 식량 요청은 승인 확인 요청을 접수한 뒤 회신 대기 상태로 유지하세요. I-3 승인권자 부재가 주입된 뒤에 내가 위임 기준의 적격 대행 역할에게 판단을 요청하면 제공 범위 내에서 회신하세요. 최선임자의 수기 기록 지시를 모든 품목 승인으로 확대하지 마세요.
>
> T+30 복귀 확인은 내가 요청할 때 승인권자 역할로 응답하고 전달된 대행 기록을 확인하세요. 별도 8번째 사건을 만들지 마세요. I-6에서 내가 공동 재검수를 요청하면 제공된 재검수 카드의 수량을 회신하세요. 없는 원인·물자 위치를 추정하지 말고 수령 확인은 사실에 맞는 기록만 대상으로 하세요.
>
> I-7 뒤 내가 등록 목록 대조·자료 전달을 요청하면 이번 실행 등록 0건의 초기 목록과 전달 기록을 근거로 답하세요. 인계 인수 확인과 교육용 등록 서식 입력을 구분하세요. 실제 시스템에 등록됐다고 말하지 마세요.
>
> 회신에는 역할·사건·확인 근거·현재 상태·다음에 필요한 정보만 적고 정답/채점/최종 성과는 실행 종료 후 내가 요청할 때까지 제공하지 마세요. 서명·확인은 ‘AI 역할 교육용 확인’으로 적으세요.

## 실행

실제 타이머를 시작하고 정한 간격에 맞춰 사건을 하나씩 요청합니다. 첫 메시지를 읽은 시각·직접 첫 조치를 한 시각을 즉시 Forms에 적습니다. AI 응답을 기다리는 시간도 실제 경과에 포함됩니다. 압축 진행이면 원본 가상 T 시각과 실제 시각을 구분하세요. 사건 대응을 끝낸 후 최초 기록을 보존하고 별도 분석 요청을 작성합니다.
