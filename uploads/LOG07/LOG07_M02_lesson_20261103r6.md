# 미션2 — 다른 사람도 쓸 수 있는 확인 절차 만들기

## 이번에 할 일
미션1에서 만든 확인 항목을 실제 행동으로 바꿉니다. “잘 확인한다” 대신 무엇을 비교하고, 다르면 누구에게 무엇을 요청할지 적습니다.

**익힐 AI 활용:** AI로 문서 초안을 만들고 시험 사례로 고치는 방법

**준비 자료:** 자신의 미션1 결과, 교육용 K01~K10·S01~S08 기준, T01~T07 사례

**완성할 것:** 일반·긴급 체크리스트·절차 흐름·휴대용 카드·수정 기록

**용어 도움:** SOP=누가 어떤 순서로 확인하고 조치할지 적은 절차. 교차 검토=다른 관점에서 빠진 부분을 살펴봄.


## 처음 시작하는 순서와 용어

미션 안내와 제공 자료를 읽은 뒤 학생용 Workbook의 미션2 작성란을 여세요. 이 미션의 빈 양식은 forms/LOG07_M02_forms.md이며, Workbook에 같은 항목이 준비되어 있습니다. 따로 같은 내용을 두 번 작성할 필요는 없습니다.

체크리스트는 빠짐없이 확인할 항목의 목록입니다. SOP는 그 항목을 누가, 어떤 순서로 확인하고, 문제가 생기면 어떻게 처리할지 적은 절차입니다. K01~K10은 기본 확인 기준, S01~S08은 안전·보안 기준, T01~T07은 절차를 시험할 사례 번호입니다.

- 활동1: 「AI에게 요청하기 전 내 생각·6단계 SOP」에 판단과 근거를 기록합니다.
- 활동2: 「6단계 SOP·안전·보안8개」에 판단과 근거를 기록합니다.
- 활동3: 「교차 검토·시험」에 판단과 근거를 기록합니다.
- 활동4: 「휴대용 카드 5~7묶음」에 판단과 근거를 기록합니다.

AI 답변을 받으면 먼저 기록 번호와 원문 값을 찾고, 답변의 어느 부분을 채택하거나 고쳤는지 남기세요. 원문에 없으면 확인 불가로 표시하고 필요한 자료를 적습니다. 문서는 작성 내용 저장, 대화는 원문 저장으로 각각 보관합니다. HTML에서는 작성 JSON을 내려받습니다.

## 작성할 때 알아두세요
제공 자료를 읽고 내 생각을 먼저 짧게 적은 뒤 AI에 초안을 요청하세요. 표 전체의 초안을 한 번에 요청해도 됩니다. 같은 내용을 칸마다 AI에 다시 묻지 않아도 됩니다. 답변을 원자료와 비교해 고친 후 각 입력칸에 옮깁니다.

실제 대화는 아래 대화 기록란에 목적·실제로 보낸 요청 전체·실제로 받은 답변 전체를 한 묶음으로 저장합니다. 보완 대화는 새 묶음으로 추가하므로 파일명이 달라지는 것이 정상입니다. ‘실제 AI 사용·최종 결정’에는 원문 파일 위치와 본인의 채택·수정·보류 이유를 적습니다.

작성 내용 저장은 현재 미션 문서를 저장합니다. 대화 저장은 대화 원문을 별도로 저장합니다. 마지막 ‘진행 확인·내려받기’의 show_submission() 셀을 실행하면 ‘확인하고 ZIP 만들기’ 버튼이 나타납니다. 작성 중이면 ‘미완료 상태로 검토용 ZIP 저장’을 선택해 보관합니다.

한 번 작성한 내용은 저장해 두고 이어서 사용하세요. 이 미션에서 요구한 수행 내용과 판단 근거를 남기되, 아직 하지 않은 활동은 이유와 다음 할 일을 적습니다. 저장 성공과 과제 통과는 별개입니다.

## 차례대로 해보기

**확인할 점:** 기본 기준 10개와 안전·보안 8개 모두의 연결 위치가 있는지 대조합니다.

**AI 요청 예시 — 대괄호에는 내 자료를 넣으세요:**
