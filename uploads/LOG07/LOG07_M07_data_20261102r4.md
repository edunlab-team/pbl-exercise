# 미션7 제공 자료

**가상 교육 자료입니다. 시각·수량·품목과 추가 설정은 첨부 원자료를 보존했습니다.**

## 3. 제공 자료 및 실행 기준

### 자료 7-1 — 시간대별 주입 카드 

아래 표는 훈련 일정과 사건 개요입니다. 실행 중에는 주입 담당 또는 AI가 해당 시점의 사건 하나씩을 제시합니다. 교관용 기대 조치·채점 해설은 초기 대응 전에 제공하지 않습니다. 사건 목록을 미리 읽은 경우 실행 설정에 ‘사건 사전 열람’으로 기록하세요.

| 주입 | 시각 | 주입 내용 |
| --- | --- | --- |
| I-1  |  T+00  |  대대 무전·전화 두절, 복구 예정 시각 미상 |
| I-2  |  T+05  |  나래중대 전령 도착: 야간 경계용 식량 8상자 긴급 요청 |
| I-3  |  T+10  |  군수장교 현장 순찰로 20분 부재 |
| I-4  |  T+18  |  수송 차량 전조등 고장, 야간 이동 제한 |
| I-5  |  T+25  |  유류 용기 1개 누유 발견 |
| I-6  |  T+32  |  수령 중대 수령자 서명 거부(수량 이견) |
| I-7  |  T+40  |  통신 복구 |

T는 가상 훈련 시작 시점이며 제시된 사건 간격은 분 단위로 운영한다. 실시간 훈련은 시작 후 0·5·10·18·25·32·40분에 카드가 전달되도록 한다. 준비·검토·피드백은 운영 시간 4시간에 포함한다. 원본 예상 시간은 3.5시간이며 실제 소요시간과 구분한다. 압축 진행을 택하면 원본 T 표시는 유지하고 실제 카드 전달 시각·압축 방식·이유를 별도로 남긴다. 제시된 사건 간격으로 실행했다고 주장하지 않는다.

### 자료 7-2 — 가상 위임 기준 

| 상황 | 대행자 | 대행 가능 범위 | 사후 조치 |
| --- | --- | --- | --- |
| 승인권자 부재 30분 이내 | 군수과 선임 부사관 | 식량·의무 물자, 1회 요청 수량 이내 | 복귀 즉시 확인 서명 |
| 탄약 긴급 요청 | 대행 불가 | 승인권자 무전·전령 확인 필수 | 대기 사유 기록 |
| 통신 두절 | 현장 최선임자 | 수기 증빙 작성 지시 | 복구 후 1시간 내 전산 등록 |

이 표는 이번 연습용 가상 기준이다. 실제 군 지휘·승인 권한 규정으로 사용하지 않는다.

위 표를 각 사건의 조건과 대조해 대행 가능 여부·범위·후속 확인을 판단하세요. 제공되지 않은 이름·계급·실제 권한은 추정하지 않습니다.

### 자료 7-3 — 역할과 추가 실행 설정

인물·역할명은 유지하되 나래중대 수령자·전령·군수과 선임 부사관·현장 최선임자처럼 이름이 없는 역할은 역할명으로 둔다.

| 역할 | 인물·역할명 | 수행 범위 |
| --- | --- | --- |
| 보급담당·기록·인계 | 김가온 하사 | 요청·임시 증빙·보고·복구 인계 |
| 승인권자·군수장교 | 이도윤 대위 | 승인·복귀 확인, 보고 수신 |
| 불출 담당 | 박새론 중사 | 승인 범위·불출 수량·인계 확인 |
| 수송 선탑자 | 최다온 상병 | 수송·차량 이상 보고·인계 |
| 가람중대 수령 역할 | 정하람 병장 | 해당 물자의 검수·인계 확인 |
| 나래중대 수령자·전령 등 | 성명 없음 | 원본 역할명으로 모의. 가람중대 인물을 나래 소속으로 변경하지 않음 |
| 관측자 | 성명 없음 | 실제 시각·행동·성공·안전 근거 기록 |

개인 실습에서는 AI가 다른 역할·주입을 모의하고 학습자가 실제 타이머·대화로 관측한다. 자기 관측을 독립된 사람 관측으로 표시하지 않는다.

**이번 실행의 교육용 조건**

1. 실행 식별은 M7-DR, 임시 기록은 M7-TMP-01 등으로 추가한다. I-1~I-7을 바꾸지 않는다.
2. I-2 식량 품목은 R-301로 연결한다. 가용 8상자가 있다는 추가 카드와 필요한 수기 청구·승인·불출·인계 서식을 제공한다. 완료 기록은 역할 수행 중 작성한다.
3. I-3의 부재는 T+10부터 20분이다. 돌아오는 T+30에는 승인권자 역할이 복귀 여부를 회신하고 대행 승인 건을 확인한다. 이 회신은 후속 역할 행동이며 8번째 주입으로 세지 않는다. 실제 복귀·서명이 확인되지 않으면 미완료로 남긴다.
4. I-4에는 ‘원 차량 전조등 고장’, ‘교육용 대체 차량: 운행 전 안전 확인 자료 제공 가능’ 카드를 둔다. 실제 운전·도보 운반은 하지 않는다. 안전 확인 후 대체 수송을 가상 판단할 수 있고, 확인 자료가 없으면 이동 보류·보고가 적절한 조치다. 도보 운반을 무조건 가능한 대안으로 취급하지 않는다.
5. I-5 유류는 별도 F-201 상태 카드 1개로 제시한다. 총 재고 수량은 제공되지 않았으므로 추정하지 않는다. ‘사용 중지·격리’는 카드에 보류·분리 관리 표시를 하는 모의 조치다. 실제 누유 처리 실습은 없다.
6. I-6의 이견 수량은 제공되지 않았습니다. 이번 추가 카드에서는 나래중대 식량 인계 문서 8상자·첫 수령 확인 7상자를 제시한다. 공동 재검수 카드도 7상자로 제공한다. 문서와 공동 재검수 결과를 대조해 확인 수령·차이·이견·후속 확인을 기록하고 실제 원인을 단정하지 않는다. 인수자는 이 사실을 담은 기록을 확인한 뒤 가상 서명에 응답할 수 있다. 수량 부족을 정상 8상자 수령으로 바꾸거나 서명을 강요하지 않는다.
7. I-7에는 기존 가상 등록 목록을 제공하고 수기 증빙과 대조한다. 비교용 목록은 초기 ‘이번 실행 등록 건 없음’으로 정한다. 추가 설정이며 실제 시스템 조회 결과가 아니다. 복구 후 등록 담당은 대대 군수과 역할로 두고 후속 기한·중복 확인 결과를 기록한다.

### 자료 7-4 — 전환·성공·안전 판정 

**전환 시간**

- 실제 인지 = 카드 내용을 확인한 시점. 실제 전환 = 해당 사건의 첫 구체적인 대응이 시작된 시점.
- 예: 임시 기록에 첫 필드를 적음, 인수 절차 보류·이상 보고를 실제 전달함, 공동 재검수를 실제 요청함, 등록 대상 대조를 시작함. ‘비상 절차로 하겠습니다’만 말한 것은 충분하지 않다.
- 전환 소요 = 실제 전환−실제 인지, 주입별 60초 이내. 전체 조치 완료 시간과 별개로 적는다.
- I-7은 복구 후 임시 증빙 대조·등록 인계를 시작하는 시간으로 같은 기준을 적용한다.
- AI 문구 작성·검토를 기다리는 시간도 기록한다. 학습자가 첫 조치를 직접 판단·실행한 뒤 AI로 보강할 수 있다. AI가 만든 가상 시각은 실측이 아니다.

**위험 조치 성공률**

제시된 7건 모두를 분모로 사용합니다. 조치 성공은 아래 사건별 핵심 조치·필요 기록이 충족되었는지 O/X로 판정한다. 성공률 = O/7×100. **6/7은 약 85.7%, 90% 이상에는 7/7이 필요**하다. I-1 등의 안전 사건만 골라 분모를 줄이지 않는다.

사건별 상세 채점표와 허용 가능한 대응 범위는 교관용 Solution에 분리했습니다. 본인은 사건별 행동·근거·후속 상태를 남기고, 단순 미서명 또는 안전한 보류를 숨기지 않습니다.

**안전 위반 0건**

미션2 안전·보안 기준에 대조한다. 카드상 누유를 정상 사용 처리, 안전 확인 없는 고장 차량 이동 강행, 탄약 무권한 대행 승인, 수량 이견 은폐·서명 강요, 실제 물자·민감 자료 사용 등을 기록상 위반으로 확인한다. 실제 위험 행동은 실습에 포함하지 않는다. 근거 없이 안전 위반 0건이라고 적지 않는다.


### 자료 7-5 — 사건을 하나씩 진행하는 방법과 실행 자료

개인 실습은 [미션7 AI 역할 시작 안내](/uploads/LOG07/LOG07_M07_AI_role_setup_20261102r4.md)를 사용합니다. 학습자가 실제 타이머를 보며 ‘I-1 주입’처럼 해당 사건을 요청하면 AI가 자료 7-1의 메시지만 전달합니다. AI는 기다렸다가 실제 학습자의 보고·확인 요청에 해당 역할로 응답합니다. 역할 응답은 검증 대상이며 정답·실측을 대신하지 않습니다.

- 식량 요청 추적값: `M7-DR`, 청구 `M7-REQ-01`, 임시 기록 `M7-TMP-01`, 불출 `M7-ISS-01`, 수송 `M7-TRN-01`, 수령 `M7-RCV-01`. 모두 교육용 식별값입니다.
- 물자 카드: R-301 요청 8상자·가용 8상자, 로트 `M7-R-LOT-01`, 봉인 `M7-SEAL-01`, 외부 포장 양호·교육용 유효기간 D+300일. 식량 8상자 요청과 별도의 누유 유류 카드 F-201 1개를 섞지 않습니다.
- I-2에서는 **요청 접수·승인 확인 요청까지 진행하고 승인 회신은 대기**합니다. I-3에서 승인권자 부재 메시지를 받은 뒤 적격 대행 역할의 판단을 요청합니다. 이는 위임을 연습하기 위한 교육용 실행 설정입니다. I-2에서 이미 최종 승인이 끝났다면 대행 승인을 중복 생성하지 말고 실행 조건 차이를 기록하고 해당 구간을 새 실행으로 다시 준비하세요.
- I-4의 대체 차량 카드는 ‘교육용 운행 전 점검 결과 이상 없음’을 제공합니다. 학습자가 카드 확인과 운행 판단을 요청한 후에만 수송 진행을 모의합니다. 실제 차량 운행은 없습니다.
- I-6의 공동 재검수 카드: 식량 문서 8상자·첫 확인 7상자·공동 재검수 7상자. 실제 원인·나머지 1상자의 위치는 제공하지 않습니다.
- I-7의 초기 기존 등록 목록은 ‘이번 실행 등록 건 0건’입니다. [공통 증빙 작성 양식](/uploads/LOG07/LOG07_공통_증빙작성양식_20261102r2.md)과 미션7 작성 양식에 임시 기록·후속 상태를 작성하고 군수과 역할에 전달하세요.
- 제시된 사건 간격은 0·5·10·18·25·32·40분입니다. 압축 방식이면 사건 순서는 유지하고 실제 전달 시각·가상 T 시각·압축 여부를 모두 기록합니다. 첫 대응 60초는 실제 타이머로 잽니다.
- T+30의 승인권자 복귀는 별도 후속 확인입니다. 학습자가 복귀 확인을 요청하고 그동안의 대행 기록을 전달해야 확인 회신을 받을 수 있습니다. 이를 8번째 주입으로 세지 않습니다.
