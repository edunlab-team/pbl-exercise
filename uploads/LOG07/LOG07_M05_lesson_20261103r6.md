# 미션5 — 기록 12세트에서 오류 찾기

## 이번에 할 일
숫자가 맞아 보여도 서명이나 시각이 다를 수 있습니다. 먼저 스스로 판단하고 AI의 검토와 비교한 뒤, 고정한 제출본을 정답표와 대조합니다.

**익힐 AI 활용:** AI의 판정을 자료로 확인하고 놓친 오류·과도한 판단을 고치는 방법

**준비 자료:** S01~S12 증빙 요약과 미션2의 확인·보고 기준

**완성할 것:** 12세트 판정표·AI 검토·초기 점수와 수정 기록

**용어 도움:** 오탐=정상인데 오류라고 함. 미탐=오류인데 정상이라고 함. 요약에 없는 사실은 추가 확인 대상입니다.

**시작하기 전에:** S01부터 한 행씩 읽고 청구·승인·불출·적재·수령 수량을 비교한 다음 시각과 서명을 확인하세요. 대조한 두 값과 판단 이유를 먼저 적고, AI에게 놓친 항목이 있는지 검토를 요청합니다. 교관 정답은 평가 제출본을 고정한 뒤 확인합니다. 최초 판정표는 수정하지 말고 보완본을 따로 만드세요.


## 처음 시작하는 순서와 용어

미션 안내와 제공 자료를 읽은 뒤 학생용 Workbook의 미션5 작성란을 여세요. 이 미션의 빈 양식은 forms/LOG07_M05_forms.md이며, Workbook에 같은 항목이 준비되어 있습니다. 따로 같은 내용을 두 번 작성할 필요는 없습니다.

한 세트는 서로 연결된 여러 기록의 요약입니다. 오탐은 정상인데 오류라고 판단한 경우, 미탐은 오류인데 정상이라고 판단한 경우입니다. 최초 이상 단계는 기록이 처음 어긋나는 지점입니다. 원인을 추측하기보다 서로 다른 두 값과 기록 번호를 먼저 찾으세요.

- 활동1: 「12세트 판정」에 판단과 근거를 기록합니다.
- 활동2: 「12세트 판정」에 판단과 근거를 기록합니다.
- 활동3: 「정답 공개 전 제출 고정·정답 대조 후 기록」에 판단과 근거를 기록합니다.
- 활동4: 「12세트 판정·정답 대조 후 기록」에 판단과 근거를 기록합니다.

AI 답변을 받으면 먼저 기록 번호와 원문 값을 찾고, 답변의 어느 부분을 채택하거나 고쳤는지 남기세요. 원문에 없으면 확인 불가로 표시하고 필요한 자료를 적습니다. 문서는 작성 내용 저장, 대화는 원문 저장으로 각각 보관합니다. HTML에서는 작성 JSON을 내려받습니다.

## 작성할 때 알아두세요
제공 자료를 읽고 내 생각을 먼저 짧게 적은 뒤 AI에 초안을 요청하세요. 표 전체의 초안을 한 번에 요청해도 됩니다. 같은 내용을 칸마다 AI에 다시 묻지 않아도 됩니다. 답변을 원자료와 비교해 고친 후 각 입력칸에 옮깁니다.

실제 대화는 아래 대화 기록란에 목적·실제로 보낸 요청 전체·실제로 받은 답변 전체를 한 묶음으로 저장합니다. 보완 대화는 새 묶음으로 추가하므로 파일명이 달라지는 것이 정상입니다. ‘실제 AI 사용·최종 결정’에는 원문 파일 위치와 본인의 채택·수정·보류 이유를 적습니다.

작성 내용 저장은 현재 미션 문서를 저장합니다. 대화 저장은 대화 원문을 별도로 저장합니다. 마지막 ‘진행 확인·내려받기’의 show_submission() 셀을 실행하면 ‘확인하고 ZIP 만들기’ 버튼이 나타납니다. 작성 중이면 ‘미완료 상태로 검토용 ZIP 저장’을 선택해 보관합니다.

한 번 작성한 내용은 저장해 두고 이어서 사용하세요. 이 미션에서 요구한 수행 내용과 판단 근거를 남기되, 아직 하지 않은 활동은 이유와 다음 할 일을 적습니다. 저장 성공과 과제 통과는 별개입니다.

## 차례대로 해보기

### 활동1. 12세트를 읽고 초기 교차검증표 작성하기
먼저 혼자 12세트의 초기 판정을 적으세요. 아직 교관 해설은 보지 않습니다.

**AI 요청 예시 — 대괄호에는 내 자료를 넣으세요:**
> 내가 만든 초기 판정표의 빈칸을 찾는 검토만 해줘. 정상/오류의 정답을 먼저 알려주지 말고, 세트마다 대조값·최초 이상 단계·근거·보고 경로를 적었는지 질문해줘. [내 초기 표]

**확인할 점:** 수량뿐 아니라 시각·서명·봉인을 봅니다. 제공 필드에 없는 정보만으로 정상 세트를 오류로 바꾸지 않습니다.

**기록할 곳:** Workbook 미션5의 「12세트 판정」.

### 활동2. AI로 초기 판단을 교차 검토하기
본인 초기 판정을 남긴 뒤 AI의 별도 판단과 비교하세요.

**AI 요청 예시 — 대괄호에는 내 자료를 넣으세요:**
> S01~S12 요약과 내 초기 판정을 붙입니다. 세트별 AI 판단/대조한 두 값/초기 판단과 차이/추가 확인을 작성해줘. 확인된 불일치와 실제 원인 가설을 나누고 자료에 없는 문서·인물을 만들지 마.

**확인할 점:** 특히 승인과 불출의 선후, 승인수량과 불출수량을 다시 읽고 오탐·미탐 후보를 확인합니다.

**기록할 곳:** Workbook 미션5의 「12세트 판정」.

### 활동3. 정답 대조·오탐/미탐·결과 보고하기
AI 검토까지 반영한 평가 제출본을 고정한 뒤 교관 정답을 받으세요.

**AI 요청 예시 — 대괄호에는 내 자료를 넣으세요:**
> 정답 공개 전에 저장한 내 평가 제출본과 지금 받은 교관 정답을 붙입니다. 정상/오류와 핵심 유형이 모두 맞은 세트 수를 세고, 오탐/미탐/유형 오판 및 최초 점수를 계산해줘. 보완 후 결과로 최초 점수를 바꾸지 마.

**확인할 점:** 85% 기준은11/12이상입니다. 공개 전 제출본이 없으면 최초 평가 미실시로 표시합니다.

**기록할 곳:** Workbook 미션5의 「정답 공개 전 제출 고정·정답 대조 후 기록」.

### 활동4. 우선순위·보고 경로 완성하기
틀린 판단을 보완하고 확인 우선순위와 보고 경로를 완성하세요.

**AI 요청 예시 — 대괄호에는 내 자료를 넣으세요:**
> 내 오판·추가 확인 목록을 붙입니다. 수량/승인 범위/봉인/직무 분리와 작성 누락·시각 문제를 구분해 확인 순서와 보고·보류 범위를 제안해줘. 자료5-3을 근거로 하고 실제 원인을 단정하지 마.

**확인할 점:** 모든 오류 세트에 근거·최초 이상 단계·보고 경로가 있는지 확인합니다. 최초 제출본과 보완본을 별도로 둡니다.

**기록할 곳:** Workbook 미션5의 「12세트 판정·정답 대조 후 기록」.

## 제출 전 확인
- 정상/오류와 핵심 유형이 맞는 세트 11/12 이상
- 오류 세트마다 최초 이상 단계·두 기록의 값·보고 경로를 제시
- 정답 열람 전 제출본과 열람 후 보완본을 구분하고 원인·책임을 단정하지 않음
