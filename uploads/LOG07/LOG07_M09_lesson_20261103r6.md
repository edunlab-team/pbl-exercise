# 미션9 — 같은 조건으로 다시 해 보고 비교하기

## 이번에 할 일
가상 보급 요청 3건을 개선 전과 후에 같은 조건으로 처리해 비교합니다. 실제 기록으로 시간과 오류의 변화를 계산하고, 목표에 미달한 결과도 그대로 설명합니다.

**익힐 AI 활용:** AI로 계산을 검산하고 개선 효과와 비교 한계를 설명하는 방법

**준비 자료:** 미션4의 최초 실행 기록·미션8의 개선안 또는 미션9의 준비 경로에서 직접 만든 기준 기록·개선안. 두 실행의 요청·상태·역할 조건은 같게 유지합니다.

**완성할 것:** 재훈련 기록·전후 비교표·계산 근거·보수 교육 제안

**용어 도움:** 상대 감소율=(이전−이후)÷이전×100. %p는 두 비율의 단순 차이입니다.

**시작하기 전에:** 미션4·8을 수행했다면 그 최초 실행 기록과 개선안을 사용합니다. 수행하지 않았다면 이 미션 안에서 동일한 3요청의 기준 실행을 먼저 기록하고, 본인의 절차에서 개선할 부분을 정한 뒤 같은 조건으로 다시 실행합니다. 준비 방법은 제공 자료의 ‘기준 자료가 없는 경우’를 따릅니다. 선택 미션을 완료했다고 표시하거나 예시 숫자를 본인 성과로 복사하지 않습니다.


## 처음 시작하는 순서와 용어

미션 안내와 제공 자료를 읽은 뒤 학생용 Workbook의 미션9 작성란을 여세요. 이 미션의 빈 양식은 forms/LOG07_M09_forms.md이며, Workbook에 같은 항목이 준비되어 있습니다. 따로 같은 내용을 두 번 작성할 필요는 없습니다.

기준 실행은 개선하기 전의 첫 실행입니다. 두 실행은 요청·역할·시작과 끝·기록 수를 같게 두어야 비교할 수 있습니다. 상대 감소율은 이전 값에 비해 얼마나 줄었는지 나타내고, %p는 두 비율의 단순 차이입니다. 이전 값이 0이면 나눗셈으로 감소율을 만들지 않고 산출 불가로 적습니다.

- 활동1: 「동일 조건·수정버전」에 판단과 근거를 기록합니다.
- 활동2: 「실제 전후 요청시간·논리증빙15개」에 판단과 근거를 기록합니다.
- 활동3: 「계산·판정」에 판단과 근거를 기록합니다.
- 활동4: 「반복교육 제안」에 판단과 근거를 기록합니다.

AI 답변을 받으면 먼저 기록 번호와 원문 값을 찾고, 답변의 어느 부분을 채택하거나 고쳤는지 남기세요. 원문에 없으면 확인 불가로 표시하고 필요한 자료를 적습니다. 문서는 작성 내용 저장, 대화는 원문 저장으로 각각 보관합니다. HTML에서는 작성 JSON을 내려받습니다.

## 작성할 때 알아두세요
제공 자료를 읽고 내 생각을 먼저 짧게 적은 뒤 AI에 초안을 요청하세요. 표 전체의 초안을 한 번에 요청해도 됩니다. 같은 내용을 칸마다 AI에 다시 묻지 않아도 됩니다. 답변을 원자료와 비교해 고친 후 각 입력칸에 옮깁니다.

실제 대화는 아래 대화 기록란에 목적·실제로 보낸 요청 전체·실제로 받은 답변 전체를 한 묶음으로 저장합니다. 보완 대화는 새 묶음으로 추가하므로 파일명이 달라지는 것이 정상입니다. ‘실제 AI 사용·최종 결정’에는 원문 파일 위치와 본인의 채택·수정·보류 이유를 적습니다.

작성 내용 저장은 현재 미션 문서를 저장합니다. 대화 저장은 대화 원문을 별도로 저장합니다. 마지막 ‘진행 확인·내려받기’의 show_submission() 셀을 실행하면 ‘확인하고 ZIP 만들기’ 버튼이 나타납니다. 작성 중이면 ‘미완료 상태로 검토용 ZIP 저장’을 선택해 보관합니다.

한 번 작성한 내용은 저장해 두고 이어서 사용하세요. 이 미션에서 요구한 수행 내용과 판단 근거를 남기되, 아직 하지 않은 활동은 이유와 다음 할 일을 적습니다. 저장 성공과 과제 통과는 별개입니다.
