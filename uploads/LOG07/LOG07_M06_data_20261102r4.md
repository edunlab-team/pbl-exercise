### 자료 6-2 — 역할 연결 

- 실수령·검수 역할: 정하람 병장.
- 보급담당·확인·인계 역할: 김가온 하사.
- 상급 보고 수신 역할: 원본 대대 군수장교 이도윤 대위.
- 인수·가상 등록 역할: 대대 군수과.미션1~미션3처럼 승인자 역할 참여자가 등록 역할을 모의할 수 있으며 별도 직위·성명을 만들어 확정하지 않는다.
- 개인 실습에서는 학습자가 검수·등록 입력 판단·브리핑을 맡고 AI가 검토자·인수자 등을 모의한다.AI 역할의 확인은 사람의 확인과 구분한다.

### 자료 6-4 — 검수·등록·인계 기준 

1. 수령증과 표지 카드의 수량·상태를 대조하고 부족·훼손·유효기간 임박을 기록한다.
2. 총 확인 수량과 상태 이상이 있는 수량을 서로 다른 항목으로 적습니다. 상태 이상이 있다는 이유로 총 확인 수량을 임의로 줄이지 않습니다.
3. 수령증과 표지 카드의 값을 대조해 차이(확인 수량−수령증 수량)를 직접 계산합니다. 원 수령증은 보존하고, 차이의 실제 원인은 자료 없이 확정하지 않습니다.
4. D+20일 임박은 원본의 우선 사용 표시 조치로 연결한다.이는 교육용 재고 관리 표시이며 검수·보관·사용 적합성 확인을 생략하는 지시가 아니다.
5. A-101의 제공된 로트 A-2511-C를 유지한다.다른 품목에 같은 로트를 복사하지 않는다.
6. 가상 등록은 제시된 8개 필드를 **품목별 1행, 4행**으로 작성한다.정상 품목의 차이는 ‘0·수량 일치’, 후속 조치는 ‘해당 없음·확인된 추가 조치 없음’으로 적을 수 있다.빈칸을 정상 또는 0으로 추정하지 않는다.
7. 실제 등록 완료가 아니라 교육용 서식 입력이다.검수자·확인자 표기는 실제 수행·모의 역할과 연결하고 미확인 서명을 완료했다고 쓰지 않는다.
8. 이번 실습의 부족 보고 기준은 **대대 군수장교에게 당일 내 보고**다.실제 군 규정이 아닌 가상 기준으로 표시한다.

### 자료 6-5 — 필수 항목 누락률과 시간 측정 

- 등록 필드: 제시된 8항목 × 4품목 = 32필드.품목별로 필요한 내용이 실제 근거와 맞는지 확인한다.
- 누락률 = 누락/불충분 필드 수 ÷ 32 × 100.목표 0%는 32/32가 모두 유효하게 작성된 상태다.‘완료’처럼 대상·값을 알 수 없는 기입은 충족으로 세지 않는다.
- 등록표 외에도 **수량 차이·상태 이상·유효기간 임박 3개 핵심 사항**과 조치·담당·보고 기한이 브리핑에서 빠지지 않았는지 별도로 확인한다.32필드가 채워졌다고 이 인계 내용 누락을 허용하지 않는다.
- 인계 시간은 브리핑 시작→SBAR·자료 전달·필요 확인 질문 종료까지 **실제 경과 시간**이다.인수자 퀴즈는 인계 직후 별도로 실시하고 브리핑 10분 측정과 구분한다.
- D일 21:00은 가상 수령 시각이다.실제 인계 시간은 타이머·관측자 기록으로 남기며 AI 생성 시각으로 대체하지 않는다.
- AI 방식은 인수자 질문·응답을 기다리는 시간도 기록한다.장애나 응답 대기는 따로 표시하고 조별 방식과 동일 조건인 것처럼 비교하지 않는다.

### 자료 6-6 — 인수자 돌발 퀴즈 

1. 수량이 모자란 품목과 차이 수량은?
2. 봉인이 훼손된 품목은 어떻게 처리 중인가?
3. 유효기간이 임박한 품목과 우선 사용 조치는?
4. 전산 등록에 남은 후속 조치 번호는 무엇인가?
5. 차이 수량에 대해 누구에게 언제까지 보고해야 하는가?

**조별:** 인수자가 전달받은 브리핑·등록표를 참고해 답한다.교관은 정답과 대조한다.

**개인+AI:** 다른 대화에서 인수자 역할을 시작하는 방식을 권장한다.인계한 SBAR·등록표·필요 증빙만 주고 정답표·교관 해설은 주지 않는다.퀴즈 5개에 실제로 답하게 하고 학습자가 근거와 대조한다.같은 대화를 썼다면 이미 전체 자료를 본 조건을 명시한다.

AI 퀴즈는 전달 자료가 필요한 정보를 담았는지 보는 모의 검증이다.실제 사람의 이해·기억 향상이 검증됐다고 표현하지 않는다.


### 자료 6-7 — AI 인수자 역할 시작 방법

먼저 본인의 검수·등록표와 SBAR를 작성하고 검토합니다. 인수자 역할은 새 대화에서 시작하고 **본인이 실제 인계할 자료만** 제공합니다. 교관 해설·퀴즈 정답표는 넣지 않습니다.

> 교육용 보급 인수자 역할을 맡아주세요. 내가 전달할 SBAR·가상 등록표·근거 자료만 읽고 인수에 필요한 질문을 하세요. 없는 정보를 채우거나 정답을 추정하지 말고 질문해주세요. 설정을 확인하면 ‘인계 대기’라고 답하고 기다리세요. 인계 시작을 알린 뒤 내가 자료를 전달하겠습니다. 이후 퀴즈를 한 문항씩 보내면 전달받은 자료만 근거로 답해주세요. 교육용 인수 확인과 실제 시스템 등록 완료를 구분하고 실제 시간은 만들어내지 마세요.

인수자에게 전달하기 직전에 실제 타이머를 시작합니다. 자료 전달과 필요한 질문·답변이 끝난 때를 종료로 기록합니다. 퀴즈 5문항은 그 이후에 보내며 인계 10분에 포함하지 않습니다. 처음 받은 답을 보존하고, 틀린 답은 인계 자료의 누락인지 AI의 오독인지 구분합니다.
