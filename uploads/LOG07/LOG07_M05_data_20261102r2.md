**읽는 범위**

- 청구/승인은 각각 요청 수량·승인 수량이다. S08의 ‘8/6’은 청구 8, 승인 6이다.
- 수량은 원본 표의 값을 그대로 대조한다. 같은 세트 내 동일 단위의 수량으로 읽는 교육용 조건이며, 임의 환산을 하지 않는다. 요약표에 없는 단위·로트를 이미 확인한 것으로 쓰지 않는다.
- A-101은 탄약, F-201은 유류, R-301은 식량, M-401은 구급키트 코드다. 코드의 글자·숫자에 공식 의미를 새로 부여하지 않는다.
- 세트별 부대·인물 이름은 제공되지 않았다. 가람중대 보급담당자는 학습자 역할일 뿐, 12건의 실제 요청자·불출자·수령자를 김가온 등으로 새로 지정하지 않는다.
- S01 등은 증빙 세트 ID다. 미션1의 보조 AI 해석 문장 S1~S3과 다른 자료다.

### 자료 5-2 — 판정 범위와 원인 구분 

**‘정상’은 제공된 검증 필드에서 오류를 발견하지 못한 상태다.** 전체 업무의 완전한 정상·안전·등록 완료를 보증하지 않는다. 자료 5-1의 정상 세트에 유효기간·총재고·전산 완료 정보가 없다는 이유만으로 이번 오류 판정에서 오류로 분류하지 않는다. 더 확인할 자료는 별도 칸에 적는다.

**‘오류’는 제공 기록에서 확인되는 불일치·누락 또는 훈련 기준 위반이다.** 다음을 구분한다.

| 구분 | 작성할 내용 |
| --- | --- |
| 확인된 사실 | 대조할 필드·값·문구·역할과 그 차이 |
| 기록상 최초 이상 단계 | 처음 불일치가 드러나는 단계. 실제 원인 발생 단계로 단정하지 않음 |
| 가능한 원인 | 기재 오류·확인 누락·역할 겸임·실제 수량 차이 등 가설 |
| 추가 확인 | 원자료·변경 승인·담당 설명·재검수·기록 정정 이력 등 |
| 보고·현재 조치 | 오류 보완 요청 또는 상급 보고·추가 확인. 정상 완료 처리 보류 범위 |

S09의 불출자=수령자는 **이번 훈련의 직무 분리 기준**상 오류로 판정한다. 제공된 훈련 기준이며 실제 부대의 모든 겸임을 일률적으로 위법·유용으로 판정하는 규칙이 아니다.

### 자료 5-3 — 교차확인 우선순위·보고 경로 

학습자는 다음 틀을 미션2·미션3와 연결해 구체적인 규칙으로 작성한다.

1. 수량·승인 범위·봉인·인계 확인처럼 정상 처리 판단을 바꿀 신호를 먼저 확인한다.
2. 이상이 보이면 추가 확인 전 정상 완료로 확정하지 않고 관련 기록을 보존한다.
3. 작성 누락·시각 문제도 작성 담당과 승인 역할에 확인·보완을 요청한다. 처음부터 단순 실수로 확정하지 않는다.
4. 수량·승인 범위·직무 분리·봉인 신호는 상급 역할에 보고하고 관련 역할 교차 확인을 요청한다. 상급 보고는 유용 확정이 아니라 확인 수준을 높이는 조치다.
5. 실제 원자료나 담당 회신 없이 학습자 또는 AI가 서명·승인 시각·봉인번호를 임의 정정하지 않는다.

### 자료 5-4 — 교관 정답 공개·점수 규칙 

- 초기 판정과 AI 검토를 마친 **평가 제출본을 먼저 고정**한 뒤 정답을 공개한다.
- 정답 세트 1건은 정상/오류 구분이 맞고, 오류인 경우 해당 핵심 오류 유형도 맞은 판정을 뜻한다. 단순히 전부 ‘오류’로 적어 점수를 얻지 않는다.
- 식별 성공률 = 정답 세트 수 / 12 × 100. 85% 이상에 필요한 최소 정수는 **11세트**, 11/12 = 약 **91.7%**다. 10/12 = 약 83.3%로 미달이다.
- 최초 이상 단계·대조 근거·보고 경로는 점수와 별도로 모든 오류 세트에서 확인한다. 11세트만 맞았다고 필수 근거 누락이 자동 통과되지는 않는다.
- 정답 공개 뒤 수정한 학습 최종본은 평가 제출본과 구분한다. 최초 점수를 수정 후 성공률로 바꾸지 않는다.
- 오탐 = 정답 정상인데 오류로 분류. 미탐 = 정답 오류인데 정상으로 분류. 정상/오류는 맞았으나 핵심 유형을 틀린 경우는 유형 오판으로 별도 적는다.
