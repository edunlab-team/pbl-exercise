# QLT05 Colab 실행 안내

1. QLT05_student_20261104v1.ipynb를 Colab의 노트북 업로드로 엽니다.
2. 첫 준비 셀 업로드 창에서 QLT05_실습프로젝트_20261104v1.zip을 선택합니다. 출제자용 전체제작본 ZIP과 다릅니다.
3. ROOT=/content/QLT05_project를 확인하고 준비 셀을 실행합니다. 필요한 numpy/pandas/scipy/scikit-learn/matplotlib을 확인하고, 없을 때만 별도 설치 셀을 실행합니다.
4. 핵심 함수를 구현·저장한 뒤 미션별 실행 셀을 실행합니다. outputs/M번호/실행시각 아래 stdout·stderr·그림·결과표를 보존합니다. 오류는 stderr와 failure.json을 확인합니다.
5. AI 제안 수정 코드를 lesson에 적힌 src 또는 pipeline 파일에 저장한 뒤 같은 실행 셀을 다시 실행합니다. 실행마다 결과 폴더가 달라 기준 결과를 덮어쓰지 않습니다. 함수 저장 도구가 이전 파일을 .before 사본으로 보존합니다.
6. M7 직접 검토 셀에서 후보를 하나 고르고 본인이 가상 품질관 역할의 결정·근거를 입력합니다. AI가 대신 승인하면 안 됩니다. 무응답은 HOLD로 기록하고 재상정 기록을 남깁니다.
7. forms, docs, reports의 최종 본문·표를 저장합니다. 마지막 셀에서 uploads/QLT05.zip을 만들고 다운로드합니다. ZIP 생성은 목표 달성/교관 승인의 증거가 아닙니다.

원본 코드는 각각 가상 데이터를 만드는 독립 모듈입니다. 실행 도구가 한 순서로 실행해 결과를 모으지만 모든 모듈이 한 운영 DB를 공유하는 서비스는 아닙니다. M10은 독립 시간선에서 통합 모의 기능을 수행합니다.

검증은 로컬 Python 실행 기준입니다. 실제 Colab 서비스 검증과 CMS 저장·다운로드 검증은 별도로 기록합니다. M4/M5 등의 실행 시간은 플랫폼에 따라 달라집니다. M8 화면2초는 집계표 계산 범위이며 웹 렌더링을 측정한 것이 아닙니다.

준비 셀을 다시 실행해도 기존 실습 폴더를 덮어쓰지 않습니다. 새 실습을 시작하려면 먼저 기존 수정 코드·출력 ZIP을 내려받아 보관하고 폴더를 별도로 정리하세요.
