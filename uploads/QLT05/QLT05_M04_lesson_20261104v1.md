# QLT05 M04 — 텍스트 임베딩 및 토픽 모델링 기반 장비 구조적 품질 취약점 자동 군집화 모델 고도화

## 상황과 목표

가상 품질 분석 담당자로서 외주정비 검사 실적과 QDR를 분석합니다. 텍스트 임베딩(TF-IDF)과 토픽 모델링(NMF)으로 장비 구조적 품질 취약점을 자동 군집화하고, 부위별 월간 QDR 건수 기준 모델을 파생 피처로 고도화한다.

## 원본 수행 범위와 평가

- 원본 선택 미션. 전체 실습에서는 수행합니다.
- 원본 예상 시간 3시간〔실측값이 아님〕
- 원본 수행: 결함 서술의 핵심 문장을 TF-IDF로 벡터화하고 NMF 토픽 36개로 군집화해 부위·결함 라벨과의 일치도(NMI)를 확인한다. 토픽별 건수, Critical 비중, 설계 취약 비중으로 취약 군집을 순위화한다. 지연값, 훈련 강도, 계절, 직전 치명도·검사 대기 등 파생 피처 10개 이상으로 월간 건수 모델을 만들어 시계열 교차검증 MAPE를 평가하고 순열 중요도로 피처를 줄인다.
- [선택] 토픽 군집·파생 피처  — 파생 피처 10개 이상, 기준 모델 MAPE 25% 이하, 시계열 교차검증 적용, 피처 설계가 품질 실무에서 납득 가능한가.
- 원본 산출물: src/features/qlt05_feature_engineering.py, 기준 모델

## 이번 미션의 핵심 구현

- 파일: `src/features/qlt05_feature_engineering.py`
- 함수: `fit`
- 입력·출력 계약: d,cols → 학습된 회귀 모델. 제공 d의 월간 QDR 건수 n을 예측하며 시간 순서의 학습·검증 분리를 유지한다.
- 데이터 생성 함수 usage_index는 제공 코드입니다. 반복되는 생성 함수 빈칸 대신 위 핵심 함수를 구현합니다.
- 핵심 구현 후 첫 실행을 기준으로 보존하고, 추가 변경 과제를 수행해 전후를 비교합니다. AI 초안을 그대로 제출하지 말고 실제 대화·본인 검토·오류 수정 근거를 남깁니다.


## 학습 활동

### 활동1 — 계획과 사전 판단

원본 목표·기본 코드·자료를 읽고 토픽 모델 fit에는 어느 기간이 들어가는가?를 판단합니다. AI에 맡길 범위·자료·제약·확인 방법을 정합니다.

### 활동2 — AI와 코드 변경

핵심 함수를 구현하고 첫 실행 후 결과를 보존한 뒤 AI와 기획을 구현에 적용합니다. 변경 과제: 과거 구간에만 fit한 NMF 토픽 수36과24를 비교한다. NMI·군집 해석·시간 폴드 MAPE를 기록하고 피처 축소의 평가 재사용 한계를 확인한다.

### 활동3 — 근거 대조와 재실행

수정 코드를 저장하고 재실행합니다. 후반 평가 기간을 반복 사용하면 무엇이 달라지는가? AI 설명·코드 선택3건 이상을 자료·실행과 대조하고 보완 답변도 다시 확인합니다.

### 활동4 — 최종 판단과 산출물

원본 평가 기준·변경 전후·코드·실제 AI 대화·보고서를 제출합니다. 미달·미측정·실제 승인 상태를 구분합니다. 어휘·NMF·설계 취약 토픽·상위 대상 부위는 월0~17의 과거 자료로 고정했다. 군집 해석 표는 전체36개월의 사후 탐색이다. 이후 피처는 전월 관측을 쓰는 월별1단계 순차 평가이며6개월을 한 번에 예측하는 방식이 아니다. 후반 기간 순열 중요도와 그 기간 성능 재측정은 탐색용이다. 0건월 MAPE는 분모 max(건수,1)를 사용한다.
