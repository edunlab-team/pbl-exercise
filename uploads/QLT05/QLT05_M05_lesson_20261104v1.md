# QLT05 M05 — 결함 치명도(Critical/Major/Minor) 기반 종합 품질 취약성 지수 산출 엔진 개발

## 상황과 목표

가상 품질 분석 담당자로서 외주정비 검사 실적과 QDR를 분석합니다. 결함 치명도(Critical/Major/Minor)를 분류하고 치명도 가중 종합 품질 취약성 지수를 부위별로 산출·예측하는 엔진을 개발한다.

## 원본 수행 범위와 평가

- 원본 필수 미션. 전체 실습에서는 수행합니다.
- 원본 예상 시간 3.5시간〔실측값이 아님〕
- 원본 수행: 키워드 규칙과 TF-IDF 로지스틱 회귀의 치명도 분류 정확도와 Critical 재현율을 비교하고 신뢰도 구간별 실제 정확도를 점검한다. 치명도 가중(1, 3, 9) 월간 부위별 취약성 지수를 릿지 중심 모델과 부스팅·랜덤 포레스트 잔차 보정 후보로 예측하며, 확장 윈도 내부 검증으로 선택해 학습 기간 평균 기준 모델과 Hold-out에서 MAE, RMSE, R2를 비교한다.
- [필수] 취약성 지수 엔진  — 기준 모델 대비 MAE/RMSE 20% 이상 개선, R2 0.85 이상, 불규칙한 월별 변동에서도 예측이 안정적인가.
- 원본 산출물: src/models/qlt05_advanced_model.py

### 활동4 — 최종 판단과 산출물
