# QLT05 M03 — 빈도 분석 기반 1차 다발 결함 부품 도출 Baseline 알고리즘 구현

## 상황과 목표

가상 품질 분석 담당자로서 외주정비 검사 실적과 QDR를 분석합니다. 빈도 분석 기반 1차 다발 결함 부위 도출 Baseline을 구현하고, 탐색적 분석으로 빈도 기준의 한계와 외주정비 검사 병목, 핵심 관리 대상을 찾는다.

## 원본 수행 범위와 평가

- 원본 필수 미션. 전체 실습에서는 수행합니다.
- 원본 예상 시간 2.5시간〔실측값이 아님〕
- 원본 수행: 학습 기간 건수 상위 5개 부위를 다발 결함 부위로 지정해 검증 기간 적중률과 치명도 가중 지수 순위와의 차이를 확인한다. 월간 QDR 건수와 훈련 강도, 검사 대기일 등 피처의 스피어만 상관계수·p-value를 계산하고 업체별 검사 대기·재검사율·정비 품질 원인 비중을 비교하며 EDA 차트 8종 이상을 그린다. 조치 비용 파레토(ABC) 분석으로 상위 20% 부위를 식별한다.
- [필수] 빈도 Baseline·EDA  — EDA 차트 8종 이상, 유의한 상관 피처 5개 이상(p<0.05), 파레토 상위 20% 부위 식별, 외주 병목 등 핵심 발견점이 품질 의사결정에 직관적인가.
- 원본 산출물: notebooks/qlt05_eda_analysis.ipynb, EDA 요약 리포트

## 학습 활동

### 활동1 — 계획과 사전 판단

원본 목표·기본 코드·자료를 읽고 빈도보다 치명도가 중요한 부위는 어디인가?를 판단합니다. AI에 맡길 범위·자료·제약·확인 방법을 정합니다.

### 활동2 — AI와 코드 변경

핵심 함수를 구현하고 첫 실행 후 결과를 보존한 뒤 AI와 기획을 구현에 적용합니다. 변경 과제: 빈도 Baseline 상위 부위 수5와3을 비교한다. 검증 기간 적중률과 Critical 누락 비중의 분모를 정하고 빈도·치명도 순위의 차이를 설명한다.

### 활동3 — 근거 대조와 재실행

수정 코드를 저장하고 재실행합니다. 상관계수로 책임을 확정할 수 있는가? AI 설명·코드 선택3건 이상을 자료·실행과 대조하고 보완 답변도 다시 확인합니다.

### 활동4 — 최종 판단과 산출물

원본 평가 기준·변경 전후·코드·실제 AI 대화·보고서를 제출합니다. 미달·미측정·실제 승인 상태를 구분합니다. p<0.05는 상관 탐색이며 결함이나 업체 책임의 인과 증명이 아니다. 파레토 상위20%는12부위 중 반올림 규칙을 확인한다. 빈도 상위5가 치명도 상위5와 다를 수 있다. 검증 라벨은 평가에만 사용하고 순위 선정은 학습 기간에서 고정한다.
