# QLT05 M06 — 야전 QDR 발생 현황 및 장비 부위별 결함 집중도 히트맵 대시보드 구현

## 상황과 목표

가상 품질 분석 담당자로서 외주정비 검사 실적과 QDR를 분석합니다. 야전 QDR 발생 현황과 부위별 결함 집중도를 히트맵·경보로 구성하고, 예측 건마다 기여도 상위 3개 인자와 자연어 요약을 자동 산출하는 설명가능성(XAI) 모듈을 구현한다.

## 원본 수행 범위와 평가

- 원본 선택 미션. 전체 실습에서는 수행합니다.
- 원본 예상 시간 3시간〔실측값이 아님〕
- 원본 수행: 치명도 분류 모델의 서술 단어·부위·결함 유형 기여도를 계산해 건마다 상위 3개 근거를 뽑고, 1순위 근거를 제거했을 때 확률이 내려가는지로 유효성을 점검한다. 점검 카드(부위, 결함, 치명도, 근거 문장)와 최근 6개월 부위별 히트맵, 월평균 대비 집중도 경보를 출력한다.
- [선택] 발생 현황·설명가능성  — 예측 건당 기여도 상위 3개 인자 자동 산출률 100%, 군수 장교와 군무원이 신뢰하고 조치할 수 있도록 근거와 현황이 명확한가.
- 원본 산출물: src/explainability/qlt05_xai_explainer.py, XAI 리포트

## 학습 활동

### 활동1 — 계획과 사전 판단

원본 목표·기본 코드·자료를 읽고 상위3개 인자는 모델이 참고한 단서인가 원인인가?를 판단합니다. AI에 맡길 범위·자료·제약·확인 방법을 정합니다.

### 활동2 — AI와 코드 변경

핵심 함수를 구현하고 첫 실행 후 결과를 보존한 뒤 AI와 기획을 구현에 적용합니다. 변경 과제: 집중도 경보 배수1.4와1.8을 비교한다. 상위3개 근거를 추출한 예측 수와 유효성 점검 표본 수를 구분하고 점검 카드의 과도한 확신 표현을 수정한다.

### 활동3 — 근거 대조와 재실행

수정 코드를 저장하고 재실행합니다. 신뢰도 높은 오분류를 어떻게 확인할까? AI 설명·코드 선택3건 이상을 자료·실행과 대조하고 보완 답변도 다시 확인합니다.

### 활동4 — 최종 판단과 산출물

원본 평가 기준·변경 전후·코드·실제 AI 대화·보고서를 제출합니다. 미달·미측정·실제 승인 상태를 구분합니다. 근거는 TF-IDF 특성값×예측 클래스 계수이며 인과 효과나 SHAP은 아니다. 인자 제거 후 확률 감소는 제한된 모델 반응 점검이다. 원본은 서술 단어+부위+결함 특성을 설명하며 히트맵은 정적 결과다. 인터랙티브 웹 서비스 완료로 쓰지 않는다. 신뢰도가 낮은 결과와 잘못 분류한 Critical을 검토 대상으로 남긴다.
