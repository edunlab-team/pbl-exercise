# QLT05 M08 — 10년치 대용량 야전 QDR 텍스트 데이터 일괄 분석 스트레스 테스트

## 상황과 목표

가상 품질 분석 담당자로서 외주정비 검사 실적과 QDR를 분석합니다. 10년(120개월)치 대용량 야전 QDR 텍스트를 일괄 분석하는 스트레스 시험을 수행해 처리 시간, 화면 구성 시간, 경보 정확도를 확인한다.

## 원본 수행 범위와 평가

- 원본 선택 미션. 전체 실습에서는 수행합니다.
- 원본 예상 시간 3시간〔실측값이 아님〕
- 원본 수행: 가상 QDR 약 6만 건에 빈 서술, 인코딩 깨짐, 과대 길이 레코드를 섞어 1~10년 단위로 주입해 격리·유실 건수와 분석 시간을 센다. 정규화·라벨링·월별 집계 후 훈련 강도로 보정한 급증 경보의 정확도·재현율·정밀도를 이벤트 기준으로 계산하고, 집계표에서 대시보드 화면을 구성하는 시간과 필터 응답 시간을 잰다.
- [선택] 대용량 일괄 분석  — 대시보드 화면 구성 2초 이내, 경보 발령 정확도 95% 이상, 불량 레코드 격리와 유실 0건이 확인되었는가.
- 원본 산출물: src/dashboard/qlt05_app.py(Streamlit/Dash 구성은 스트레스 시험 결과로 대체), 스트레스 시험 결과표
