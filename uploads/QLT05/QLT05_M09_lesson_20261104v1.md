# QLT05 M09 — AAR 기반 결함 원인 오분류 분석 및 텍스트 마이닝 룰셋 재튜닝

## 상황과 목표

가상 품질 분석 담당자로서 외주정비 검사 실적과 QDR를 분석합니다. AAR 기반으로 결함 원인 오분류 사례를 분석하고 텍스트 마이닝 룰셋을 보조 규칙으로 재튜닝해 효과를 지표로 산출한다.

## 원본 수행 범위와 평가

- 원본 필수 미션. 전체 실습에서는 수행합니다.
- 원본 예상 시간 3시간〔실측값이 아님〕
- 원본 수행: AAR 기간 원인 분류 오류를 원인 단서 없음과 단서-실제 원인 불일치로 나누고 대표 사례를 정리한다. 미상으로 남은 건에 외주 정비 후 경과일·업체·결함 유형을 쓰는 결정 트리 보조 규칙을 AAR 기간에서 학습하고 확신이 낮으면 미상으로 남긴다. 검증 기간에서 정확도와 재현율을 비교하고 비용 절감, 확인 시간 단축, 제조·정비 책임 건 식별 증가의 3대 지표를 가정 단가로 계산해 로드맵을 정리한다.
- [필수] AAR·룰셋 재튜닝  — 비용 절감액, 시간 단축률 등 3대 정량 효과 지표 산출, 검증 기간 정확도 개선, 추정 산식이 객관적이고 기획 부서를 설득할 수 있는가.
- 원본 산출물: reports/qlt05_roi_analysis.md
