# QLT05 M01 — 야전 장비 품질결함보고(QDR, Quality Deficiency Report) 데이터 스키마 분석

## 상황과 목표

가상 품질 분석 담당자로서 외주정비 검사 실적과 QDR를 분석합니다. 야전 장비 품질결함보고(QDR)의 보고 정보, 결함 서술 텍스트, 외주정비·검사 실적, 조치 결과 데이터 스키마와 데이터 딕셔너리, 결함 분석 업무 프로세스 맵을 정의한다.

## 원본 수행 범위와 평가

- 원본 필수 미션. 전체 실습에서는 수행합니다.
- 원본 예상 시간 1.5시간〔실측값이 아님〕
- 원본 수행: 결함 발견부터 QDR 작성, 접수·검토, 검사·판정, 원인 분석, 조치, 실적 집계, 다발 결함 식별, 사후검토까지 업무 흐름을 단계별로 정리하고 보고·텍스트·검사·결과 묶음으로 피처 20개 이상을 정의한다. 예측 대상(원인 구분, 조치 비용, 월간 건수, 취약성 지수)을 명확히 하고 장비 식별코드·보급 분류군은 국방 표준 코드 형식을 모사한 가상 코드로 둔다. 가상 QDR 표본을 검증기로 점검하고 오류를 일부러 넣어 검출되는지 확인한다.
- [필수] QDR 데이터 정의  — 업무 프로세스 맵 작성 완료, 피처 20개 이상 정의, 정상 표본 검증 오류 0건, 군수 실무 프로세스와 일치하고 분석 목표가 명확한가.
- 원본 산출물: docs/qlt05_logistics_domain_spec.md, 데이터 딕셔너리
