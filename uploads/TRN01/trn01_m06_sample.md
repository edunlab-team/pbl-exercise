# TRN01_M06 실습 및 검증 가이드
## 조종자 비행 궤적 3D 재생 및 취약 구간 하이라이트 분석 대시보드 구현

### 1. 미션 개요 및 학습 목표
수치 점수와 등급만으로는 조종자가 어느 비행 구간에서 어떤 조작 실수를 반복하는지 직관적으로 파악하기 어렵다. 본 미션에서는 경로 이탈 3m 초과, 자세 30도 초과, 급조작 구간을 3D 궤적 위에 강조 표시하고, 단계별 오차 추이·스틱 입력·동료 대비 약점 프로필을 통합 제공하는 분석 대시보드(trn01_dashboard.py)를 구현한다. 야간 모드 가독성과 1초 단위 재생 갱신 성능을 확인하고, 시각화 결과를 근거로 조종자 피드백 포인트를 도출한다.

**학습 목표:**
복잡한 시계열 수치와 모델 판정 결과를 교관과 조종자가 직관적으로 해석하고 훈련 피드백으로 연결할 수 있는 3D·다중 지표 시각화 설계 역량을 익힌다. 경로 이탈 3m 초과·자세 30도 초과·급조작 취약 구간을 3D 궤적에 매핑하고 단계별 오차·스틱 입력·동료 대비 약점 프로필을 통합 구성하는 방법과, 실시간성(1초 갱신) 및 야간 시인성을 고려한 분석 UI 구현 원칙을 습득한다.

- **소요 시간**: 2.5시간
- **필수 산출물**: src/ui/trn01_dashboard.py (또는 웹 UI 컴포넌트) (필수)

### 2. 가상 데이터셋 및 보안·HITL 유의사항
- **참조 데이터셋**: `trn01_m06_dataset.json`
- **실습 노트북**: `TRN01_student.ipynb` / `TRN01_solution.ipynb`
- **보안 및 HITL 원칙**: 모든 비행로그·조종자(P001~)·점수는 교육용 가상 자료이며, AI 분석 결과는 참고 지표일 뿐 최종 등급·재교육 결정은 교관이 근거를 기록해 확정합니다.
