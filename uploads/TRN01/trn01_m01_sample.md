# TRN01_M01 실습 및 검증 가이드
## 드론 조종 시뮬레이터 비행로그(스틱 조작, 자세각, 고도 유지, 경로 오차) 데이터 스키마 정의

### 1. 미션 개요 및 학습 목표
드론 시뮬레이터 비행로그는 조종자 메타데이터, 전술 환경 변수, 시계열 조작 기록이 함께 들어오기 때문에, 분석 전에 잘못된 형식이나 보안 위반 데이터를 걸러내는 기준이 필수적이다. 본 미션에서는 가명 조종자 ID(P001~), 비행 조건·풍속·GPS 오차 등 전술 파라미터, 스틱·자세·고도·경로 레코드의 스키마와 허용 범위를 정의하고 자동 검증기를 구현한다. 정상 세션 20건과 오류 주입 5종을 모두 판별한 뒤 데이터 스키마(trn01_input_schema.json)와 명세서(trn01_data_spec.md)로 정리한다.

**학습 목표:**
시계열 비행로그 분석 전 단계에서 데이터 무결성과 보안 규정을 코드 수준으로 강제하는 스키마 설계 및 유효성 검증 역량을 익힌다. 세션 메타데이터(가명 ID, 코스, 기록 주기), 전술 파라미터(비행 조건, 풍속, GPS 오차, 영상 지연), 스틱·자세·고도·경로 레코드의 자료형과 허용 범위를 JSON 스키마로 정의하는 방법을 습득하고, 정상 세션 20건과 5종 오류(실명형 ID·미허용 조건·누락·범위 초과·시각 중복) 주입 테스트를 통해 경계값 검증과 명세 문서화 기준을 체득한다.

- **소요 시간**: 1.5시간
- **필수 산출물**: data/schema/trn01_input_schema.json (필수), docs/trn01_data_spec.md (필수)

### 2. 가상 데이터셋 및 보안·HITL 유의사항
- **참조 데이터셋**: `trn01_m01_dataset.json`
- **실습 노트북**: `TRN01_student.ipynb` / `TRN01_solution.ipynb`
- **보안 및 HITL 원칙**: 모든 비행로그·조종자(P001~)·점수는 교육용 가상 자료이며, AI 분석 결과는 참고 지표일 뿐 최종 등급·재교육 결정은 교관이 근거를 기록해 확정합니다.
