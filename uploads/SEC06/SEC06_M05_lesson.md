# SEC06 M05 — 가상 배치 시나리오 기반 기만체/차폐 효과 분석 기록서 작성 실습

## 미션 상황

당신은 가상 제3시설방호중대의 기록 분석 책임 역할입니다. 가상 배치 시나리오의 효과 기록을 분석해 효과 확인 승인·보류의 분기점과 책임 직책을 확정하고, 보호 표지·민간 시설 관련 금지 사항을 지침에 반영한다.

- 원본·새 Git 편성 3시간〔실측값이 아님〕
- 최종 산출물: `sop/sec06_approval_thresholds_sop.md`
- 공통 작성 안내와 AI 역할 안내를 먼저 읽습니다.

## 이번 미션 운영 보완〔출제자 추가 설명〕

의사결정 트리 5단계에 맞춰 책임표를 5칸으로 확장했습니다. 단계 1의 ‘G3 이상’은 G1·G2·G3이라고 명시합니다. 해당 단계 충족도 자동 승인을 뜻하지 않습니다. 비교 조건 미해결·필수 재확인 누락·표지 쟁점이면 보류/검토 연계를 남깁니다. 모든 승인 검토 경로는 마지막 권한 확인과 사람 역할의 직접 결정이 필요합니다. 효과 확인 주장에 대한 가상 승인이며 실제 방호·교전·배치 승인과 다릅니다. 긴급 상황에도 확인 단계는 생략하지 않습니다.

## 학습 활동

### 활동 1 — 기준·권한·경계선을 먼저 읽는다

M2~M4의 버전과B1~B5,미확인 재확인/권한/법무 상태를 적는다.

### 활동 2 — AI와 5단계트리·책임표를 만든다

G1~G3명시·교차확인·반박·검토연계·사람 권한의5단계를 연결한다.

### 활동 3 — 경계선5건과승인 우회를 검토한다

본인이주판정·병행확인요청·근거를 직접 기록하고AI 분기설명을 대조한다. 미해결 항목에서자동 승인되지 않는지 확인한다.

### 활동 4 — 직접 결정·긴급규칙을 저장한다

B1~B5와5단계책임·사람 결정·긴급확인 유지·검토대기를 M6·M9·M10에 전달한다.
