# SEC06 Student Notebook 실행 안내

1. 프로젝트 개요 참고자료의 SEC06_student_20261104v1.ipynb를 Colab의 파일 → 노트북 업로드로 엽니다. 인터넷과 기관 허용이 필요합니다.
2. 준비 셀을 실행합니다. 실습자료가 내장되어 ZIP 업로드나 코드 수정은 필요하지 않습니다. 긴 준비 코드는 기본 숨김입니다.
3. 미션 셀을 실행하고 진행 안내를 펼칩니다. 작성란에 직접 판단·근거·검토 결과를 입력하고 작성 내용 저장을 누릅니다. 다시 실행하면 저장본을 읽습니다.
4. 허용된 AI에서 실제 대화를 진행한 뒤 목적·요청 원문·답변 원문을 각각 입력하고 이 대화 저장을 누릅니다. 초안과 보완 대화는 따로 저장합니다. 지금 시각 기록은 실제 이벤트에만 사용합니다.
5. M7은 카드 도구 내려받기 버튼으로 HTML을 받아 브라우저에서 엽니다. 현재 카드만 AI에 제공하고 응답·공개 로그를 내려받아 실습 폴더 evidence/M07에 별도 보관합니다. 카드별 측정값은 없어 효과 소멸 지점은 판정 불가입니다.
6. 종료 전에 작성 JSON과 검토용 ZIP을 내려받습니다. 새 런타임에서는 작성 JSON 가져오기를 사용합니다. 기존 기록은 복원 전 별도 보존합니다. 카드 로그·외부 발표 파일 등 JSON에 포함되지 않는 증거는 ZIP과 함께 별도 보관하고 새 실습 폴더의 같은 위치로 복원합니다.
7. 전체 사이클 문서 10개와 실제 AI 원문이 갖춰졌을 때만 검토용 체크를 해제해 제출용 ZIP을 만듭니다. 파일 검사와 학습 PASS·교관 승인은 별도입니다. 실제 Colab 화면·폐쇄망·학생 사용성은 별도 검수 대상입니다.
