- 원본·새 Git 편성 2.5시간〔실측값이 아님〕

- 공통 작성 안내와 AI 역할 안내를 먼저 읽습니다.

## 이번 미션 운영 보완〔출제자 추가 설명〕

메모의 사실은 ‘그러한 보고/측정이 기록되어 있음’으로 한정하고 실제 효과까지 확정하지 않습니다. M-1의 보수 지시는 완료 기록이 아닙니다. M-2의 위치 이동은 예정이고 새 위치·이동 완료를 만들지 않습니다. M-3의 배치 유지 문장은 계획/판단이므로 실제 승인·시행 완료로 바꾸지 않습니다. 모의 공격 횟수 차이 미확인을 숨기지 않습니다. 원본‘인접 간격(기준)확보’예시는 제공되지 않은 기준이므로 구체 값을 만들지 않고 근거 확인 필요로 표시합니다.

### 활동 1 — 메모3건을 직접 분리한다

M-1~M-3에서확인 사실·판단·조치 상태·미확인을 표시한다.
