## 파일을 열고 시작하기
프로젝트 개요의 참고자료에서 SEC06_student_20261104v1.ipynb를 내려받습니다. Colab의 파일 → 노트북 업로드로 연 뒤 준비 셀부터 실행하세요. 자료가 내장되어 실습 ZIP을 따로 올리거나 RESULT 코드의 주석을 고치지 않습니다. 미션 셀을 실행하면 안내 펼치기와 빈 작성란이 나타납니다. 별도 폴더가 필요할 때만 SEC06_실습프로젝트_20261104v1.zip을 풀어 materials의 안내·자료와 forms의 양식을 확인합니다. 기존 작업본은 먼저 ZIP으로 보관하고 같은 결과를 두 곳에 동시에 작성하지 마세요.

## AI에게 질문하고 답변 고치기
기관이 허용한 AI에서 해당 미션의 가상 기록·본인 질문·원하는 결과 형식을 제공합니다. AI 역할 안내와 미션별 요청 예시를 참고하세요. 먼저 본인이 읽고 판단한 내용을 적고, AI 주장 3건 이상을 원자료·계산과 대조해 유지·수정·보류 이유를 남깁니다. 초안·보완·모의 역할 대화의 실제 요청과 답변은 목적과 함께 대화 저장란에 각각 보존합니다. 교관 해설·실제 군사정보·개인정보·미래 카드는 제공하지 않습니다.

## 어디에 쓰고 저장하나요?
같은 미션의 작성란에 판단·근거·검토·최종 선택을 적고 '작성 내용 저장'을 누릅니다. 해당 미션의 최종 경로와 작성 양식 두 경로에 같은 내용을 저장하며 이전 문서는 work_history에 남깁니다. 미션 셀을 다시 실행하면 저장본을 읽습니다. '작성 JSON 내려받기'와 '작성 JSON 가져오기'로 기록을 백업·복원합니다. 복원 전 기존 기록도 보존합니다. 런타임이 종료되기 전에 JSON과 검토용 ZIP을 본인 저장장치로 내려받으세요. 작성 중에는 검토용, 원본 전체 사이클의 문서와 실제 AI 원문이 갖춰지면 제출용 ZIP을 만듭니다. 파일 존재 검사는 내용 채점·학습 PASS·교관 승인이 아닙니다.

## 폐쇄망에서는 어떻게 하나요?
Google Colab과 외부 AI는 인터넷 접속과 기관 허용이 필요합니다. 폐쇄망에서 외부 AI가 실행된다고 가정하지 않습니다. 허용된 로컬 Jupyter에서 Python·IPython·ipywidgets가 미리 준비된 경우 Notebook의 작성 도구를 사용할 수 있습니다. 그렇지 않으면 실습 ZIP의 Markdown 양식을 로컬 편집기로 작성하고 폴더 전체를 백업하세요. M7 순서형 카드 HTML은 브라우저에서 열어 현재 카드에 응답하고 로그를 내려받습니다. 외부 AI 활용·실제 평가가 불가하면 미실시로 기록합니다. 실제 폐쇄망·Colab 사용성은 별도 확인 대상입니다.
