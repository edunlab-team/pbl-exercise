# QLT03 처음 시작 안내

[교육용가상자료] 실제 조직·장비·사진·정비 자료를 입력하지 않습니다.

## 파일 열기

학습자 배포 ZIP의 01_학습자자료 최상위에서 `QLT03_assignment.ipynb`를 엽니다. ZIP의 `01_학습자자료/`가 실행 루트입니다. 아래 docs·reports·src 경로는 실행 루트 기준입니다.

교육장 Jupyter에서 노트북을 열면 환경 준비 셀이 기본 환경 목록·기록 양식·수정 코드·앱과 이 안내를 만듭니다. 파일 → 다른 이름으로 저장으로 사본을 만들고 위에서 아래로 진행하세요. 환경이 준비되지 않았으면 운영 담당자에게 확인합니다.

## 실행 순서

노트북 열기 → 환경 준비 셀 실행 → 미션 코드 저장 → 실행·확인 순서입니다.

1. 환경 준비 셀을 실행합니다. `requirements.txt`와 `requirements-dashboard.txt`가 준비되며 기존 파일은 덮어쓰지 않습니다. 준비된 환경에서는 설치하지 않습니다.
2. 해당 미션의 백업 셀 → 코드 저장 셀 → 실행·확인 셀을 순서대로 실행합니다. `%%writefile`은 코드 저장 명령입니다. 코드 저장 셀은 덮어쓸 수 있으므로 바로 앞 백업 셀을 함께 실행합니다.
3. 출력 로그의 지표·단위·분모와 그림을 읽고 `reports/mNN_record.md`에 관찰값을 적습니다. 도전은 `work/mNN_challenge.py`에서 변경 조건과 전후 결과·해석을 기록합니다. 결과가 같거나 나빠져도 적용 증거와 이유를 설명합니다.
4. 최종 파일은 `docs/원문_제출경로_연결표.md`에서 확인합니다. 원문 이름의 Python 사본은 비교용이며 현재 수정 실습·도전 코드 경로를 기록지에 연결합니다. 원문을 덮어쓰지 않습니다.

READY는 도전 코드 수정·저장을 마쳤음을 학습자가 표시하는 값입니다. 수정·저장 후 도전 실행 셀의 READY=False를 READY=True로 바꾸세요. 기본 실행 확인 PASS는 도전·해석·원문 산출물 작성 완료를 뜻하지 않습니다. 오류가 나면 첫 오류 메시지와 입력 조건을 그대로 기록하고 원인과 수정 내용을 남깁니다.

## 미션 8 웹앱과 제한 환경

환경 준비 셀이 `src/dashboard/qlt03_app.py`를 생성합니다. 미션 8 코드 저장 셀로 시뮬레이터를 저장한 뒤 준비된 환경에서 `python -m streamlit run src/dashboard/qlt03_app.py`를 실행합니다. 앱의 실행 버튼·필터를 사용해 표·그래프·로그와 해석을 기록합니다. 설치나 웹앱 실행이 제한되면 노트북 미션 8 시뮬레이터를 동등한 대체 경로로 사용합니다. `docs/M08_웹앱과_대체경로.md`를 읽으세요.

## 기록 보존과 이어 하기

종료 전에 수정한 노트북과 reports·직접 작성한 docs·work·outputs를 원래 폴더 구조대로 저장합니다. 노트북 사본 저장과 작업 환경 파일 보존은 별개입니다. `docs/저장과_새런타임_복원.md`에 따라 복원한 뒤 준비 셀을 재실행합니다. 준비 셀은 이미 존재하는 문서·코드·기록을 건너뜁니다. 저장이 제한되면 화면을 닫기 전에 담당자에게 허용된 기록 보존 경로를 확인하세요.

## 개념과 시간

미션 3~미션 5 전에 `docs/핵심지표_한장.md`에서 지표의 뜻·분모·좋아지는 방향과 계산 예시를 읽으세요. 용어·오류 메시지·수정 후보를 AI에 질문할 수 있지만 코드와 실제 출력의 대조·최종 판단은 직접 합니다.

원문 계획은 28.5시간, 화면 표시 시간는 28시간입니다. 초보자는 약 1.3~1.7배를 준비 계획용 추정 범위로 참고합니다. 학습자 실측 시간이 아닙니다. 선택 미션 4·미션 6·미션 8은 산출물과 Q1·Q2·Q3 모두 가점/참고이며 최종 PASS에서 제외합니다. 필수 7미션 21문항을 평가합니다.

[실습 준비·보안·제출 안내](실습준비와_제출안내.md)를 확인하세요.

종료 전 허용된 저장 위치에 저장하고 다시 열어 확인한 뒤 사용한 교육장 계정에서 로그아웃합니다. 공용 PC에 비밀번호를 저장하지 않으며 로컬 사본은 조직 규정에 따라 정리합니다.
