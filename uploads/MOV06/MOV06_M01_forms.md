# MOV06 M01 작성 양식 — 군수 수송선단 GPS 위치, 화물 센서, 통신 상태 텔레메트리 데이터셋 정의

원본 평가: [필수] 프로세스 맵·피처 정의  — 업무 프로세스 맵이 작성되고 예측·추적 피처 후보가 20개 이상 정의되며, 데이터 사전과 실제 데이터 컬럼의 누락이 0건이고 주입 오류 6종이 모두 검출되는가. 실무 납품 업무 흐름과의 일치성과 분석 목표의 명확성이 설명되는가.
