## 지금 해결할 문제
위치·속도·센서 기록의 형식이 서로 다르면 선단의 도착 시각을 함께 계산하기 어렵습니다. 먼저 어떤 항목을 언제 받는지 정하고 오류를 찾아냅니다.

여러분은 교육용 가상 물류 데이터 분석 담당자입니다. 실제 부대 위치를 추적하거나 수송을 지시하는 활동은 아닙니다.

텔레메트리는 장비가 보내는 위치·상태 관측 기록입니다. 스키마는 항목과 자료형의 약속, 피처는 분석에 쓰는 입력 항목, sentinel은 센서 오류를 표시하는 특별한 값입니다.

## 완료 전 확인
사전과 실제 컬럼의 누락 0건, 피처 후보 20개 이상, 주입 오류 6종 검출을 확인합니다. 37개 필드·31개 후보·21개 모델 입력의 범위를 구분합니다.

데이터 사전은 37개 필드이고, 예측·추적 피처 후보는 31개입니다.

후보 수와 최종 모델 입력 21개는 다릅니다.

s_true / off_true / stopped_true / stop_cause / eta_true는 합성 정답이며 예측 입력에 넣지 않습니다.

좌표는 km 단위의 가상 평면 좌표입니다.
