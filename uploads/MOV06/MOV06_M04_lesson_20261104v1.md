# MOV06 M04 — 도로 상태, 기상, 적 위협 정체 변수를 반영한 머신러닝 기반 정밀 ETA 예측 모델 고도화


## 지금 해결할 문제
단순 ETA를 도로·기상·정차 이력으로 보완합니다. 아직 도착하지 않은 이동의 미래 관측을 학습에 섞으면 실전보다 성능이 좋아 보일 수 있으므로 자료 시점을 함께 확인합니다.

여러분은 교육용 가상 물류 데이터 분석 담당자입니다. 실제 부대 위치를 추적하거나 수송을 지시하는 활동은 아닙니다.

시계열 교차검증은 과거로 학습하고 뒤 시점으로 검증하는 방법입니다. Ridge는 규제를 둔 회귀 모델, GBR는 여러 작은 예측 모델을 순서대로 결합하는 방법입니다. 순열 중요도는 입력을 섞었을 때 성능이 얼마나 변하는지 보는 지표입니다.

함수를 구현·저장하고 첫 실행을 보존하세요. 다음 변경을 적용해 같은 조건으로 다시 실행합니다: 동일한 이동 단위 시간 폴드에서 Ridge와 GBR를 비교한다. 변수군 제거 실험과 미래 관측 변조 시험으로 피처의 인과적 생성 시점을 검증한다.

파생 피처 10개 이상과 시계열 교차검증 평균 MAPE 25% 이하를 원본 조건으로 확인합니다. 이동 단위 분리와 피처를 알 수 있는 시점을 함께 기록합니다.

남은 노선 구성·우천·시간대 계수는 모의 상황에서 알려진 정보입니다.
