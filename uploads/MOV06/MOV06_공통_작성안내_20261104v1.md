# MOV06 공통 작성 안내

## 처음 시작할 때
프로젝트 개요의 최신 학생용 Notebook과 실습 ZIP을 내려받습니다. Notebook의 준비 셀에 ZIP 하나를 선택하고 MOV06_project 경로를 확인하세요. 같은 번호 미션의 학습 안내를 읽고 forms의 빈 양식과 docs·reports의 시작 문서를 작성합니다. 핵심 함수는 구현할 빈칸입니다.

## AI와 구현하고 확인하기
제공된 가상 자료·입출력 계약·평가 조건과 원하는 형식을 함께 질문합니다. 함수 이름·인자·기본값은 유지하고 함수 전체를 저장 셀의 implementation 문자열에 넣습니다. 첫 실행의 코드·로그·그림을 보존한 뒤 추가 변경과 재실행을 진행하세요. 실제 AI 설명이나 코드 선택 3건 이상을 자료·실행값·테스트로 대조하고 유지·수정·보류 이유를 기록합니다. AI 대화 원문은 별도 파일로 저장하고 양식에 경로를 적습니다.

## 자료와 수행 범위
모든 위치·선단·화물·단가·역할은 가상입니다. 실제 군사정보·개인정보를 입력하지 마세요. 좌표는 km 평면 좌표이며 모의 정답 라벨은 평가에만 사용합니다. 각 모듈은 가상 자료를 독립 생성하므로 앞 미션의 결과가 자동 연결되는 운영 서비스는 아닙니다. 앞서 확인한 가정·성능 해석·판단을 다음 보고서에 연결합니다. 인과 보정 예시는 최소 보조 코드이며 M2 정제 규칙 10종의 완성 답안을 대신하지 않습니다.

원본 필수는 M1·M2·M3·M5·M7·M9·M10, 선택은 M4·M6·M8입니다. 원본 예상 합계 28.5시간과 CMS 편성 합계 31시간은 실제 소요시간과 구분합니다. 미션별 편성·평가 수치는 CMS 원본을 따릅니다.

## 저장·이어쓰기·제출
코드 저장은 replace_function으로 이전 파일의 .bak 사본을 만듭니다. 문서·양식은 Colab 파일 패널에서 내려받아 편집한 뒤 같은 경로로 올리거나 %%writefile 문서 저장 셀을 사용하세요. 런타임 초기화 전에 양식·코드·실제 대화·outputs를 검토용 ZIP으로 보관합니다. 준비 셀 재실행은 기존 실습 폴더를 덮어쓰지 않습니다. 다른 환경에서 이어 쓸 때는 보관 ZIP의 내용을 MOV06_project 폴더에 복원한 뒤 ROOT를 확인하세요.

최종 제출 셀은 원본 필수 7개 구현·실행 기록과 M7 직접 역할 입력·감사 로그 등을 검사합니다. 파일 존재는 본문·정량 목표 달성·실제 교관 승인의 증거가 아닙니다. M10 문서 점검의 미작성 FAIL은 본문 작성 전 상태를 뜻합니다. 교관용 완성 Solution의 파일·권한은 별도 확인 대상이며 학생 자료에 연결하지 않습니다.
