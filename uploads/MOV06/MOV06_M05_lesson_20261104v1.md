# MOV06 M05 — 수송선단 경로 이탈 및 불시 정차 감지 신뢰도 경보 엔진 개발


## 지금 해결할 문제
잡음이 낀 GPS를 실제 이탈로 오인하면 불필요한 경보가 생깁니다. 이탈·정차 신호가 얼마나 지속됐는지 보고 경보와 ETA 성능을 따로 평가합니다.

여러분은 교육용 가상 물류 데이터 분석 담당자입니다. 실제 부대 위치를 추적하거나 수송을 지시하는 활동은 아닙니다.

정밀도는 낸 경보 중 실제 사건의 비율, 재현율은 실제 사건 중 찾아낸 비율입니다. Hold-out은 모델 선택 뒤 평가할 별도 이동 구간이며, 신뢰도 점수 자체가 실제 정확도를 뜻하지는 않습니다.


## 시작 순서
프로젝트 개요 → 참고자료에서 최신 학생용 Notebook과 실습 ZIP을 준비하고, 미션 5의 학습 안내·작성 양식을 읽으세요.

함수를 구현·저장하고 첫 실행을 보존하세요. 다음 변경을 적용해 같은 조건으로 다시 실행합니다: 정차 경보 임계값 0.5와 0.8을 같은 관측·잡음 조건에서 비교한다. 이벤트 재현율·탐지 지연·오경보와 고정 hold-out의 ETA 성능을 구분한다.



forms/MOV06_M05_forms.md과 지정 산출물에 실제 결과·근거 검토 3건 이상·수정 이유·미확인 사항을 기록합니다.




## 완료 전 확인
경보의 이벤트 단위 재현율·탐지 지연·잡음 조건 오경보를 확인합니다. 기준 대비 MAE·RMSE 각각 20% 이상 개선과 R2 0.85 이상은 별도 ETA 평가로 판단합니다.

0~1 신뢰도는 거리·정차 길이로 만든 점수이며 보정된 확률이 아닙니다.

이벤트 탐지율과 행 단위 정확도·오경보를 구분합니다.

자료 경로와 저장 방법은 아래 학습자료 안내를 따르세요. 파일 저장이나 ZIP 생성만으로 평가 통과·교관 승인이 이루어지지는 않습니다.



## 학습 목표
이탈 거리와 정차 지속 시간으로 0~1 신뢰도를 계산해 0.5 이상을 경보로 보고, 이벤트 단위 재현율·탐지 지연·오경보를 깨끗한 관측과 GPS 잡음 조건에서 비교합니다.

정차 임계값 0.3·0.5·0.8의 정밀도와 재현율 변화를 확인합니다.

감지 신뢰도를 피처로 넣은 앙상블 ETA 모델과 기준 모델의 MAE·RMSE·R2를 hold-out 이동에서 비교하고 이탈·정차·우천 상황별 오차를 분석합니다.


## 구현할 함수와 입출력

## 추가 변경과 비교
