# MOV06 실행 안내

1. 허용된 인터넷 환경에서 최신 MOV06_student_20261104v1.ipynb를 Google Colab의 파일 → 노트북 업로드로 엽니다. 폐쇄망에서는 기관이 준비한 Python·패키지·AI 환경을 사용합니다.
2. 첫 준비 셀에서 프로젝트 공통 첨부에서 내려받은 최신 MOV06 실습 ZIP 하나를 선택합니다. 서버가 붙인 파일명 접미 번호가 있어도 준비 셀에서 선택할 수 있습니다. 전체 교관용 인계 ZIP이 아닙니다. ROOT가 /content/MOV06_project인지 확인하고, 필요한 패키지가 없을 때만 설치 셀의 주석을 풉니다. 설치 후에는 런타임 재시작이 필요할 수 있습니다.
3. 같은 번호 미션의 계약과 빈 함수를 확인하고 함수 저장 셀의 주석을 풀어 전체 def를 implementation에 넣습니다. 저장 뒤 실행 셀을 실행하세요. 미구현 함수는 의도적으로 오류를 냅니다. 문법 검사와 실제 실행·평가 통과는 다릅니다.
4. run_mission은 outputs/M번호/실행별 폴더에 실제 로그·표·그림·run.json 또는 failure.json을 저장합니다. 경로와 실행 조건을 양식에 연결하고 첫 실행과 수정 실행을 보존하세요.
5. M7 직접 입력 셀에서는 CTL 기안 → TCO 검토 → LOG 검토를 역할별로 직접 수행합니다. 대체 수송은 두 단계 승인, 현장 확인은 정해진 역할 검토를 따릅니다. 가상 역할 수행은 실제 인증·수송 지시가 아닙니다.
6. 양식·보고서는 파일 패널에서 편집·재업로드하거나 %%writefile 셀로 저장합니다. 미완료 상태는 검토용 ZIP, 필수 조건을 갖춘 뒤에는 최종 제출 셀로 내려받습니다. 실제 Colab·폐쇄망 실행은 별도 검증 사항이며 로컬 실행만으로 완료 표시하지 않습니다.
