# QLT02 M06 수입 검사 불량 추세 및 고위험 납품업체 모니터링 품질 대시보드 구현

당신은 교육용 품질 데이터 분석 담당자입니다. 수입 검사 불량 추세와 고위험 납품업체를 모니터링하는 품질 대시보드를 만들고, 경보 로트마다 기여도 상위 3개 인자를 설명한다.

## 원본 기준

- 목표: 수입 검사 불량 추세와 고위험 납품업체를 모니터링하는 품질 대시보드를 만들고, 경보 로트마다 기여도 상위 3개 인자를 설명한다.
- 원본 예상 3시간〔CMS 편성 3시간, 실측 시간이 아님〕
- 수행: 월별 표본 불량률과 관리한계, 업체별 평균 위험 지수와 추세(악화·유지), 위험 지수 분포, 대표 로트의 기여도 워터폴을 2x2 대시보드로 그린다. 요인을 7개 군(업체 이력, 규격 변경·불일치, 정밀 규격, 납기, 표본검사, 구매요구 조건, 품목군)으로 묶어 섀플리 기여도를 정확히 계산하고, 상위 3개 인자와 조치 제안을 자연어 문장으로 만든다.
- 원본 평가: [선택] 대시보드·설명 근거  — 경보 로트 상위 3개 인자 자동 산출률 100%, 기여도 합이 예측값과 일치(가법성), 자연어 설명과 조치 제안, 대시보드 4개 패널이 제시되었는가.
- 산출물: `src/explainability/qlt02_xai_explainer.py`, `reports/qlt02_xai_report.md`

## 제공 자료와 코드

교육용 기본 코드 `src/explainability/qlt02_xai_explainer.py`와 공통 데이터 파일을 제공합니다. 핵심 함수는 학습자가 구현할 빈칸이며 나머지는 교육용 제공 도구입니다. 이 ZIP에는 source_originals 폴더나 교관 정답이 포함되어 있지 않습니다. 데이터 딕셔너리와 입력 예시는 실습프로젝트 data 폴더에 있습니다. 가상 데이터 생성식은 교육용 제공 도구입니다.

- 원본 가이드의 진행: 1) M6 코드를 실행해 월별 관리한계 초과 월과 업체별 위험 현황표를 확인한다.
2) 경보 로트의 요인군별 평균 기여도를 확인한다.
3) 자동 설명 예시 문장과 조치 제안이 타당한지 검토한다.
- 실제 성과값은 본인이 코드를 실행한 뒤 기록합니다. 미리 제시된 예시 수치를 본인 결과로 복사하지 않습니다.

## 출제자가 보완한 판단 기준

7개 요인군 섀플리 기여도의 가법성은 모델의 로그 불량률 공간에서 확인합니다. 기본값+7개 기여도 합=로그 예측값이며 이것이 위험 확률에 그대로 더해진다는 뜻은 아닙니다. 상위 3개만 더해서 전체 예측값과 일치해야 하는 것도 아닙니다. 이는 정의한 배경 분포·7개 군 연합에 대한 정확 계산입니다. 상호작용이 있는 피처의 조합이 현실에서 항상 가능한 것은 아니므로 인과 설명으로 확대하지 않습니다. 경보가 0건이면 산출률은 계산 불가로 표시합니다. 2×2 정적 대시보드를 Colab에서 보고 웹 서비스 배포 완료라고 쓰지 않습니다.

## 이번 미션의 구현 범위

- 파일: `src/explainability/qlt02_xai_explainer.py`
- 구현할 함수: `shapley`
- 입력·출력 계약: x 입력 → (기여도 배열, 전체 조합 예측값). 제공 coal·bg·모델을 사용해 합산 관계를 확인한다.
- 데이터 생성·공통 보조 함수는 제공 코드입니다. 반복되는 생성 함수 빈칸을 채우는 활동으로 대체하지 않습니다.
- 먼저 핵심 함수를 구현해 첫 실행 결과를 확보하고, 아래 변경 과제로 수정 전후를 비교합니다. 실제 AI 요청·답변과 본인이 확인한 오류·수정 이유를 forms에 기록합니다.

## AI와 개발할 변경 과제

납기 요인군을 분리하여 8개 군이 되었을 때 계산량·상위 인자·가법성을 비교하고 자연어 설명을 수정합니다.

완성 프롬프트를 그대로 복사하는 대신 목표·자료·제약·필요 결과를 본인의 말로 요청합니다. 코드 작성·실행 오류 진단·테스트 설계·결과 설명에 AI를 사용할 수 있지만 최종 선택은 본인이 설명해야 합니다.


## 학습 활동

### 활동 1 — 분석 목표와 변경 계획을 먼저 정한다

원본 목표·기본 코드·데이터를 읽고 사용할 입력 시점과 평가 기준을 정리합니다. 가법성은 어떤 출력 공간에서 성립하는가? 본인의 예상·미확인 사항을 forms에 적고 AI에 제공할 자료·코드 범위를 고릅니다.

### 활동 2 — 핵심 함수를 AI와 구현하고 첫 실행 결과를 보존한다

### 활동 3 — 수정 코드를 실행하고 근거를 검증한다

변경한 소스를 저장하고 재실행합니다. 3개 인자만 제시할 때 나머지 기여도는 어디에 남길까? AI의 주장·구현 선택 3건 이상을 원본·코드·검증 결과와 대조하고 보완을 요청합니다. 목표 미달·예시·교육용 가정·실측을 구분합니다.

### 활동 4 — 결과와 판단을 제출하고 다음 단계에 연결한다

변경 전후 결과·검토·최종 선택 이유를 양식에 정리합니다. 코드·노트북·로그·그림·보고서와 각 원본 산출물을 보존합니다. 개인 작성 완료와 실제 교관 승인 상태를 구분합니다.
