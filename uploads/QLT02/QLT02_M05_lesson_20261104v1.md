# QLT02 M05 로트별 품질 위험 지수(Quality Risk Score) 산출 및 조기경보 엔진 개발

당신은 교육용 품질 데이터 분석 담당자입니다. 앙상블 모델로 로트별 확정 불량률을 예측해 품질 위험 지수(0~100)와 경보 등급을 산출하는 조기경보 엔진을 개발한다.

## 원본 기준

- 목표: 앙상블 모델로 로트별 확정 불량률을 예측해 품질 위험 지수(0~100)와 경보 등급을 산출하는 조기경보 엔진을 개발한다.
- 원본 예상 3.5시간〔CMS 편성 4시간, 실측 시간이 아님〕
- 수행: 그래디언트 부스팅과 랜덤 포레스트를 묶은 앙상블을 앞 18개월로 학습하고 최근 6개월 hold-out에서 기준 모델과 MAE·RMSE·R2를 비교한다. 예측 불량률이 허용 불량률 5%를 넘을 확률을 위험 지수로 바꿔 경보·주의·정상 등급을 매긴다. 등급별 실제 불량 비율과 샘플링 오합격 로트 포착 수를 확인한다.
- 원본 평가: [필수] 위험 지수·예측 성능  — 기준 모델 대비 MAE 또는 RMSE 20% 이상 개선, R2 0.85 이상, 위험 등급별 실제 불량 비율이 단조롭게 구분되는가.
- 산출물: `src/models/qlt02_advanced_model.py`, `reports/qlt02_model_metrics.md`

## 제공 자료와 코드

교육용 기본 코드 `src/models/qlt02_advanced_model.py`와 공통 데이터 파일을 제공합니다. 핵심 함수는 학습자가 구현할 빈칸이며 나머지는 교육용 제공 도구입니다. 이 ZIP에는 source_originals 폴더나 교관 정답이 포함되어 있지 않습니다. 데이터 딕셔너리와 입력 예시는 실습프로젝트 data 폴더에 있습니다. 가상 데이터 생성식은 교육용 제공 도구입니다.

- 원본 가이드의 진행: 1) M5 코드를 실행해 hold-out 성능 비교표를 확인한다.
2) 위험 등급별 실제 불량 로트 비율을 확인한다.
3) 샘플링에서 오합격된 불량 로트를 조기경보가 몇 건 잡았는지 기록한다.
- 실제 성과값은 본인이 코드를 실행한 뒤 기록합니다. 미리 제시된 예시 수치를 본인 결과로 복사하지 않습니다.

## 출제자가 보완한 판단 기준

앞 18개월 중 학습 시작 전에 확정된 자료만 학습하고 최근 6개월을 시간 순서대로 평가합니다. 과거 평가 구간 이력을 갱신할 때에도 당시 공개된 자료만 사용합니다. 이는 순차적인 과거 재생 평가이며 미래 확정 라벨을 즉시 알 수 있다고 가정하지 않습니다. 원본 위험 지수는 로그 불량률과 정규 잔차 가정으로 산출한 모형 점수입니다. 확률 보정이 검증된 실제 불량 확률이라고 단정하지 않습니다. 등급별 실제 비율과 분모를 기록하고 빈 등급은 판정 불가로 둡니다.

## 이번 미션의 구현 범위

- 파일: `src/models/qlt02_advanced_model.py`
- 구현할 함수: `RiskEngine._log_pred`, `RiskEngine.risk`
- 입력·출력 계약: 모델 로그 예측은 GBM/RF 가중 결합, 위험 점수는 불량 기준 초과 확률×100. 제공 sigma와 BAD_RATE를 사용한다.
- 데이터 생성·공통 보조 함수는 제공 코드입니다. 반복되는 생성 함수 빈칸을 채우는 활동으로 대체하지 않습니다.
- 먼저 핵심 함수를 구현해 첫 실행 결과를 확보하고, 아래 변경 과제로 수정 전후를 비교합니다. 실제 AI 요청·답변과 본인이 확인한 오류·수정 이유를 forms에 기록합니다.
