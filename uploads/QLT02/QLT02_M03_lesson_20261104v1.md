# QLT02 M03 불량률 통계 기반 1차 로트(Lot) 합격/불합격 판정 Baseline 알고리즘 구현

당신은 교육용 품질 데이터 분석 담당자입니다. 표본 불량 수가 합격판정수 이하이면 합격시키는 통계적 샘플링 기반 로트 합격/불합격 판정 Baseline을 구현하고, 탐색적 분석으로 불량 관련 요인을 찾는다.

## 원본 기준

- 목표: 표본 불량 수가 합격판정수 이하이면 합격시키는 통계적 샘플링 기반 로트 합격/불합격 판정 Baseline을 구현하고, 탐색적 분석으로 불량 관련 요인을 찾는다.
- 원본 예상 2.5시간〔CMS 편성 3시간, 실측 시간이 아님〕
- 수행: 로트 크기별 표본 수와 합격판정수로 판정한 뒤 확정 불량률과 비교해 오합격·오불합격을 측정한다. 규격 등급, 규격 불일치, 납기 지연, 업체, 품목군별 차트 8종을 그리고 상관계수와 p-value로 유의한 요인을 고른다. 업체 파레토(ABC) 분석으로 집중 관리 대상을 정하고 핵심 발견점을 문서화한다.
- 원본 평가: [필수] Baseline 판정·EDA  — Baseline 판정 혼동표와 오판정률 제시, EDA 차트 8종 이상, 통계적으로 유의한 상관 피처 5개 이상, 파레토 상위 관리 업체가 도출되었는가.
- 산출물: `notebooks/qlt02_eda_analysis.ipynb`, `reports/qlt02_eda_summary.md`

## 제공 자료와 코드

교육용 기본 코드 `src/analysis/qlt02_baseline.py`와 공통 데이터 파일을 제공합니다. 핵심 함수는 학습자가 구현할 빈칸이며 나머지는 교육용 제공 도구입니다. 이 ZIP에는 source_originals 폴더나 교관 정답이 포함되어 있지 않습니다. 데이터 딕셔너리와 입력 예시는 실습프로젝트 data 폴더에 있습니다. 가상 데이터 생성식은 교육용 제공 도구입니다.

- 원본 가이드의 진행: 1) M3 코드를 실행해 Baseline 판정 혼동표와 오합격·오불합격률을 확인한다.
2) 상관 검정 표에서 p<0.05인 요인을 고른다.
3) 파레토 ABC 등급과 핵심 발견점을 정리한다.
- 실제 성과값은 본인이 코드를 실행한 뒤 기록합니다. 미리 제시된 예시 수치를 본인 결과로 복사하지 않습니다.

## 출제자가 보완한 판단 기준

혼동표에서 오합격률과 오불합격률의 분모를 명시합니다. p-value는 교육용 탐색 결과이며 인과관계나 실무에서 재현되는 영향력을 보장하지 않습니다. 생성식이 심어 놓은 패턴을 다시 찾아낸 결과입니다. 다중 검정·표본 수·업체별 로트 규모의 영향을 검토하고 목표 5개를 채우려고 p값을 바꾸지 않습니다.

## 이번 미션의 구현 범위

- 데이터 생성·공통 보조 함수는 제공 코드입니다. 반복되는 생성 함수 빈칸을 채우는 활동으로 대체하지 않습니다.

## AI와 개발할 변경 과제

합격판정수 c와 c-1을 비교하고 오합격·오불합격의 변화를 분모·수량과 함께 설명합니다.

완성 프롬프트를 그대로 복사하는 대신 목표·자료·제약·필요 결과를 본인의 말로 요청합니다. 코드 작성·실행 오류 진단·테스트 설계·결과 설명에 AI를 사용할 수 있지만 최종 선택은 본인이 설명해야 합니다.


## 학습 활동

### 활동 1 — 분석 목표와 변경 계획을 먼저 정한다

원본 목표·기본 코드·데이터를 읽고 사용할 입력 시점과 평가 기준을 정리합니다. 오합격률의 분모는 불량 로트인가, 합격 로트인가? 본인의 예상·미확인 사항을 forms에 적고 AI에 제공할 자료·코드 범위를 고릅니다.

### 활동 2 — 핵심 함수를 AI와 구현하고 첫 실행 결과를 보존한다

### 활동 3 — 수정 코드를 실행하고 근거를 검증한다

변경한 소스를 저장하고 재실행합니다. 상관성이 높으면 원인이라고 말해도 될까? AI의 주장·구현 선택 3건 이상을 원본·코드·검증 결과와 대조하고 보완을 요청합니다. 목표 미달·예시·교육용 가정·실측을 구분합니다.

### 활동 4 — 결과와 판단을 제출하고 다음 단계에 연결한다

변경 전후 결과·검토·최종 선택 이유를 양식에 정리합니다. 코드·노트북·로그·그림·보고서와 각 원본 산출물을 보존합니다. 개인 작성 완료와 실제 교관 승인 상태를 구분합니다.
