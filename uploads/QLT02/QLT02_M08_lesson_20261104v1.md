# QLT02 M08 불량 부품 대량 납품 가상 주입 시 조기경보 신속성 스트레스 테스트

당신은 교육용 품질 데이터 분석 담당자입니다. 평소 품질이 좋던 업체가 불량 부품을 대량 납품하는 상황을 가상으로 주입해 조기경보의 정확도와 신속성, 대시보드 갱신 성능을 시험한다.

## 원본 기준

- 목표: 평소 품질이 좋던 업체가 불량 부품을 대량 납품하는 상황을 가상으로 주입해 조기경보의 정확도와 신속성, 대시보드 갱신 성능을 시험한다.
- 원본 예상 3시간〔CMS 편성 3시간, 실측 시간이 아님〕
- 수행: 우수 업체 V03에 불량 로트 위주의 대량 납품 60로트와 손상 레코드 12건을 주입한다. 손상 레코드는 격리하고, 로트 경보 정확도와 업체 단위 누적합(CUSUM) 경보가 몇 번째 로트에서 울리는지 측정한다. 로트 수를 1배·10배·50배로 늘려 대시보드 갱신 시간을 잰다.
- 원본 평가: [선택] 조기경보 스트레스 시험  — 대시보드 갱신 시간 2초 이내, 대량 납품 주입 로트 경보 정확도 95% 이상, 업체 경보 신속성과 평시 오경보 수, 손상 레코드 격리가 확인되었는가.
- 산출물: `src/dashboard/qlt02_app.py`, `reports/qlt02_stress_test.md`

## 제공 자료와 코드

교육용 기본 코드 `src/dashboard/qlt02_app.py`와 공통 데이터 파일을 제공합니다. 핵심 함수는 학습자가 구현할 빈칸이며 나머지는 교육용 제공 도구입니다. 이 ZIP에는 source_originals 폴더나 교관 정답이 포함되어 있지 않습니다. 데이터 딕셔너리와 입력 예시는 실습프로젝트 data 폴더에 있습니다. 가상 데이터 생성식은 교육용 제공 도구입니다.

- 원본 가이드의 진행: 1) M8 코드를 실행해 주입 내용과 손상 레코드 격리 결과를 확인한다.
2) 스트레스 구간 전체와 주입 로트의 경보 정확도를 구분해 기록한다.
3) CUSUM 업체 경보 시점과 대시보드 갱신 시간을 확인한다.
- 실제 성과값은 본인이 코드를 실행한 뒤 기록합니다. 미리 제시된 예시 수치를 본인 결과로 복사하지 않습니다.

## 출제자가 보완한 판단 기준

V03 주입 60로트와 손상 레코드 12건, 1·10·50배를 유지합니다. 주입 구간과 전체 스트레스 구간 정확도를 구분하며 목표 95%는 원본의 주입 로트 기준으로 평가합니다. 전체 구간의 미달도 함께 기록합니다. 2초는 위험 계산·업체 집계·추세·상위 20건 계산이라는 원본 측정 범위이고 파일 로드·모델 학습·웹 화면 렌더링·네트워크는 포함하지 않습니다. 고정 환경·반복 횟수·중앙값을 기록합니다. CUSUM 경보가 없을 때도 오류 없이 미발령을 남겨야 합니다.
