# QLT02 M02 검사 측정치 결측치 정제, 납품업체별 불량 이력 인코딩 전처리 모듈 구현

당신은 교육용 품질 데이터 분석 담당자입니다. 검사 측정치 결측을 정제하고 납품업체별 불량 이력을 정보 누수 없이 인코딩하는 전처리 모듈을 구현한다.

## 원본 기준

- 목표: 검사 측정치 결측을 정제하고 납품업체별 불량 이력을 정보 누수 없이 인코딩하는 전처리 모듈을 구현한다.
- 원본 예상 2시간〔CMS 편성 2시간, 실측 시간이 아님〕
- 수행: 중복 로트, 업체 코드 표기, 날짜 형식, 재고번호 형식, 범위 오류 등 정제 규칙 10종을 적용하고 치수 측정 결측은 KNN으로 보간한다. 긴급 불출처럼 군수 특수 예외 기록은 삭제하지 않고 표시해 보존한다. 업체 불량 이력은 현재 로트 이전 기록만으로 계산하고, 정제 전후 기술통계와 정합성 검증 통과율을 비교한다.
- 원본 평가: [필수] 정제·정합성 검증  — 정제 규칙 10종 적용, 정합성 검증 통과율 100%, 특수 예외 기록 보존, 업체 이력 인코딩의 정보 누수 방지가 확인되었는가.
- 산출물: `src/etl/qlt02_data_cleansing.py`, `reports/qlt02_cleansing_quality.md`

## 제공 자료와 코드

교육용 기본 코드 `src/etl/qlt02_data_cleansing.py`와 공통 데이터 파일을 제공합니다. 핵심 함수는 학습자가 구현할 빈칸이며 나머지는 교육용 제공 도구입니다. 이 ZIP에는 source_originals 폴더나 교관 정답이 포함되어 있지 않습니다. 데이터 딕셔너리와 입력 예시는 실습프로젝트 data 폴더에 있습니다. 가상 데이터 생성식은 교육용 제공 도구입니다.

- 원본 가이드의 진행: 1) M2 코드를 실행해 정제 전 정합성 검증 실패 항목을 확인한다.
2) 정제 규칙 10종의 적용 건수와 KNN 보간 결과를 확인한다.
3) 업체 이력 인코딩 표에서 이전 로트만 쓰는 이유(정보 누수 방지)를 정리한다.
- 실제 성과값은 본인이 코드를 실행한 뒤 기록합니다. 미리 제시된 예시 수치를 본인 결과로 복사하지 않습니다.

## 출제자가 보완한 판단 기준

원본 코드의 전체 기간 평균 이력값과 전체 데이터에 맞춘 KNN 스케일·보간은 미래 정보를 볼 수 있습니다. 보완 코드는 이력 공개 시점을 수령 30일 뒤라는 교육용 가정으로 두고, 현재 접수보다 먼저 공개된 과거만 사용합니다. 이력 없는 업체의 사전값 5%는 고정 가정입니다. KNN은 앞 18개월 정제 자료에 fit한 뒤 이후 구간을 transform합니다. 부호·단위의 자동 수정은 이 데이터 생성기의 알려진 오류 주입을 복원하는 규칙이며, 출처·단위 근거가 없는 실제 오류에는 일반화하지 않습니다. 특수 예외와 수정/격리 사유를 보존합니다.

## 이번 미션의 구현 범위

- 파일: `src/etl/qlt02_data_cleansing.py`
- 구현할 함수: `clean`
- 입력·출력 계약: raw DataFrame → (정제 DataFrame, 처리 로그). 제공 정제 규칙과 학습 구간 기준의 결측치 처리를 구현한다.
- 데이터 생성·공통 보조 함수는 제공 코드입니다. 반복되는 생성 함수 빈칸을 채우는 활동으로 대체하지 않습니다.
- 먼저 핵심 함수를 구현해 첫 실행 결과를 확보하고, 아래 변경 과제로 수정 전후를 비교합니다. 실제 AI 요청·답변과 본인이 확인한 오류·수정 이유를 forms에 기록합니다.

## AI와 개발할 변경 과제

KNN 이웃 수 3·5·10을 같은 학습/검증 조건에서 비교하고 공개 시점 기반 업체 이력의 누수 방지 검증을 실행합니다.

완성 프롬프트를 그대로 복사하는 대신 목표·자료·제약·필요 결과를 본인의 말로 요청합니다. 코드 작성·실행 오류 진단·테스트 설계·결과 설명에 AI를 사용할 수 있지만 최종 선택은 본인이 설명해야 합니다.
