# QLT02 M07 합부 판정 경계선 품목에 대한 품질 검사관 정밀 재검사(HITL) 워크플로우 설계

당신은 교육용 품질 데이터 분석 담당자입니다. 합부 판정 경계선에 있는 로트를 자동 확정하지 않고 품질 검사관 정밀 재검사로 넘기는 인간 개입(HITL) 워크플로우를 설계하고, 한정된 검사 시간을 최적 배분한다.

## 원본 기준

- 목표: 합부 판정 경계선에 있는 로트를 자동 확정하지 않고 품질 검사관 정밀 재검사로 넘기는 인간 개입(HITL) 워크플로우를 설계하고, 한정된 검사 시간을 최적 배분한다.
- 원본 예상 3.5시간〔CMS 편성 4시간, 실측 시간이 아님〕
- 수행: 표본 불량 수가 합격판정수 근처이거나 위험 확률이 중간인 로트를 재검사 대기열에 등록한다. 월 가용 검사 시간 안에서 기대 순편익이 큰 로트를 고르는 0-1 정수계획(MIP)과 현행 선착순 방식을 실제 확정 결과로 비교한다. 최초 검사자 재배정 금지, 판정 근거 기록, 해시 이력을 적용하고 물량 증가·검사 시간 감소에 대한 민감도를 분석한다.
- 원본 평가: [필수] 재검사 승인·최적 배분  — 경계선 로트 자동 확정 0건, 최적화 적용 시 현행 대비 품질비용 15% 이상 절감, 검사관 판정 근거 기록, 돌발 수요 민감도 분석이 제시되었는가.
- 산출물: `src/optimization/qlt02_simulator.py`, `reports/qlt02_hitl_review.md`

## 제공 자료와 코드

교육용 기본 코드 `src/optimization/qlt02_simulator.py`와 공통 데이터 파일을 제공합니다. 핵심 함수는 학습자가 구현할 빈칸이며 나머지는 교육용 제공 도구입니다. 이 ZIP에는 source_originals 폴더나 교관 정답이 포함되어 있지 않습니다. 데이터 딕셔너리와 입력 예시는 실습프로젝트 data 폴더에 있습니다. 가상 데이터 생성식은 교육용 제공 도구입니다.

- 원본 가이드의 진행: 1) M7 코드를 실행해 경계선 로트 선별 기준과 대기열 등록 수를 확인한다.
2) 재검사 없음·선착순·MIP 방식의 품질비용과 놓친 불량 로트를 비교한다.
3) 검사관 재검사 기록과 민감도 분석 표를 해석한다.
- 실제 성과값은 본인이 코드를 실행한 뒤 기록합니다. 미리 제시된 예시 수치를 본인 결과로 복사하지 않습니다.

## 출제자가 보완한 판단 기준

원본의 재검사 기록은 확정 라벨에서 판정을 생성한 교육용 예시이며 사람이 승인한 기록이 아닙니다. 자동 최종 확정이 없는 대기열 상태와 예시 판정을 구분합니다. 제공된 approval 도구로 학습자가 가상 검사관 역할의 선택·근거를 직접 입력하는 실습을 추가합니다. 최초 검사자 재배정·근거 공란·AI 자동 승인·기록 변조가 차단되는지 확인합니다. MIP는 예측된 기대 순편익으로 선택하며 실제 확정 결과는 사후 비교에만 사용합니다. 솔버가 실패하거나 해가 없으면 임의 선택으로 정상 처리하지 않습니다. 비용 절감은 정밀 재검사의 완전한 판정이라는 교육용 가정을 포함합니다.
