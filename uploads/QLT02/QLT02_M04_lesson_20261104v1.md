# QLT02 M04 다변량 분석 및 머신러닝 기반 은닉 품질 결함 패턴 식별 모델 고도화

당신은 교육용 품질 데이터 분석 담당자입니다. 다변량 분석으로 단일 요인에서 드러나지 않는 은닉 품질 결함 패턴(규격 x 납기 상호작용, 업체 품질 추세)을 식별하는 피처와 기준 모델을 만든다.

## 원본 기준

- 목표: 다변량 분석으로 단일 요인에서 드러나지 않는 은닉 품질 결함 패턴(규격 x 납기 상호작용, 업체 품질 추세)을 식별하는 피처와 기준 모델을 만든다.
- 원본 예상 3시간〔CMS 편성 3시간, 실측 시간이 아님〕
- 수행: 표본 불량률, 지연 비율, 정밀 규격 x 촉박 납기, 치수 편차/공차, 업체 최근 추세 등 파생 피처 10개 이상을 만든다. Ridge 기준 모델로 로트 확정 불량률을 예측하고 시계열 교차검증으로 과적합을 점검한다. 순열 중요도로 영향이 작은 피처를 줄이고, 상호작용·추세 피처 유무에 따른 오차 차이로 은닉 패턴을 확인한다.
- 원본 평가: [선택] 피처 설계·기준 모델  — 파생 피처 10개 이상, 시계열 교차검증 기준 모델 MAPE 25% 이하, 피처 중요도 기반 차원 축소와 은닉 패턴 2개 이상의 근거가 제시되었는가.
- 산출물: `src/features/qlt02_feature_engineering.py`, `reports/qlt02_feature_validation.md`

## 제공 자료와 코드

교육용 기본 코드 `src/features/qlt02_feature_engineering.py`와 공통 데이터 파일을 제공합니다. 핵심 함수는 학습자가 구현할 빈칸이며 나머지는 교육용 제공 도구입니다. 이 ZIP에는 source_originals 폴더나 교관 정답이 포함되어 있지 않습니다. 데이터 딕셔너리와 입력 예시는 실습프로젝트 data 폴더에 있습니다. 가상 데이터 생성식은 교육용 제공 도구입니다.

- 원본 가이드의 진행: 1) M4 코드를 실행해 파생 피처 목록과 시계열 교차검증 MAPE를 확인한다.
2) 순열 중요도 상위 피처와 차원 축소 결과를 확인한다.
3) 규격 x 납기 교차표와 업체 추세로 은닉 패턴을 설명한다.
- 실제 성과값은 본인이 코드를 실행한 뒤 기록합니다. 미리 제시된 예시 수치를 본인 결과로 복사하지 않습니다.

## 출제자가 보완한 판단 기준

과거 로트라 해도 확정 결과 공개 전이면 업체 이력에 넣지 않습니다. 시계열 폴드 학습에서도 검증 시작 전에 확정된 라벨만 씁니다. MAPE 분모가 0이면 처리 방식을 명시하고 지표를 숨기지 않습니다. 원본의 이후 6개월 순열 중요도는 탐색용이고 같은 기간으로 다시 평가한 차원 축소 성능을 독립적인 최종 검증 성능으로 부르지 않습니다. M5의 최종 비교에서는 피처·모델 선택 전에 평가 조건을 고정합니다.

## 이번 미션의 구현 범위

- 먼저 핵심 함수를 구현해 첫 실행 결과를 확보하고, 아래 변경 과제로 수정 전후를 비교합니다. 실제 AI 요청·답변과 본인이 확인한 오류·수정 이유를 forms에 기록합니다.

## AI와 개발할 변경 과제

상호작용 피처 유무를 같은 시간 폴드에서 비교하고 은닉 패턴 2개에 대한 근거·한계를 작성합니다.

완성 프롬프트를 그대로 복사하는 대신 목표·자료·제약·필요 결과를 본인의 말로 요청합니다. 코드 작성·실행 오류 진단·테스트 설계·결과 설명에 AI를 사용할 수 있지만 최종 선택은 본인이 설명해야 합니다.


## 학습 활동

### 활동 2 — 핵심 함수를 AI와 구현하고 첫 실행 결과를 보존한다

### 활동 3 — 수정 코드를 실행하고 근거를 검증한다

### 활동 4 — 결과와 판단을 제출하고 다음 단계에 연결한다
