# QLT02 M09 AAR 기반 불량 오판정 사례 분석 및 검사 샘플링 파라미터 재보정

당신은 교육용 품질 데이터 분석 담당자입니다. 고정 샘플링 기준의 불량 오판정 사례를 사후검토(AAR)로 분석하고, 위험 등급별 샘플링 파라미터를 재보정해 정량 효과를 산출한다.

## 원본 기준

- 목표: 고정 샘플링 기준의 불량 오판정 사례를 사후검토(AAR)로 분석하고, 위험 등급별 샘플링 파라미터를 재보정해 정량 효과를 산출한다.
- 원본 예상 3시간〔CMS 편성 3시간, 실측 시간이 아님〕
- 수행: 학습 구간의 오합격·오불합격 사례를 경계선 불량률, 업체 이력 미반영, 정밀 규격 기준 동일 등 원인으로 분류한다. 입고 전 정보(업체 이력, 납기, 규격 변경 등)로 위험 등급을 나누고 등급별 표본 크기와 합격판정수를 비용 최소 기준으로 다시 정한다. 검증 구간에서 비용 절감액, 검사 시간 단축률, 불량품 유출 감소율을 산식과 함께 제시한다.
- 원본 평가: [필수] AAR 원인분석·재보정 효과  — 오판정 원인 분류, 등급별 샘플링 기준 재보정, 비용 절감액·시간 단축률·유출 감소율 3대 정량 효과 지표와 산식·가정이 제시되었는가.
- 산출물: `reports/qlt02_roi_analysis.md`, `src/analysis/qlt02_sampling_recalibration.py`

## 제공 자료와 코드

교육용 기본 코드 `src/analysis/qlt02_sampling_recalibration.py`와 공통 데이터 파일을 제공합니다. 핵심 함수는 학습자가 구현할 빈칸이며 나머지는 교육용 제공 도구입니다. 이 ZIP에는 source_originals 폴더나 교관 정답이 포함되어 있지 않습니다. 데이터 딕셔너리와 입력 예시는 실습프로젝트 data 폴더에 있습니다. 가상 데이터 생성식은 교육용 제공 도구입니다.

- 원본 가이드의 진행: 1) M9 코드를 실행해 오합격·오불합격 원인 분류를 확인한다.
2) 입고 전 위험 등급과 등급별 재보정 샘플링 기준(n, c)을 확인한다.
3) 3대 정량 효과 지표와 산식, 가정 단가를 정리한다.
- 실제 성과값은 본인이 코드를 실행한 뒤 기록합니다. 미리 제시된 예시 수치를 본인 결과로 복사하지 않습니다.

## 출제자가 보완한 판단 기준

위험 등급에 수령검사 결과를 넣으면 입고 전 샘플링 계획이 될 수 없습니다. 입고 전 정보만 쓰는 별도 입력 목록을 확인합니다. 등급별 n,c는 학습 구간에서 정하고 검증 구간에서는 고정합니다. 원본 단가·검사시간·손실계수는 교육용 가정이며 비용 절감액·시간 단축률·불량 유출 감소율의 분모·단위를 명시합니다. 기준 0이면 감소율은 계산 불가입니다. 음수 개선도 그대로 보고합니다. 확정 불량률을 이용한 실제 비용은 사후 평가값이지 계획 때 알 수 있던 값이 아닙니다.

## 이번 미션의 구현 범위

- 파일: `src/analysis/qlt02_sampling_recalibration.py`
- 구현할 함수: `evaluate`
- 입력·출력 계약: df,n,c,seed → acc/FA/FR/검사분/검사비/유출손실/반품손실/총비용/유출불량품 사전. 제공 비용 가정과 난수 재현성을 유지한다.
- 데이터 생성·공통 보조 함수는 제공 코드입니다. 반복되는 생성 함수 빈칸을 채우는 활동으로 대체하지 않습니다.
- 먼저 핵심 함수를 구현해 첫 실행 결과를 확보하고, 아래 변경 과제로 수정 전후를 비교합니다. 실제 AI 요청·답변과 본인이 확인한 오류·수정 이유를 forms에 기록합니다.
