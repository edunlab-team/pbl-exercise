# QLT02 학생용 Workbook v3 — Colab 실행 안내

## 1. 시작하기

1. `QLT02_student_20261104v3.ipynb`를 Google Colab에 업로드합니다.
2. Notebook 첫 화면 아래의 **「실습자료 자동 준비 (클릭하여 실행)」** 셀에서 ▶ 버튼을 클릭합니다. 이 셀은 Colab의 **양식(form) 보기**로 저장되어 긴 내장 ZIP 인코딩 코드가 기본적으로 펼쳐지지 않도록 구성했습니다. 셀의 코드 보기 설정을 변경하면 코드가 보일 수 있습니다.
3. 출력에서 `내장 실습 ZIP 검증 및 준비 완료` 및 `프로젝트 위치: /content/QLT02_project`를 확인합니다. 실습자료 ZIP을 따로 업로드하지 않습니다.
4. 기존 `/content/QLT02_project` 폴더가 있으면 덮어쓰지 않습니다. 다시 시작하기 전에 작업 파일을 백업하세요.
5. 필요한 라이브러리가 없을 때만 설치 셀을 사용합니다. 이후 함수 저장 helper 셀을 실행하고 미션 1~10을 진행합니다.

## 2. 실습과 기록

- M1~M10 핵심 함수는 학생이 직접 구현하며, 첫 실행 출력과 변경·재실행 결과를 구분합니다.
- AI 요청·답변 원문, 근거 검토 3건 이상, 수정 이유와 최종 판단은 각 `forms/QLT02_Mxx_forms.md`에 저장합니다.
- 보조 기록: `save_mission_note(미션번호, "판단", "AI 대화", "검증 근거")`.
- 진행 현황: `show_progress()` — 실행 로그 개수와 메모 유무만 표시합니다. **정량 PASS 또는 교관 승인 아님**.

## 3. 보존·복원·제출

- `export_work_json()`으로 작업 JSON 백업을 내려받고, 새로운 세션에서는 준비 셀·기본 helper를 실행한 뒤 `restore_work_json()`으로 복원합니다. 기본적으로 기존 파일은 덮어쓰지 않습니다.
- 최종 제출 셀은 작성 파일과 실행 흔적을 확인하여 `QLT02.zip`을 생성합니다. ZIP 생성만으로 평가 PASS나 교관 승인이 인정되지는 않습니다.
- 내장 실습 ZIP은 `QLT02_실습프로젝트_20261104v1.zip`과 같은 교육용 실습자료입니다. 별도 ZIP 파일은 문제 발생 시 확인·백업용으로만 제공할 수 있습니다.

## 4. 문제가 생기면

- **코드가 길게 보일 때:** 첫 준비 셀 오른쪽 메뉴에서 **양식 보기/코드 숨기기**를 선택합니다. Colab UI 버전에 따라 표시 방식이 다를 수 있습니다.
- **준비 오류:** 에러 메시지를 보관하고 런타임을 확인하세요. 기존 폴더를 지우기 전에 작업 파일을 백업합니다.
- **실행 파일이 없다는 오류:** 첫 준비 셀을 다시 실행하고 출력 경로가 `/content/QLT02_project`인지 확인합니다.

## 5. 검증 범위

v3는 v2의 실습 코드와 내장 ZIP을 그대로 유지하고, 준비 셀의 기본 표시 방식을 Colab 양식 보기로 수정했습니다. 로컬에서 Notebook 구조, Python 문법, ZIP 압축해제와 작업 백업·복원을 테스트했습니다. **Colab 웹 브라우저에서 양식 접힘 표시 여부, M1~M10 완수, 정량 PASS는 별도 사용자 확인이 필요합니다.**
