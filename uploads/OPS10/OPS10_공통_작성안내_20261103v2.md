# OPS10 시작 전 5단계

1. CMS 공통 참고자료의 최신 학생용 파일을 내려받습니다. Notebook, 오프라인 HTML 중 사용할 도구 하나를 고릅니다. ZIP에는 읽을 자료와 빈 양식이 들어 있습니다.
2. Colab을 쓸 수 있다면 Notebook을 업로드하고 준비 셀부터 실행합니다. 실습 자료는 내장돼 있어 ZIP을 따로 올릴 필요가 없습니다. HTML은 내려받아 브라우저로 열며 AI 기능은 들어 있지 않습니다.
3. 미션의 진행 안내와 제공 자료를 읽고 결과 작성란을 엽니다. 입력란의 빈 양식에 작성하므로 코드나 RESULT 문자열을 고치지 않습니다. 기존 저장 함수는 제공 도구 안에서 그대로 사용합니다.
4. 기관에서 허용한 AI의 별도 대화에 질문과 필요한 가상 자료를 붙입니다. 먼저 본인 생각을 적고, 답변의 핵심 설명 3건 이상을 자료 번호·문장과 대조해 고칩니다. 모르는 사실은 확인 필요로 둡니다.
5. 문서를 저장하고 목적·실제 요청·실제 답변을 한 묶음씩 따로 저장합니다. 작성 중에도 검토용 ZIP을 보관하세요. HTML에서는 작성 JSON을 내려받고 나중에 가져오기로 복원할 수 있습니다. Notebook 준비 셀을 다시 실행해도 이미 저장한 작성본은 보존됩니다.

## 파일과 저장
Workbook은 입력하고 결과를 저장하는 작성 도구입니다. materials는 읽을 자료, forms는 빈 양식, docs·sop·logs 등은 결과를 담는 폴더 이름입니다. 도구가 미션별 경로로 저장하며 같은 문서를 두 번 작성하지 않습니다. 화면의 저장 완료 메시지와 파일명을 확인하세요. 저장 연습에는 ‘저장 연습용 — 실제 실습 결과 아님’처럼 정답과 무관한 문장을 쓸 수 있습니다. 제출본에는 연습 글을 실제 결과로 쓰지 않습니다.

HTML은 같은 브라우저에 임시 저장을 시도하지만 기기 설정에 따라 실패할 수 있습니다. 반드시 작성 JSON을 내려받아 별도 보관하세요. 복원할 때 기존 기록이 있으면 확인 후 교체하며 이전 기록은 별도 JSON으로 보관합니다. Colab 런타임이 사라지면 Notebook 파일만으로 결과가 복구되지 않으므로 내려받은 결과 ZIP·원문을 보관하세요.

## 실습과 확인의 범위
가상 상황실·사건·역할만 사용합니다. 실제 경보·통신·장비 조작을 하지 않습니다. AI는 상대 역할의 모의 회신을 할 뿐 실제 권한·서명을 갖지 않습니다. 실제 시각은 지금 발생한 사건에만 기록하고 가상 D일/T 시각과 구분합니다. AI가 예상한 로그·시간·승인을 실제 결과로 제출하지 않습니다.

미션5의 전체 추가 회신·정답은 진행자 전용입니다. 질문에 맞는 자료를 받아야 해당 검증을 할 수 있습니다. 제공받지 못하면 확인·채점 미실시로 기록합니다. 학생용 초안이나 AI 추정을 정답으로 쓰지 않습니다.

미션6은 원본 내 필수·선택 표시가 서로 달라 운영기관 결정 대기입니다. 어떤 조건도 임의로 낮추지 않습니다. 미션9는 실제 최초 실행 기록과 개선 SOP가 필요하며 자료가 없으면 먼저 첫 실행과 개선안을 준비합니다. 하지 않은 선택 미션을 수행했다고 표시하지 않습니다.

원본 예상 합계는 27시간, CMS 편성은 29시간입니다. 실제 소요는 측정 전이며 두 값을 실제 실습 시간으로 쓰지 않습니다. 파일 작성·AI 원문 보관·실제 수행·정량 목표·교관 승인은 각각 별개입니다. ZIP 생성은 교육 통과 인증이 아닙니다.

## 폐쇄망에서 사용하기
HTML은 외부 글꼴·CDN·AI·네트워크 없이 자료 읽기와 작성·JSON/검토 ZIP 내보내기를 제공합니다. Colab·외부 AI 접속이 가능하다고 가정하지 않습니다. AI 대화는 기관 승인 환경이 별도로 필요합니다. 사용할 수 없으면 AI 미실시·필요 환경을 적고 AI 활용 평가를 완료로 표시하지 않습니다.
