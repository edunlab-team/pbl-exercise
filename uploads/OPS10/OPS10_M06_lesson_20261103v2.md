## 진행할 때 확인하세요

세 상황은 각각 별도 건으로 다룹니다. 아래는 연습에 필요한 추가 상태 자료입니다. 여기 적힌 사실을 바탕으로 본인이 후속 조치를 정하세요.

| 항목 | 제공된 상태 자료 |
| --- | --- |
| 건1 | 발령 상태가 남아 있으며 해제 확인 자료는 아직 제공되지 않음 |
| 건2 | 다른 초소 확인 요청 중이며 회신 미제공 |
| 건3 | 오경보 판명 후 별도 정정 보고 대기. 초소 이름 미제공 |
| 통신·인접 역할 | 카드 전달 정상, 인접 역할 추가 회신 대기 없음 |
| 기록·확인 시점·연락 | 이번 작성물과 접수 대장, 다음 확인 D+1일 01:05(가상), 상황장교 역할 |

필수 항목 10번째 칸은 본인이 전달에 필요하다고 판단한 내용을 정하고 이유를 씁니다.

자료에 없는 인계 경과 시각은 미제공으로 표시하고 실제 대화 시각과 구분합니다. 개인 실습에서는 학습자가 인계자, AI가 인수자 역할로 복창·질문합니다. 각 항목이 누락되면 AI가 질문하고 학습자가 보완합니다. AI 회신을 ‘AI 모의 인수 확인’으로 남기며 실제 사람의 서명을 만들지 않습니다.

인계 직후 역할 안내에 따라 상태 재확인 질문 5개를 받고 **학습자가 답합니다.** 개인 방식은 자신이 전달한 내용을 다시 확인하는 실습이며 독립적인 타인의 상황 인식 시험과는 다릅니다. 기록과 대조해 일치 4/5 이상을 확인합니다. 정답을 보며 답한 경우 그 사실을 표시합니다.

| 질문 내용 | 본인의 실제 답변 | 인계 자료와 대조한 근거 | 일치 여부 |
| --- | --- | --- | --- |
| | | | |

원본 필수 항목 10개를 모두 전달해야 누락률이 0%입니다. ‘확인 필요’라는 상태를 정확히 전달한 경우를 누락으로 처리하지 않습니다. 미제공 상태를 없는 사실로 채운 경우는 보완이 필요합니다.
