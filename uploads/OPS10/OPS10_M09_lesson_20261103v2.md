# OPS10 미션9 재발 방지책을 적용한 동일 시나리오 재실행(Re-run) 및 성공률 측정

## 시작과 작성 위치

개선 전과 같은 조건으로 다시 실행합니다. 실제 시간과 오류를 비교해 시간 30% 단축·오류 50% 감소 목표를 평가하며, 미달이나 계산할 수 없는 결과도 그대로 남깁니다.

**용어:** 감소율은 (이전−이후)÷이전×100입니다. 이전 값이 0이면 감소율은 계산할 수 없습니다. 같은 사건·분모·시간 측정법이어야 비교할 수 있습니다.

**열 자료:** 이 미션 안내의 제공 자료와 학생용 Workbook 미션9. **작성할 곳:** 미션9의 결과 작성란 또는 forms/OPS10_M09_forms.md 한 곳입니다. 최종 문서 경로는 eval/ops10_rerun_performance_comparison.md이며 도구가 저장합니다. 코드나 폴더를 직접 만들 필요는 없습니다.

## 미션 상황

당신은 교육용 가상 상황실의 훈련 참여자입니다. 재발 방지책을 적용한 수정 SOP로 같은 시나리오를 다시 실행하고 조치 시간과 오류 발생률 개선을 수치로 확인한다. 개인 실습에서는 최종 판단을 맡고 AI의 다른 역할과 직접 확인·보고·인계를 주고받습니다.

- 자료의 예상 시간: 3시간〔실측값이 아님〕

## 진행할 때 확인하세요

미션4의 사건·역할·회신 조건·시계·보고 대상·적용 단계·오류 집계 방법과 미션8의 수정 SOP를 가져옵니다. 미션4를 하지 않았다면 먼저 실행해 기준 기록을 확보합니다. AI가 최초 실행 기록을 만들어 주는 방식은 사용하지 않습니다.

원본은 사건 순서만 변경할 수 있게 하지만 시간·인계 의존성이 깨질 수 있습니다. 그대로 재실행해도 됩니다. 순서를 바꾸면 서로 독립적인 사건만 바꾸고, 어떤 사건을 바꿨는지와 비교 한계를 적습니다. 역할 교체나 모델 변경도 결과에 영향을 주므로 같은 조건으로 유지하는 것을 우선합니다.

시간 단축률=(1차 평균-재실행 평균)/1차 평균×100. 오류 감소율=(1차 오류-재실행 오류)/1차 오류×100. 원본 오류 합계에는 **오경보 발령+180초 초과 보고+인계 누락 항목**의 세 유형을 모두 포함합니다. 원본 비교표에 빠져 있던 지연 초과 행을 추가합니다.

1차 기준이 0이면 감소율은 ‘계산 불가〔기준 0〕’로 표시합니다. 오류가 0→0이면 무오류 유지라고 설명하되 ‘50% 감소 달성’으로 쓰지 않습니다. 미완료·미측정이 있으면 비교 가능한 범위를 표시하고 완료 기록을 생성하지 않습니다. 개선 목표 미달과 검증 수행 완료는 별도입니다.

| 지표 | 미션4 실제 값·근거 | 미션9 실제 값·근거 | 변화율·계산 과정 | 원본 목표 | 달성·미달·판정 불가 |
| --- | --- | --- | --- | --- | --- |
| 평균 조치 시간 | | | | 30% 이상 단축 | |
| 평균 보고 지연 | | | | 180초 이내 | |
| 오경보 발령 건수 | | | | 오류 합계에 포함 | |
| 180초 초과 보고 건수 | | | | 오류 합계에 포함 | |
| 인계 누락 항목 수 | | | | 오류 합계에 포함 | |
| 오류 합계 | | | | 50% 이상 감소 | |
| SOP 준수율 | | | | 80% 이상 | |
| 미완료·미측정 건수 | | | | 비교 한계 설명 | |

AI에는 익명화된 실제 측정표를 주어 계산·누락을 검토시키고, 본인이 계산식과 원기록을 다시 대조합니다. 연습 효과와 SOP 개선 효과를 이 비교만으로 분리했다고 단정하지 않습니다.


## 학습 활동

### 활동 1 — 같은 조건인지 확인한다

미션4기준 기록과 미션8수정 SOP를 가져옵니다. 사건·역할·응답·평가표·측정 방법을 맞추고 변경이 있으면 기록합니다.

**AI에게 물어볼 예시:**
> 최초 실행 기록과 수정 SOP를 붙입니다. 사건·역할·회신·시계·오류 분모가 같은지 점검표를 만들어 줘.

**AI에게 물어볼 예시:**
> 최초 실행과 같은 [역할/사건/현재 단계]로 재실행합니다. 내 요청에만 답하고 실제 시간·성공 여부를 만들지 마.

**검증·기록:** AI의 핵심 설명 3건 이상을 원자료 번호·문장과 대조합니다. 미션9 작성란의 관련 표와 활동별 진행 기록에 고친 내용·이유를 남기세요. 문서와 실제 대화 원문은 각각 저장합니다.

### 활동 3 — 변화율과 목표 달성을 검증한다

**AI에게 물어볼 예시:**

**검증·기록:** AI의 핵심 설명 3건 이상을 원자료 번호·문장과 대조합니다. 미션9 작성란의 관련 표와 활동별 진행 기록에 고친 내용·이유를 남기세요. 문서와 실제 대화 원문은 각각 저장합니다.
