# LOG04 학습자 시작 안내

01_학습자자료의 LOG04_workbook.ipynb를 엽니다.

미션 1 첨부에서 노트북과 학습자 ZIP을 받아 허용된 폴더에 풉니다. 교육장 Jupyter에서 노트북을 열고 파일 → 다른 이름으로 저장에서 별칭이 든 사본을 만듭니다. 셀은 내용을 담은 칸입니다. 준비 코드 셀을 선택해 Shift+Enter를 누르면 자료 파일을 만듭니다. 기존 작성 파일은 덮어쓰지 않습니다. 오류가 나면 마지막 오류 문장과 셀 이름을 운영 담당자에게 보여 줍니다. 읽는 셀은 더블클릭해 편집하고 Shift+Enter로 다시 표시합니다.

생성형 AI에 질문하는 법: 역할(무슨 일을 도울지), 자료(제공된 가상 내용), 형식(표·목차 등), 조건(추측 금지·분량)을 넣습니다. 한 번에 완벽하지 않아도 됩니다. 빠진 부분을 알려 다시 요청한 뒤 직접 고쳐 씁니다. 개인정보와 실제 업무자료는 넣지 않습니다.

전체 학습계획은 27시간입니다. 미션 4·6·8은 선택이며 산출물과 평가 모두 가점·참고입니다. 최종 판정은 필수 7미션 21문항으로 합니다. 선택 미션을 하지 않았으면 제공된 대체 입력으로 다음 필수 미션을 진행합니다. 초보자는 약 1.3~1.7배를 준비 계획용 추정으로 참고하고 실제 시간은 따로 기록합니다.

종료 전 노트북과 작성 파일을 허용된 위치에 저장하고 다시 열어 확인합니다. 공용 PC의 계정에서 로그아웃합니다. 제출처·마감 일시·시간대는 해당 과제 공지에서 확인합니다. 별도 공지가 없으면 미션별 산출물을 ZIP 하나로 묶어 해당 미션 제출란에 첨부합니다. 통합 문서는 미션별 제목과 위치를 표시합니다. 파일명은 과제ID_미션번호_산출물명과 실제 확장자를 쓰며 개인정보를 넣지 않습니다.

공용 PC에 비밀번호를 저장하지 않으며 로컬 사본은 조직 규정에 따라 정리합니다. 노트북 사본과 reports·직접 작성한 docs·work·outputs를 원래 폴더 구조대로 저장합니다. 실명·개인 식별번호는 파일명에 넣지 않습니다.
