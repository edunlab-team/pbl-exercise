## 2. 데이터 파일 열기

**`.md` 파일**(실습자료·README·치환 시나리오) — 메모장으로 열면 글자 그대로 보입니다. 표는 `|`로 칸이 나뉘어 있습니다.
마우스 오른쪽 버튼 → **연결 프로그램** → 메모장.

**`.csv` 파일**(출처 이력대장·보고 접수대장) — 엑셀 같은 표 계산 프로그램으로 열면 표로 보입니다. 엑셀이 없으면 메모장으로
열어도 됩니다. 이때는 쉼표로 칸이 나뉜 글자 목록으로 보입니다. **첫 줄은 자료 안내문이고 두 번째 줄부터가 표의 머리글입니다.**

## 3. 계산하기

적중률(적중 건수 ÷ 보고 건수 × 100), 접수 시각 차이(분), 근거 점수(가중치 합 − 반대 합 − ? 개수 × 계수),
일치율(일치 칸 ÷ 5 × 100)은 **손으로 계산하지 않아도 됩니다.** 윈도우 시작 메뉴의 "계산기"나 엑셀에 `=6/8*100`처럼 입력하세요.

문제지가 "AI가 아닌 도구로 직접 계산하라"고 하면 **AI에게 계산을 맡기지 말라**는 뜻입니다. AI는 이런 산수를 자주 틀립니다.
시각 차이는 "11:05와 11:40 → 35분"처럼 분으로 적습니다.

## 4. 표 만들기

"표로 정리하세요"는 **특정 프로그램을 요구하지 않습니다.** 엑셀·한글·워드로 만들어도 되고 메모장에 이렇게 적어도 됩니다.

```
보고ID | 등급 코드 | 근거(열 이름=값)
X9 | Q9 | 과거보고건수=0, 재인용원출처=Z0
```

※ 위 표의 값은 **표 모양을 보여 주기 위한 가짜 예시**(X9·Q9·Z0는 데이터셋에 없는 기호)입니다. 실제 값은 `02_데이터셋`에서 직접 확인해 채우세요.

## 수행과 평가의 공통 기준

협업 기록 선택: 사람 조원·평가자·레드팀·심의자가 참여하면 역할(실명 불필요), 제공 자료와 기준, 독립 판단 원문·작성 순서·학습자 대조 결과를 기록한다. 이 경우 아래 AI 세션·프롬프트·응답 인용 조건은 해당 인간 역할의 요청문·판정 원문으로 충족하며 AI 사용을 추가로 요구하지 않는다. 혼자 수행할 때는 안내된 수의 AI 새 대화로 대체하고 프롬프트 전문·응답 원문·도구명·세션 구분을 남긴다. 실제 협업을 할 수 없으면 미수행으로 기록하고 만든 응답을 실제 응답으로 표시하지 않는다.

선별은 결과의 정오를 확인하는 과정이다. 폐기·기각·미반영·불일치가 0건이어도 전체 후보의 자료 ID/열 값 대조표와 유지 이유가 있으면 충족한다. 차이 또는 오류를 일부러 만들지 않는다. 변경 적용 근거와 전후 대조가 있으면 결과가 같아도 인정한다.

응답이 5줄 또는 150자보다 짧으면 실제 응답 전문과 분량을 그대로 기록한다. 최소 분량을 맞추기 위해 줄바꿈·문장을 추가하지 않으며, 요청 자료·판정값·근거와 대조한 기록으로 평가한다.

시간 안내: 학습 계획은 원문 소요시간을 기준으로 한다. 단계별 실제 소요시간은 직접 기록한다. 원문의 카드당 제한·발표 시간 등 성취 조건은 그대로 적용한다. 실제 소요시간은 별도로 측정하고 미측정은 미측정으로 쓴다.

로컬 문서의 판단 시각·선판단·버전은 학습자의 자기기록이며 사후 변경 방지나 본인 인증을 보장하지 않는다. 초기본을 별도 보존하고 수정본에 변경한 값·자료 ID·이유를 적어 앞뒤를 대조한다. 기록 간 모순이나 근거 누락은 보완 요청으로 다루며 잠금이 없다는 사실이나 동일한 문장만으로 부정행위를 추정해 FAIL하지 않는다. 실제 독립 수행 여부는 필요할 때 수행 설명·재시연 등으로 별도 확인한다.

**미션 2 일치 정의:** 세 판정의 출처 신뢰성(A~F)과 정보 정확성(1~6) 두 축이 모두 같아야 일치입니다. 다수결이 아닙니다.

**기록 범위:** 과거보고건수는 D일 이전 전체 보고 이력입니다. 접수대장은 일부만 수록한 표이므로 D-n일 행만 과거 부분집합으로 센 뒤 부분집합이 전체보다 많은지 대조합니다. 당일 보고를 과거 건수에 넣거나, 부분 표가 전체와 같아야 한다고 판정하지 않습니다. 미션 3 K3-B=C3는 접수 시각 연결용이며 본문까지 같은 보고라는 뜻이 아닙니다. AAR A·B는 별개 가상 사례로 시각을 합치지 않습니다.

**시간·변화:** 미측정 값은 미측정으로 남깁니다. 일지 시각 차이를 개인 수행시간으로 만들지 않습니다. 전후 양쪽의 실측값이 있는 같은 사례만 비교하고 포함·제외 ID와 분모를 적습니다. 직접 측정하지 않은 예상 시간은 실제 소요시간으로 기록하지 않습니다.

**카드 운영:** `미션7_순차카드.html`을 브라우저로 열면 인터넷 없이 한 장씩 재생할 수 있습니다. 카드 본문은 실습자료에도 공개되어 있어 실제 블라인드 시험이 아닙니다. 사전열람 여부와 일시정지·목표 초과 사유를 기록합니다. 원자료를 고치지 않고 순차 표시만 합니다.

**최종 부록:** 앞 미션 원본을 보존하고 미션 8 변경이 반영된 최종 개정본을 배치합니다. 원본·개정본·변경이력을 구별합니다. 치환 사례는 분기 1부터 중단 분기까지 조건·예/아니오·자료 ID와 값을 남깁니다. 같은 분기라는 이유만으로 결함으로 판정하지 않습니다.

**원문 성취 기준:** 미션 2 Q1은 5건 중 4건 이상 일치, 미션 7 Q1은 80% 이상입니다. 미달이면 Q1은 보완 필요로 두고, 성실한 시도·원인 분석·재수행 증거는 Q2에서 별도로 평가합니다. 기록만으로 원문 수치 기준을 충족했다고 판정하거나 일치를 꾸며내지 않습니다.

멈춘 분기: 예/아니오와 관계없이 보류·추가 확인·전문 검토로 넘긴 지점의 분기 번호다. 조건·예/아니오·근거·후속 조치를 함께 적는다. 중단 뒤 분기는 미도달로 표시한다.

## 반제품 예제 프롬프트 ①~⑤ (빈칸을 데이터셋 값으로 채우는 것이 과제입니다)

빈칸을 일반론으로 채우면 제약으로 인정되지 않습니다. 모든 입력은 [교육용가상자료] 데이터셋만 사용합니다.

### ① 미션 1 — 약점 후보 발산 (구조화 출력 + 범위 제약)
```
다음 보고 다섯 건(C1~C5)만 보고 작업해. (범위 제약)
[보고 원문] ← 실습자료 미션 1 '가. 제공 자료' 표를 그대로 붙여넣기
출력 형식: 유형 | 약점 후보 | 확인되는 보고(C#) 또는 '확인 안 됨' (구조화 출력)
규칙:
- (규칙 1) ← 보고에서 확인되지 않는 약점을 어떻게 표시하게 할지 채우세요
- (규칙 2) ← 약점을 '~할 수 있다'가 아니라 어떤 꼴의 문장으로 쓰게 할지 채우세요 (예: '~가 없다', '~가 미확인이다')
유형당 후보 ( )개 이하로.
```

### ② 미션 2 — 등급 판정 (역할 지정 + 기준 제약, 조원 대체)
```
너는 가상 조직 A팀의 분석관이야. (역할 지정)
아래 판정 기준 문구만 사용해 R1~R5의 등급 코드(출처 신뢰성 A~F + 정보 정확성 1~6, 예: B2)를 매겨. (기준 제약)
[판정 기준 12칸] ← 내가 쓴 6×6 판정 기준 전문
[평가 지표표] ← 작성 서식 1
[보고 R1~R5] ← 실습자료 미션 2 제공 자료 1
[출처 이력대장 해당 행] ← H-1·I-1·O-1·S-1·H-2 행을 그대로
규칙:
- (규칙 1) ← 출처 설명에 없는 사실을 추정하지 못하게 하는 문장을 채우세요
- (규칙 2) ← 재전달·재인용 보고를 어떻게 다루게 할지 채우세요 (README 독립 출처 규칙 활용)
출력 형식: R# | 등급 코드 | 근거(열 이름=값)
```
※ 이 프롬프트는 **내 판정을 먼저 적은 뒤** 두 도구(또는 새 세션 2개)에 각각 넣습니다.

### ③ 미션 3 — 상충 분석 (단계적 사고 + 발산 후 선별)
```
아래 상충 쌍 (K#)의 보고 A·B와 접수대장 행만 보고, 반드시 이 순서로 답해. (단계적 사고)
1) 상충 유형을 시각·위치·수량·주체·의미 중에서 고른다
2) 원인 후보를 5개 낸다 (출처 오류·시차·허위·재인용 등)
3) 후보마다 어떤 자료로 확인할 수 있는지 적는다
[보고 A·B] ← 실습자료 미션 3 제공 자료 1의 해당 행
[접수대장 행] ← 보고_접수대장.csv의 해당 두 행 그대로
규칙:
- (규칙 1) ← 접수대장에 없는 시각을 쓰지 못하게 하는 문장을 채우세요
- (규칙 2) ← 결론(통과 여부)을 말하지 못하게 하는 문장을 채우세요
```

### ④ 미션 4·8 — 레드팀 (역할 반전)
```
네 역할은 레드팀이야. 작성 팀의 기준이 특정 출처에 유리하거나 단정으로 흐르는 지점을 반박해. (역할 반전)
[기준서 조항] ← 미션 4: 서식 1·2 전문 / 미션 8: 미션 2 서식 3 + 미션 4 서식 2 + 미션 5 서식 1·2 전문 (조항 번호 포함)
[사례] ← 미션 4: S1~S3 / 미션 8: AAR 일지 A·B
규칙:
- (규칙 1) ← 기준서·자료 밖의 사실을 지어내지 못하게 하는 문장을 채우세요
- (규칙 2) ← 반박마다 어느 조항 번호를 겨냥하는지 붙이게 하는 문장을 채우세요
- 법적 쟁점은 '법무 검토 필요'로만 표시해
반박 ( )건 이상, 각 반박에 '이 근거만으로 단정할 수 있는가'를 포함해.
```

### ⑤ 미션 7 — 평가자 2 독립 채점 (독립 세션 + 루브릭 제약)
```
[새 채팅에서 시작] 너는 평가자 2야. 아래 루브릭만 사용해 판단표를 5영역 채점해. (루브릭 제약)
등급 점수: 탁월 4 · 우수 3 · 보통 2 · 미흡 1
[루브릭 전문] ← 작성 서식 1의 20칸 전부 (요약 금지)
[판단표 전문] ← 카드 D1~D7 판단표 전부

- (규칙 2) ← 영역마다 근거가 된 카드 번호를 적게 하는 문장을 채우세요
출력 형식: 영역 | 점수 | 근거 카드 번호 | 한 줄 이유
```
※ 내 채점을 먼저 적고 시각을 남긴 뒤 실행합니다. 판단표를 만든 채팅에서 이어서 하지 않습니다.
