# MOV02_M03 실습 및 검증 가이드
## 다익스트라 기반 최단거리 보급 경로 탐색 1차 Baseline 알고리즘 구현

### 1. 미션 목표
- 보급소에서 전방 지원 부대까지 소요시간 기반 다익스트라(Dijkstra) Baseline 최단 경로를 탐색합니다.
- 하드코딩 없이 외부 설정 문자열(YAML)로 분리된 15종 군 수송 검증 규칙 엔진을 구축합니다.
- 15종 규칙 판정을 50ms 이내(평균 0.1ms 수준)에 완료하고 9종 경계 조건 단위 테스트 100% PASS를 달성합니다.

### 2. 가상 데이터셋 안내
- 파일명: `mov02_m03_dataset.json`
- `rules_config`: 규칙 엔진 외부 설정값 (최대 비포장 비율 0.5, 우회 계수 2.5, 최대 위협 구간 1 등)
- `rule_catalog`: 15종 군 수송 검증 규칙 명세(R01~R15)
- `test_requests`: Baseline 탐색용 수송 요청 6건
- `boundary_test_cases`: 9종 극단 경계 조건(적재량 일치, 기한 0분 여유, 고립 노드 등) 테스트 케이스

### 3. 검증 지표
- 15종 검증 규칙 코딩 및 평균 처리 지연시간 50ms 이하 충족 (실측 ~0.1ms)
- scipy 다익스트라 대비 비용 계산 일치율 100% 확인
- 9종 경계 조건 단위 테스트 100% 통과
