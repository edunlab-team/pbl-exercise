# [PRC01_M05] 계약 위험 점수 산출 및 규정 위반 가능성 신뢰도 지수 엔진 개발 실습 및 검증 가이드

## 1. 미션 개요 및 핵심 목표
* **미션 식별자:** `PRC01_M05`
* **필수 산출물:** `src/ui/prc01_app.py`
* **핵심 달성 목표:** ROC-AUC 0.954 달성, 고위험군 위반율 94% vs 관심군 5% 변별력 확보, 4대 화면 UI 구축

---

## 2. 세부 실습 수행 절차 (GuideSteps 연계)
* 1. 룰 적중 내역과 NLP 위험 조항 수를 결합한 로지스틱 회귀 앙상블 위험 점수(0~100) 산출
* 2. 룰-모델 일치도 및 예측 확률 분별력 기반 신뢰도 지수(0~100) 설계
* 3. 별도 검증셋 대상 ROC Curve, AUC(0.954) 및 등급별 실제 위반율 통계 분석
* 4. 4대 핵심 뷰(입력요약, 성능분포, 고위험목록, 결과요약) 인터랙티브 UI 구현

---

## 3. 평가 및 PASS/FAIL 판정 기준 (Checkpoints)
- [ ] **[필수]** 위험 점수가 0~100점으로 정규화되어 산출되는가?
- [ ] **[필수]** 신뢰도 지수가 저신뢰도 건을 효과적으로 식별하는가?
- [ ] **[필수]** 검증셋 ROC-AUC가 0.90 이상인가?
- [ ] **[필수]** 4대 화면 인터랙션이 실무자 중심 우선순위 필터링을 지원하는가?
