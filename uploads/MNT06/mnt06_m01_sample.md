# [MNT06_M01] 3D CAD 모델 및 소재 물성 데이터 정의 실습 가이드

## 1. 미션 개요
폐기율이 높은 수리부속 가운데 야전 3D 프린팅 대체 제작 후보 부품을 선별하기 위해 3D CAD 메쉬 정보와 금속·폴리머 소재 물성 데이터를 표준 규격으로 정의하고 입력 무결성을 검증합니다.

## 2. 주요 데이터셋 안내 (`mnt06_m01_dataset.json`)
- `schema_fields`: 26개 표준 군수·제조 피처 정의 및 단위 규격
- `injected_errors_sample`: 유효성 검증기 방어력 테스트를 위한 5건의 고의 주입 결함 데이터

## 3. 핵심 수행 단계
1. **데이터 딕셔너리 정립**: 국방 표준 코드(가상 NIIN/FSC)를 포함한 20개 이상 피처 정의
2. **업무 프로세스 맵**: 식별부터 CAD 확보, 승인(HITL), 장착 시험까지 7단계 E2E 업무 흐름도 작성
3. **스키마 검증기 구현**: 결측치, 음수, 범위 초과 등 주입 결함 5건 100% 검출 확인
4. **심화 튜닝**: `humidity_pct` 환경 피처 확장 및 경계 초과 검출 단위 테스트

## 4. 핵심 판정 기준
- 피처 20개 이상(목표 26개) 정의 완료
- 스키마 검증기 정상 샘플 오류 0건, 주입 결함 5건 100% 검출
- 산출물: `docs/mnt06_logistics_domain_spec.md` 및 데이터 딕셔너리
