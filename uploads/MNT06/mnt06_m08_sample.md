# [MNT06_M08] 부품 50~500종 일괄 부하 테스트 실습 가이드

## 1. 미션 개요
전시 또는 긴급 정비 상황을 가정하여 복잡 형상 부품 50종(최대 500종)의 대규모 동시 요청에 대한 신뢰성 일괄 평가 스트레스 테스트를 수행하고 서비스 회복 탄력성을 검증합니다.

## 2. 주요 데이터셋 안내 (`mnt06_m08_dataset.json`)
- `batch_load_benchmarks`: 50종(0.37초)부터 500종(1.89초)까지 2초 이내 처리 벤치마크
- `trichotomy_classification`: 경보-보류-정상 삼분법 분류 및 확정 판정 정확도 98.6%
- `fail_safe_fallback`: 모델 장애 주입 시 무중단 간이 규칙 폴백 검증 데이터

## 3. 핵심 수행 단계
1. **일괄 부하 스트레스 시험**: 500종 배치 처리 시 2초 이내 화면 렌더링 유지 확인
2. **손상 데이터 격리**: 결함 레코드를 안전하게 분리하여 시스템 다운 방지
3. **Fail-safe 간이 규칙 전환**: 모델 장애 시 베이스라인 규칙으로 즉각 전환 검증
4. **심화 튜닝**: 비동기 워커 및 동시성 파라미터 최적화

## 4. 핵심 판정 기준
- 50종 처리 및 화면 생성 시간 2초 이내(달성 0.37초)
- 확정 판정(경보) 정확도 95% 이상(달성 98.6%)
- 산출물: `src/dashboard/mnt06_app.py`
