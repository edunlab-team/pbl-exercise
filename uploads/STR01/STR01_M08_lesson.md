# STR01 M08 — 전면전 발발 모의 전 부대 보급품 동시 급감 스트레스 시뮬레이션

## 상황과 목표

가상 KPI 분석 담당자로서 부대별 재고·소모·목표 DOS와 결핍 경보를 분석합니다. 전 부대의 소모가 동시에 늘고 보급이 줄어드는 가상 충격 시나리오로 경보 엔진의 스트레스 시뮬레이션을 수행한다.

## 원본 수행 범위와 평가

- 원본 선택 미션. 전체 실습에서는 수행합니다.
- 원본·새 Git 편성 3시간〔실측값이 아님〕
- 원본 수행: 소모를 1.5배, 2배, 3배로 키우고 보급량을 절반으로 줄이는 충격을 12일간 가정해 재고를 다시 계산한다. 모델만 쓸 때와 단기 소모 기반 안전장치를 더했을 때의 경보 발령 정확도와 미탐률을 비교하고, 상황판 1회 갱신 시간을 50회 반복 측정한다. 이는 교육용 가상 모델이며 실제 작전 계획과 무관하다.
- [선택] 충격 시나리오·로딩 시간  — 대시보드 로딩 시간 2초 이내, 경보 발령 정확도 95% 이상이며, 의사결정 지원에 맞게 경보 위계가 시각적으로 분명한가.
- 원본 산출물: src/dashboard/str01_app.py (Streamlit/Dash 등)

## 제공 자료

- 공통 작성 안내·Colab 실행 안내·실습 노트북·실습프로젝트 ZIP.
- 코드: `src/dashboard/str01_app.py`. 핵심 함수를 구현·저장하고 첫 실행 후 AI와 추가 변경합니다.
- 데이터: 프로젝트 `data/README.md`를 먼저 읽습니다.원장9개 필드·딕셔너리11개 필드·모델 입력16개·추가 후보8개를 구분합니다.
- 시작 양식: `STR01_M08_forms.md` 및 docs/reports의 미완성 작성 틀.


## 이번 미션의 핵심 구현

- 파일: `src/dashboard/str01_app.py`
- 함수: `evaluate`
- 계약: d,guard → 4등급 정확도·경보 여부 정확도·미탐률·전체 표본 수·정답 등급. 양수 재고 예측과 이미 재고0 관찰을 모두 분모에 포함하고 실제 양성0 미탐률은 NaN이다. 규칙 경보의 효과와 예측 모델의 성능을 구분한다.
- 반복 데이터 생성 함수는 제공 코드입니다. 제공 상수·필드 정의를 참조해 M1의 validate_ledger를 구현합니다.
- 핵심 구현 후 첫 성공 실행을 보존하고 기존 추가 변경 과제를 수행해 전후 비교합니다. 실제 AI 대화·본인 근거 검토·오류 수정 이유를 남깁니다.

## 학습 활동

### 활동1 — 계획과 사전 판단

원본 목표·기본 코드·자료를 읽고 기간을 늘리는 코드와 평가 구간을 함께 어떻게 변경할까?를 판단합니다. AI에 맡길 범위·자료·제약·확인 방법을 정합니다.

### 활동2 — AI와 코드 변경

기준 코드를 실행하고 결과를 보존한 뒤 AI와 기획을 구현에 적용합니다. 변경 과제: 충격 기간을 12일에서 25일로 늘리고 평가 구간도 함께 명시해 성능을 비교합니다. 경보 여부 정확도·4등급 정확도·미탐의 분모를 구분하고 관찰 재고 0건도 포함합니다.

### 활동3 — 근거 대조와 재실행

수정 코드를 저장하고 재실행합니다. 이미 결핍된 건을 빼서 정확도를 높이거나 경보 여부와 4등급을 혼동하지 않았는가? AI 설명·코드 선택3건 이상을 자료·실행과 대조하고 보완 답변도 다시 확인합니다.

### 활동4 — 최종 판단과 산출물

원본 평가 기준·변경 전후 코드·실제 AI 대화·보고서를 제출합니다. 정량 달성, 미측정, 문서 작성과 교관 승인 상태를 구분해 최종 판단을 남깁니다.

## 해석·검증 주의점

시험은 추상적인 소모 배율과 보급 50% 감소입니다. 정확도 분모에는 관찰 재고 0건을 포함하며 이들은 모델 예측 성공이 아니라 규칙 처리입니다. 경보 여부 일치율 95%와 4등급 일치율은 다릅니다. 50회 갱신 시간은 피처 생성·예측·집계·문자열 생성의 로컬 시간이며 웹 서비스 전체 로딩 시간이 아닙니다. 기간을 늘리면 make_samples의 hi도 조정하고 종료 범위를 기록합니다.
