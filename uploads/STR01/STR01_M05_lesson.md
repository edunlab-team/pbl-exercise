# STR01 M05 — 결핍 심각도 지수 산출 및 다단계 결핍 조기경보(주의/경계/심각) 엔진 개발

## 상황과 목표

가상 KPI 분석 담당자로서 부대별 재고·소모·목표 DOS와 결핍 경보를 분석합니다. 결핍 심각도 지수를 산출하고 주의·경계·심각 3단계 결핍 조기경보 엔진을 개발한다.

## 원본 수행 범위와 평가

- 원본 필수 미션. 전체 실습에서는 수행합니다.
- 원본·새 Git 편성 3.5시간〔실측값이 아님〕
- 원본 수행: 그래디언트 부스팅 모델로 결핍 위험 일수를 예측해 기준 모델과 MAE, RMSE, R2를 비교한다. 예상 결핍 일수와 목표 재고 대비 재고 비율로 0~100 결핍 심각도 지수를 만들고, 예상 일수 구간별로 주의, 경계, 심각 경보를 발령한다. 혼동표로 등급 정확도, 미탐률, 오탐률과 템포 급변 구간의 안정성을 확인한다.
- [필수] 심각도 지수·3단계 경보  — 기준 모델 대비 MAE/RMSE 오차율 20% 이상 개선, R2 0.85 이상이며, 템포가 불규칙하게 변하는 구간에서도 예측이 안정적인가.
- 원본 산출물: src/models/str01_advanced_model.py

## 학습 활동

### 활동1 — 계획과 사전 판단

원본 목표·기본 코드·자료를 읽고 모델 오차 개선과 경보 미탐 개선은 같은가?를 판단합니다. AI에 맡길 범위·자료·제약·확인 방법을 정합니다.

### 활동2 — AI와 코드 변경

기준 코드를 실행하고 결과를 보존한 뒤 AI와 기획을 구현에 적용합니다. 변경 과제: 경보 구간 2.5/4.5/7.5일을 3/5/8일로 바꿔 동일 시험집합에서 혼동표·미탐·오탐과 급변 구간 오차를 비교합니다. 시험 정답으로 모델을 재학습하지 않습니다.

### 활동3 — 근거 대조와 재실행

수정 코드를 저장하고 재실행합니다. 정량 목표와 급변 구간 성능을 각각 판정했는가? AI 설명·코드 선택3건 이상을 자료·실행과 대조하고 보완 답변도 다시 확인합니다.

### 활동4 — 최종 판단과 산출물

원본 평가 기준·변경 전후 코드·실제 AI 대화·보고서를 제출합니다. 정량 달성, 미측정, 문서 작성과 교관 승인 상태를 구분해 최종 판단을 남깁니다.

## 해석·검증 주의점

같은 학습·시험 자료로 릿지/GBR을 비교합니다. MAE/RMSE 개선 각각 20%와 R2≥0.85를 따로 판정합니다. 심각도 지수는 설계 점수이지 확률이 아닙니다. 세 경보 등급 외 정상 상태가 있어 혼동표는 4등급입니다. 미탐은 실제 경계 이상을 분모로, 오탐은 실제 정상 상태를 분모로 합니다. 급변 구간의 표본 수·오차도 제출합니다.
