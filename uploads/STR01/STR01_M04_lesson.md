# STR01 M04 — 작전 템포 변동 및 기상 악화 연계 부대별 결핍 위험 일자(Stockout Date) 정밀 예측 고도화

## 상황과 목표

가상 KPI 분석 담당자로서 부대별 재고·소모·목표 DOS와 결핍 경보를 분석합니다. 작전 템포 변동과 기상 예보를 반영한 파생 피처로 부대별 결핍 위험 일자(Stockout Date)를 예측하는 기준 모델을 만든다.

## 원본 수행 범위와 평가

- 원본 선택 미션. 전체 실습에서는 수행합니다.
- 원본·새 Git 편성 3시간〔실측값이 아님〕
- 원본 수행: 사전 계획 템포, 다음 7일 악천후 예보, 최근 소모 추세, 보급 후 경과일 같은 파생 피처 13개를 설계하고 이유를 한 줄씩 설명한다. 릿지 회귀 기준 모델과 단순 DOS 방식을 MAPE로 비교하고, 계획 템포 +30%와 악천후 50%를 가정했을 때 예측이 얼마나 바뀌는지 시나리오로 확인한다.
- [선택] 파생 피처·기준 모델  — 파생 피처 10개 이상을 생성하고 기준 모델 MAPE 25% 이하를 달성했으며, 피처 설계가 군수 실무에서 납득 가능한 논리를 갖는가.
- 원본 산출물: src/features/str01_feature_engineering.py 및 기준 모델

## 이번 미션의 핵심 구현

- 파일: `src/features/str01_feature_engineering.py`
- 함수: `make_samples`
- 계약: d,lo=21,hi=125 → 과거 관측·사전 계획·가상 완전예보로 만든16개 피처와 메타데이터·H. H는 향후 보급 없음 조건의 소진일수이며 모델 입력에 넣지 않는다. t0+H가 학습 기준일 이내인 표본만 학습한다.
- 반복 데이터 생성 함수는 제공 코드입니다. 제공 상수·필드 정의를 참조해 M1의 validate_ledger를 구현합니다.
- 핵심 구현 후 첫 성공 실행을 보존하고 기존 추가 변경 과제를 수행해 전후 비교합니다. 실제 AI 대화·본인 근거 검토·오류 수정 이유를 남깁니다.

## 해석·검증 주의점

파생 피처 13개와 전체 입력 16개를 구분합니다. 학습 기준일 90일까지 정답이 확정된〔t0+H≤90〕표본만 사용합니다. 시험은 t0>90입니다. H=0 건은 예측 회귀의 분모에 없고 이미 결핍 규칙으로 분리합니다. plan은 미리 알고 있는 계획 시나리오, wx_fc는 원본의 완전예보 가정입니다. 실제 미래 기상 실적을 현시점 입력으로 쓰는 검증으로 일반화하지 않습니다.
