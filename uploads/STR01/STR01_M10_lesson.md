# STR01 M10 — 전술 부대 보급 수준(DOS) 실시간 모니터링 및 결핍 경보 시스템 통합 완성

## 상황과 목표

가상 KPI 분석 담당자로서 부대별 재고·소모·목표 DOS와 결핍 경보를 분석합니다. 데이터 검증부터 예측, 경보, 승인 대기 분리, 가시화까지 이어지는 DOS 모니터링·결핍 경보 시스템과 자동 재학습 파이프라인을 완성한다.

## 원본 수행 범위와 평가

- 원본 필수 미션. 전체 실습에서는 수행합니다.
- 원본·새 Git 편성 3.5시간〔실측값이 아님〕
- 원본 수행: 환경 점검 후 데이터를 검증하고 피처를 만들어 예측·경보를 산출한다. 경계 이상 건과 이미 재고가 0인 건을 모두 군수처장 승인 대기로 분리하며 자동 집행하지 않는다. 주기마다 도전 모델을 학습해 보류 구간 성능이 2% 이상 좋아질 때만 교체하는 재학습 파이프라인을 4회 실행하고, 운영 가이드 9장 목차와 자체 점검표, 브리핑 요약을 출력한다.
- [필수] 통합 모니터링·자동 재학습  — 자동 재학습 파이프라인이 정상 실행되고 최종 문서가 100% 완비되었으며, 운영이 지속 가능하고 군수 정보체계와 연동하기 쉬운 구조인가.
- 원본 산출물: docs/str01_operations_guide.md 및 pipeline/str01_retrain.py

## 제공 자료

- 공통 작성 안내·Colab 실행 안내·실습 노트북·실습프로젝트 ZIP.
- 코드: `pipeline/str01_retrain.py`. 핵심 함수를 구현·저장하고 첫 실행 후 AI와 추가 변경합니다.
- 데이터: 프로젝트 `data/README.md`를 먼저 읽습니다.원장9개 필드·딕셔너리11개 필드·모델 입력16개·추가 후보8개를 구분합니다.
- 시작 양식: `STR01_M10_forms.md` 및 docs/reports의 미완성 작성 틀.


## 이번 미션의 핵심 구현

- 파일: `pipeline/str01_retrain.py`
- 함수: `should_promote`
- 계약: mae_old,mae_new,min_improvement=.02 → 교체 여부 bool. 유한한0이상 오차를 검사하고 후보가 엄격히 작으면서 상대2% 이상 개선해야 교체한다. 동률·현행0은 유지하고 NaN/빈 평가를 거부한다.
- 반복 데이터 생성 함수는 제공 코드입니다. 제공 상수·필드 정의를 참조해 M1의 validate_ledger를 구현합니다.
- 핵심 구현 후 첫 성공 실행을 보존하고 기존 추가 변경 과제를 수행해 전후 비교합니다. 실제 AI 대화·본인 근거 검토·오류 수정 이유를 남깁니다.

## 학습 활동

### 활동1 — 계획과 사전 판단

원본 목표·기본 코드·자료를 읽고 모델 교체 비교 당시 정답 H를 이미 알 수 있는 표본만 썼는가?를 판단합니다. AI에 맡길 범위·자료·제약·확인 방법을 정합니다.

### 활동2 — AI와 코드 변경

기준 코드를 실행하고 결과를 보존한 뒤 AI와 기획을 구현에 적용합니다. 변경 과제: 교체 문턱을 2%에서 0%로 바꿔 같은 4회 재생 실행의 선택과 오차를 비교합니다. 운영 문서 9개 장의 본문을 작성하고 검증 실패·이미 결핍·승인 대기 경로를 점검합니다.

### 활동3 — 근거 대조와 재실행

수정 코드를 저장하고 재실행합니다. 목차 존재·실행 성공·문서 내용 완비·승인 완료를 구분했는가? AI 설명·코드 선택3건 이상을 자료·실행과 대조하고 보완 답변도 다시 확인합니다.

### 활동4 — 최종 판단과 산출물

원본 평가 기준·변경 전후 코드·실제 AI 대화·보고서를 제출합니다. 정량 달성, 미측정, 문서 작성과 교관 승인 상태를 구분해 최종 판단을 남깁니다.

## 해석·검증 주의점

재학습은 104/111/118/125일의 과거 재생입니다. 도전 학습은 기준일-14까지 정답이 확정된 표본, 보류 평가도 기준일까지 정답 확정된 표본만 씁니다. 2% 이상 개선한 경우 교체하고 같은 점수면 유지합니다. 승인 대기 목록은 실제 승인·집행 완료가 아닙니다. 문서 목차 9개만으로 완료가 되지 않습니다. 시작 문서 FAIL을 유지하며 9개 장 본문 작성 후 구조·내용을 검토합니다. 실패 로그를 기록해도 필수 검증 실패 시 예측은 중단합니다.
