# MNT02 M04 — 시계열 머신러닝(Prophet/LSTM) 기반 결전 대비 야전 부품 수요 예측 모델 고도화

## 상황과 목표

가상 부품 데이터 분석 담당자로서 수요·단종 상태·재고 근거를 분석합니다. 시계열 머신러닝으로 결전 대비 야전 부품 수요 예측 모델을 고도화한다(Prophet/LSTM은 실행 환경 제약으로 포아송 그래디언트 부스팅으로 대체).

## 원본 수행 범위와 평가

- 원본 선택 미션. 전체 실습에서는 수행합니다.
- 원본·새 Git 편성 3시간〔실측값이 아님〕
- 원본 수행: 지연값·이동평균·변동성·계절지수·훈련 계획·운용시간 등 예측 시점 이전 정보로 파생 피처 10개 이상을 만든다. 확장 창 시계열 교차검증으로 MAPE를 확인하고 순열 중요도로 차원 축소 후보를 고른다. 작전 템포 1.5배 시나리오에서 다음 달 수요 증가가 큰 품목과 그 생산 상태를 확인한다.
- [선택] 수요 예측 모델  — 파생 피처 10개 이상, 시계열 교차검증 평균 MAPE 25% 이하, 피처 중요도 근거와 결전 대비 수요 증가 품목을 제시했는가.
- 원본 산출물: src/features/mnt02_feature_engineering.py 및 기준 모델

## 이번 미션의 핵심 구현

- 파일: `src/features/mnt02_feature_engineering.py`
- 함수: `make_features`
- 계약: hist DataFrame → 품목별 과거 수요와 제공된 계획 변수로 만든 파생 피처 DataFrame. lag/이동평균/계절지수는 미래 수요를 참조하지 않는다. 당월 운용시간은 사전 계획값이라는 가정을 명시한다.
- 반복 데이터 생성 함수는 제공 코드입니다. M1의 check는 제공하고 validate를 구현합니다.
- 핵심 구현 후 첫 성공 실행을 보존하고 기존 추가 변경 과제를 수행해 전후 비교합니다. 실제 AI 대화·본인 근거 검토·오류 수정 이유를 남깁니다.

## 학습 활동

### 활동1 — 계획과 사전 판단

원본 목표·기본 코드·자료를 읽고 한달앞예측의계획값과미래 실적을 어떻게 나눌까?를 판단합니다. AI에 맡길 범위·자료·제약·확인 방법을 정합니다.

### 활동2 — AI와 코드 변경

핵심 함수를 구현하고 첫 실행 결과를 보존한 뒤 AI와 기획을 구현에 적용합니다. 변경 과제: ma6·trend_t·lag2 제외 전후 교차검증을 비교하고 예측 시점에 알려진 계획 정보와 실측 정보를 구분한다.

### 활동3 — 근거 대조와 재실행

수정 코드를 저장하고 재실행합니다. 피처 제외 실험에서같은 확장창·기간·분모를 유지했는가? AI 설명·코드 선택3건 이상을 자료·실행과 대조하고 보완 답변도 다시 확인합니다.

### 활동4 — 최종 판단과 산출물

원본 평가 기준·변경 전후·코드·실제 AI 대화·보고서를 제출합니다. 미달·미측정·실제 승인 상태를 구분합니다. Prophet/LSTM이라는 원본 제목을 유지하되 실제 구현은 원본대로 포아송 HistGradientBoosting입니다. 월별 한달 앞 rolling 평가와 6개 월 고정 기점 예측을 구분합니다. 당월 운용시간은 사전에 알려진 계획값이라는 가정이 필요하고 실제 당월 실적이면 누수입니다.
