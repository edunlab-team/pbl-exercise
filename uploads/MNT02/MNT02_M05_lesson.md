# MNT02 M05 — 적정 안전재고량 산출 및 결품 위험 지수(Stockout Risk) 엔진 개발

## 상황과 목표

가상 부품 데이터 분석 담당자로서 수요·단종 상태·재고 근거를 분석합니다. 앙상블 수요 예측으로 품목별 적정 안전재고·재주문점을 산출하고 단종 위험을 반영한 결품 위험 지수(Stockout Risk) 엔진을 개발한다.

## 원본 수행 범위와 평가

- 원본 필수 미션. 전체 실습에서는 수행합니다.
- 원본·새 Git 편성 3.5시간〔실측값이 아님〕
- 원본 수행: 포아송 그래디언트 부스팅과 랜덤포레스트를 앙상블하고 가중치는 학습 기간 안의 검증 구간으로 고른다. Hold-out 6개월에서 기준 모델(MA3) 대비 MAE/RMSE 개선율과 R2를 계산한다. 예측 오차로 서비스 수준 95% 안전재고와 재주문점을 구하고, 리드타임 동안의 결품 확률에 단종 상태·단일 공급업체·대체품 부재를 결합해 위험 지수와 등급을 산출한다.
- [필수] 안전재고·위험 지수  — 기준 모델 대비 MAE/RMSE 20% 이상 개선, R2 0.85 이상, 품목별 안전재고·재주문점과 위험 등급(경보·주의·관찰)을 산출했는가.
- 원본 산출물: src/models/mnt02_advanced_model.py, 안전재고·위험 지수표

- 파일: `src/models/mnt02_advanced_model.py`
