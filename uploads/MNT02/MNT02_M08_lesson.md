# MNT02 M08 — 전시 작전 템포 증가 모의 부품 수요 300% 폭증 시뮬레이션 부하 테스트

## 상황과 목표

가상 부품 데이터 분석 담당자로서 수요·단종 상태·재고 근거를 분석합니다. 전시 작전 템포 증가로 부품 수요가 평시의 300%로 폭증하는 상황을 모의해 결품 경보와 대시보드의 성능을 부하 시험한다.

## 원본 수행 범위와 평가

- 원본 선택 미션. 전체 실습에서는 수행합니다.
- 원본·새 Git 편성 3시간〔실측값이 아님〕
- 원본 수행: 품목군별 실제 증가 배수가 다른 3개월 폭증 상황을 반복 모의하고, 평시 예측·모델 직접 예측·작전 템포 계수 보정·월별 실적 반영 방식의 경보 정확도와 결품 탐지율을 비교한다. 트리 모델이 학습 범위 밖 수요를 외삽하지 못하는 한계를 확인한다. 품목 수 50배 부하에서 대시보드 갱신 시간을 측정한다.
- [선택] 수요 폭증 부하 시험  — 대시보드 갱신 2초 이내, 경보 정확도 95% 이상(미달 시 원인과 경계 구간 처리 방안 제시), 결품 탐지율을 함께 제시했는가.
- 원본 산출물: src/dashboard/mnt02_app.py, 부하 시험 결과표

## 이번 미션의 핵심 구현

- 파일: `src/dashboard/mnt02_app.py`
- 함수: `refresh`
- 계약: Xb,it,st → (품목군별 위험 집계,품목별 위험표). 제공 ens/SURGE와 정책·위험 함수를 연결한다. 50배는 복제 품목 부하이며 실제 독립 품목 정확도와 웹 화면 갱신 시간이 아니다.
