# MNT02 M01 — 야전 정비창 수리부속 청구/출고 이력 및 장비 가동률 데이터셋 스키마 정의

## 상황과 목표

가상 부품 데이터 분석 담당자로서 수요·단종 상태·재고 근거를 분석합니다. 야전 정비창 수리부속 청구/출고 이력, 품목·공급망(단종 상태 포함), 장비 가동률 자료의 스키마와 업무 프로세스 맵, 데이터 딕셔너리를 정의한다.

- 원본 필수 미션. 전체 실습에서는 수행합니다.

- [필수] 데이터 스키마 정의  — 업무 프로세스 맵 작성 완료, 필드 20개 이상 정의, 정상 샘플 검증 오류 0건, 주입 오류 전부 검출, 예측 대상(수요)과 단종 위험 분석 목표가 명확한가.
