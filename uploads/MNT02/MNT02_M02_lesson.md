# MNT02 M02 — 결측치 보정, 계절성 수요 분리 및 수리부속 품목코드(NSN) 정제 전처리 모듈 구현

## 상황과 목표

가상 부품 데이터 분석 담당자로서 수요·단종 상태·재고 근거를 분석합니다. 청구 기록의 결측치 보정, 계절성 수요 분리, 품목코드(NSN) 정제를 수행하는 전처리 모듈을 구현한다.

## 원본 수행 범위와 평가

- 원본 필수 미션. 전체 실습에서는 수행합니다.
- 원본·새 Git 편성 2시간〔실측값이 아님〕
- 원본 수행: 중복 청구 제거, NSN 형식 정규화와 미등록 NSN 격리, 날짜·단위 통일, 음수·과다 수량 보정 등 정제 규칙 10종 이상을 적용하고 긴급 불출은 이상치로 지우지 않는다. 전산 장애로 빠진 월은 계절성 보간으로 채우고 단순 선형 보간과 오차를 비교한다. 정제 전후 기술통계와 품목군별 계절지수를 제시한다.
- [필수] 전처리 모듈  — 정제 규칙 10종 이상 적용, 정합성 검증 통과율 100%, 긴급 불출 보존, 계절성 보간이 단순 보간보다 오차가 작은지 확인했는가.
- 원본 산출물: src/etl/mnt02_data_cleansing.py 및 정제 품질 보고서
