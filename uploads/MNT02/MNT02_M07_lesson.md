# MNT02 M07 — 부품 발주량 최종 확정을 위한 정비장교 HITL 승인/조정 워크플로우 설계

## 상황과 목표

가상 부품 데이터 분석 담당자로서 수요·단종 상태·재고 근거를 분석합니다. 예측 기반 발주 정책과 단종 대체품 전환의 효과를 백테스트로 검증하고, 발주량을 정비장교가 최종 확정하는 HITL 승인·조정 워크플로우를 설계한다.

## 원본 수행 범위와 평가

- 원본 필수 미션. 전체 실습에서는 수행합니다.
- 원본·새 Git 편성 3.5시간〔실측값이 아님〕
- 원본 수행: 12개월 재고 백테스트로 현행(최근 평균+고정 여유) 정책, 예측 정책, 예측+단종 대체품 전환을 보관비·발주비·결품손실·충족률·회전율로 비교하고 효과를 분해한다. 서비스 수준과 돌발 수요(1.5배) 민감도를 본다. 다음 달 발주량은 예산 제약 선형계획으로 추천하고, 정비장교가 승인·조정·반려·보류를 사유와 함께 남기며 해시 체인 감사 로그로 변조를 검출한다.
- [필수] 발주 최적화·승인 워크플로우  — 최적화 적용 시 비용 15% 절감 또는 회전율 20% 향상(효과 분해 포함), 자동 확정 0건, 결재 사유 기록률 100%, 감사 로그 변조 검출이 되는가.
- 원본 산출물: src/optimization/mnt02_simulator.py, 결재 감사 로그
