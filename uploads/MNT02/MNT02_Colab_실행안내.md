# MNT02 Colab 실행 안내

1. MNT02_student.ipynb를 열고 준비 셀에서 MNT02_실습프로젝트.zip을 올립니다. 전체제작본 ZIP과 구분합니다. 기존 수정 폴더는 재실행해도 덮어쓰지 않습니다.
2. 필요한 라이브러리만 설치합니다. numpy·pandas·scipy·scikit-learn·matplotlib을 사용합니다. 외부 실제 데이터·API 키·장비 연결이 필요하지 않습니다.
3. 미션 Lesson·forms의 구현 계약을 읽고 본인의 사전 판단·AI에 맡길 일을 정합니다. 실제 AI 요청·답변·첫 초안·근거 대조·보완·최종 선택을 보존합니다.
4. 미션별 전체 def를 implementation 문자열에 작성해 replace_function으로 저장합니다. 이름·인자·기본값은 유지합니다. 기존 코드는 .before로 보존되고 잘못된 문법·서명은 거부됩니다. NotImplementedError 상태에서는 실행이 중단됩니다.
5. 핵심 함수 구현 후 run_mission을 처음 실행해 결과를 보존합니다. 이후 기존 추가 변경 과제로 코드·지표·경계 결과를 비교합니다. 미구현 실패를 성능 기준값으로 쓰지 않습니다. 수정한 미션부터 재실행합니다.
6. outputs/M번호/회차에 stdout·stderr·결과표·그림·run.json이 생성됩니다. 독립 모듈은 가상 자료를 각자 생성하므로 앞 미션의 코드 수정이 자동으로 모든 미션에 적용되지는 않습니다. 공통 변경을 여러 모듈에 적용하면 변경 범위·버전을 기록합니다.
7. M7 직접 입력 셀에서 가상 정비장교 역할로3건 이상 검토합니다. 사유·예산·호환성 근거를 확인하고 LEARNER_INPUT 감사 기록을 보존합니다. 예시 SIMULATED 결재를 직접 판단으로 제출하지 않습니다. 실제 사용자 인증·발주 집행은 없습니다.
8. M8의300%는 평시의3배입니다. 전체 정확도와 경계 제외 정확도를 구분하고 미달은 미달로 기록합니다. 부하 측정은 복제 품목의 계산·집계이며 실제 웹 화면 갱신 측정이 아닙니다.
9. M10의 모델 선택 검증은 독립 최종평가가 아닙니다. 운영 가이드10개 장의 실제 본문·연계 규격·보고서를 작성합니다. 출력되는 목차는 작성 완료가 아닙니다. 문서 구조 검사를 통과해도 내용 적합성은 별도 검토입니다.
10. 기본은10미션 전체 수행입니다. 원본 선택 M4·M6·M8을 제외하면 SELECTED_MISSIONS와 미수행 사유를 기록하고 후속 자료 의존성을 확인합니다. CMS 필수/선택 운영 설정은 별도 확인입니다.
11. 마지막 셀은 핵심 구현·선택된 미션 실행 기록·직접 검토3건·감사로그와 파일 존재를 확인하고 uploads/MNT02.zip을 만듭니다. 이 검사는 실제 AI 대화·보고서 충실도·학습평가 PASS·교관 승인을 인증하지 않습니다. 코드·보고서·AI 원문을 프로젝트 폴더에 보존한 뒤 내려받습니다.

원본·새 Git 편성은 28.5시간입니다. CMS의 소수 시간 저장 여부는 등록 후 확인합니다. 실제 소요시간은 별도 측정합니다. Colab 런타임 초기화 전에 저장하고 실제 Colab 서비스·CMS 화면 검증은 따로 진행합니다.
