# MNT02 M03 — 이동평균 및 지수평활법 기반 1차 부품 소요량 예측 Baseline 알고리즘 구현

## 상황과 목표

가상 부품 데이터 분석 담당자로서 수요·단종 상태·재고 근거를 분석합니다. 이동평균과 지수평활법으로 1차 부품 소요량 예측 Baseline을 만들고 탐색적 분석으로 수요 요인과 핵심 관리 품목을 찾는다.

## 원본 수행 범위와 평가

- 원본 필수 미션. 전체 실습에서는 수행합니다.
- 원본·새 Git 편성 2.5시간〔실측값이 아님〕
- 원본 수행: 3·6개월 이동평균, 단순 지수평활, 작년 같은 달 방식의 MAE·WAPE·MAPE를 평가 구간 6개월에서 비교한다. 운용시간·훈련 월·가동률 등과 수요의 상관계수·p-value를 검정하고 EDA 차트 8종을 만든다. ABC(파레토) 분석으로 상위 20% 품목을 식별하고 그중 단종·단종예고 품목을 표시한다.
- [필수] Baseline·EDA  — EDA 차트 8종 이상, 유의미한 상관 피처 5개 이상(p<0.05), Baseline 방식별 오차 비교와 ABC 상위 품목 중 단종 위험 품목을 제시했는가.
- 원본 산출물: notebooks/mnt02_eda_analysis.ipynb 및 EDA 요약 리포트

## 이번 미션의 핵심 구현

- 파일: `src/analysis/mnt02_eda.py`
- 함수: `ses`
- 계약: 수요 배열 y,alpha → 한달 앞 SES 예측 배열. 초기값은 첫 관측값이고 이후 예측은 이전 시점의 관측만 사용한다. 빈/비유한/음수 수요와 범위 밖 alpha는 거부한다. 초기 구간은 성능평가에서 제외한다.
- 반복 데이터 생성 함수는 제공 코드입니다. M1의 check는 제공하고 validate를 구현합니다.
- 핵심 구현 후 첫 성공 실행을 보존하고 기존 추가 변경 과제를 수행해 전후 비교합니다. 실제 AI 대화·본인 근거 검토·오류 수정 이유를 남깁니다.

### 활동4 — 최종 판단과 산출물

원본 평가 기준·변경 전후·코드·실제 AI 대화·보고서를 제출합니다. 미달·미측정·실제 승인 상태를 구분합니다. MAPE는 실제수요 0을 제외한 분모, WAPE는 실제 합계가 0일 때N/A를 표시합니다. 상관과p-value는 인과가 아닙니다. 가상 생성 구조·반복 품목/월·다중 비교·상관된 피처의 한계를 설명합니다.
