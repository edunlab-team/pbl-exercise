# [QLT04_M10] 전술 장비 가동률 저하 요인 분석 및 극대화 도구 최종 완성 실습 가이드

## 1. 미션 개요 및 배경
단위 모듈(전처리, 룰 엔진, AI 추천, UI, 결재선, 배치)을 단일 파이프라인으로 통합 패키징하고, 5단계 설치 점검 및 4종 시드 E2E 실행을 완료합니다.

## 2. 제공 데이터셋 안내 (`qlt04_m10_dataset.json`)
- `install_check_steps`: 클린 환경 5단계 원클릭 설치 점검표
- `seed_e2e_scenarios`: 4종 가상 시드(42, 101, 777, 999) End-to-End 실행 결과
- `self_check_score`: 시스템 9대 자체 진단 결과 및 매뉴얼(7개 장) 작성률

## 3. 핵심 수행 단계
1. **원클릭 설치 검증**: 의존성, 가상 데이터, 룰 설정, 결재선, UI 시동 등 5단계 자동 설치 스크립트 완주
2. **E2E 4종 시나리오 실행**: 시드별 다양한 작전 환경 시나리오에서 파이프라인 무결 완주 확인
3. **품질 검수 및 브리핑**: 자체 진단 9항목 통과, 7개 장 매뉴얼 100% 검수, 지휘관 보고용 1페이지 브리핑 생성
4. **도전 과제**: 검토 큐 진입 점수(queue_min_score) 변경에 따른 결재 부하 튜닝

## 4. 핵심 판정 지표 (PASS 기준)
- 원클릭 설치 스크립트 완비, 매뉴얼 작성률 100%
- E2E 4종 시나리오 및 자체 진단 9항목 100% 통과
