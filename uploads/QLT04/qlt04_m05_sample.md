# [QLT04_M05] 정비 자원 재배치 가동률 시뮬레이션 산출 엔진 실습 가이드

## 1. 미션 개요 및 배경
부대 간 정비병·부품 재배치 시 전군 가동률 상승폭을 모의하는 시뮬레이션 엔진을 구현하고, 4개 핵심 화면 UI 프로토타입을 구축합니다.

## 2. 제공 데이터셋 안내 (`qlt04_m05_dataset.json`)
- `sample_candidates`: 부대 간 재배치 후보 70건 시나리오 (공출부대, 수혜부대, 인력, 부품, 예상상승폭)
- `simulation_model_r2`: 비선형 상호작용 회귀 모델 검증 지표 (R2 0.646)

## 3. 핵심 수행 단계
1. **시뮬레이션 모델링**: 자원 결핍의 제곱항과 정비 요청 상호작용을 반영한 비선형 회귀 모델 구축
2. **제약조건 필터링**: 누적 이동 한도(max_move=4) 초과 시 자동 반려 판정 (승인대기 2건, 반려 2건)
3. **UI 인터랙션 구현**: 입력-분석-검토-결과 4단계 화면 및 상태 뱃지, 12개 네비게이션 경로 무결성 검증
4. **도전 과제**: 최대 자원 이동 한도 완화(4➔6) 시 전력 불균형 위험 평가

## 4. 핵심 판정 지표 (PASS 기준)
- 핵심 화면 4종 구현 완료 및 네비게이션 12경로 통과
- 제약조건 기반 승인대기/반려 판정 정확도 100%
- 산출물: `src/ui/qlt04_app.py`
