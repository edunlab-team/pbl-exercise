# 📘 [미션 03] 실습 및 검증 가이드
## 물리적 결함 진단 실습 및 MSEL 시나리오 설계

### 1. 실습 개요
물리적 균열, 잠금장치 결함, 환기구 이물질의 3단계 진단 기준을 정립하고, 정상 결함 6건과 비정상 기만 상황 4건(6:4 비율)으로 구성된 10건 이상의 MSEL 시나리오를 설계합니다.

### 2. MSEL 시나리오 작성 양식
```json
{
  "event_id": "INJ-01",
  "time_marker": "T+02",
  "inject_type": "정상 결함",
  "target_facility": "방폭 주출입문",
  "message_text": "점검관이 방폭문 하부 고무 가스켓을 손으로 만졌을 때 5cm 찢어짐을 감지함",
  "expected_action": "기밀 불량 판정 선언, 기록관에게 치수 기록 요청, 임시 기밀 테이핑 지시",
  "evaluation_criteria": "30초 내 위험도 판정 및 구두 복창 완료 여부"
}
```

### 3. 워크스루(Walk-through) 점검 체크리스트
* 주입 메시지 전달 시 점검관의 즉각적인 구두 대응 여부
* 통신 두절 돌발 상황 발생 시 비상 전파망 가동 여부
