# [MNT10_M02] 이동정비반 상태 정보 전처리 모듈 구현 실습 가이드

## 1. 미션 개요
통신 음영이나 수기 입력으로 인해 발생하는 이동정비반 상태 로그의 결측치·이상치를 10대 정제 규칙으로 보정하고 정상 군수 예외를 보존하는 ETL 파이프라인을 구축합니다.

## 2. 주요 데이터셋 안내 (`mnt10_m02_dataset.json`)
- `cleansing_rules`: 중복 제거, 단위 통일, 좌표 보간, KNN 보정 등 10대 정제 규칙 명세
- `cleansing_metrics`: 중복 12건 제거 및 긴급 불출 예외 15건 보존 검증 결과

## 3. 핵심 수행 단계
1. **10대 정제 파이프라인 실행**: 정제 규칙별 처리 건수 및 정합성 검증 10/10 확인
2. **군수 특수 예외 보존**: 긴급 불출(R10) 15건을 일반 이상치와 구분하여 플래그 보존
3. **기술통계 대조**: 정제 전후 인원, 연료, 좌표 기술통계량(평균, 편차) 무결성 비교
4. **도전 과제**: KNNImputer의 n_neighbors(5→2) 변경에 따른 결측 보정 민감도 분석

## 4. 핵심 판정 기준
- 데이터 정제 규칙 10종 적용 및 정합성 검증 통과율 100% 달성
- 긴급 불출 군수 예외 15건 정상 보존
