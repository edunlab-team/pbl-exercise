# [MNT10_M01] 야전 긴급 정비 요청 데이터셋 스키마 정의 실습 가이드

## 1. 미션 개요
야전 긴급 정비 요청(위치, 작전 중요도, 고장 유형)과 이동정비반 상태 데이터를 체계적으로 관리하기 위해 군수 도메인 스키마와 데이터 딕셔너리를 정의하고 무결성을 검증합니다.

## 2. 주요 데이터셋 안내 (`mnt10_m01_dataset.json`)
- `feature_groups`: 요청(13개), 정비반(6개), 결과(5개) 총 24개 핵심 군수 피처 정의
- `injected_errors_sample`: 유효성 검증기 방어력 테스트를 위한 5건의 고의 주입 결함 데이터

## 3. 핵심 수행 단계
1. **데이터 딕셔너리 정립**: 국방 표준 코드(가상 FSC/NIIN)를 모사한 20개 이상 피처 정의
2. **업무 프로세스 맵**: 접수부터 사후 실적 입력까지 전주기 6단계 업무 흐름도 도출
3. **스키마 검증기 구현**: 범위, 형식, 허용값, 누락, 자료형 오류 5건 100% 검출 확인
4. **도전 과제**: `unit_mechanics` 피처 확장 및 경계 초과 검출 단위 테스트

## 4. 핵심 판정 기준
- 피처 20개 이상(목표 24개) 정의 완료
- 스키마 검증기 정상 샘플 오류 0건, 주입 결함 5건 100% 검출
- 산출물: `docs/mnt10_logistics_domain_spec.md` 및 데이터 딕셔너리
