# ISR07 워크북 실행 안내

1. ISR07_workbook.ipynb를 Colab에서 열고 준비 셀에 ISR07_실습프로젝트.zip을 올립니다. 전체제작본 ZIP과 구분합니다. 기존 작성 폴더는 준비 셀을 다시 실행해도 덮어쓰지 않습니다.
2. 워크북의 공통 AI 역할 안내와 각 미션 Lesson을 읽습니다. 별도 AI 창에서 실제 요청·답변을 주고받습니다. API 키는 필요 없습니다. AI에게 교관 해설과 미래 장애 카드를 전달하지 않습니다.
3. RESULT 안의 작성 양식을 채운 뒤 save_result의 주석을 해제해 실행합니다. 외부 편집기로 동일 제출 경로의 파일을 작성해도 됩니다. 두 곳에 중복 작성하지 않습니다.
4. save_ai_dialogue로 실제 요청·답변 원문을 보존합니다. 초안·검토·보완·질문을 구분합니다. 제공 도구는 대화 진위나 판단의 옳고 그름을 인증하지 않습니다.
5. M4 격자·M6 가동 기록은 Lesson 표와 project/data의 CSV·JSON을 대조합니다. 제공 계산 코드는 보조 도구이며 학습자가 코드를 개발하는 과제가 아닙니다. 결측률은 계획시간이 분모이며 판독 불가와 가동 중단을 구분합니다.
6. M7의 HTML 다운로드 셀을 실행하고 내려받은 ISR07_M07_장애카드_실습.html을 자신의 브라우저에서 엽니다. 도구가 공개한 현재 카드만 AI에게 전달합니다. 전체 소스는 모든 카드를 포함하므로 미리 읽지 않습니다. 기록 다운로드 버튼으로 공개 로그를 보존합니다. Colab 셀 안에서 타이머가 실행되는 것은 아닙니다.
7. M7은 실제 25분 진행과 공개 지연·AI 대기·행동을 따로 기록합니다. mark_actual_time은 셀 실행 시각만 기록합니다. 두 평가자의 채점 원문을 먼저 고정하고 일치율을 검산합니다. 개인+AI는 AI 모의 일치율로 표시하며 실제 평가자 2명 수행을 완료했다고 쓰지 않습니다.
8. M9는 B1~B5·A·B의 7건을 같은 자료 시점과 서식 버전으로 비교합니다. 준비시간·일치율의 분모와 실측/회고 재구성을 기록합니다. 임의의 개선율 목표는 추가하지 않습니다. 발표 원고만 A4 1페이지로 확인하고 실제 시계로 3분 이내 발표·질의 3건을 확인합니다. 전체 작성 양식이 1페이지일 필요는 없습니다.
9. 한 사이클에서는 M4·M6·M8도 수행합니다. 미션별 결과·AI 대화·직접 검토·카드 로그·발표 기록을 보존하고 마지막 셀에서 uploads/ISR07.zip을 생성합니다. 미작성 양식과 AI 원문 누락은 차단하지만 내용의 충분성과 실제 교관 승인은 별도입니다.
10. Colab 런타임 초기화 전에 자료를 내려받습니다. 결과·대화·카드 로그 등 추가 증거는 project 폴더 아래 해당 미션 폴더에 저장하면 제출 ZIP에 포함됩니다. 실제 Colab 서비스와 CMS 화면은 별도 확인 사항입니다.
