# ISR07 AI 역할 실습 안내

## 실제로 AI를 사용하는 흐름

사전 판단 → 자료·제약을 담은 요청 → 첫 답변 보존 → 본인의 근거 대조 → 보완 요청 → 재확인 → 최종 선택을 진행합니다. AI에게 완성 파일 10개를 한 번에 만들어 달라고 하는 것이 학습 활동의 전부가 아닙니다.

다음 공통 규칙과 **이번 미션에서 허용한 자료·본인의 기준·버전**만 새 대화에 넣습니다. 교관용 정답과 미래 장애 카드·통제관 메모는 넣지 않습니다.

> ISR07 교육용 가상 문서 실습을 돕는다. 너는 내가 지정한 초안 작성자·기록자·레드팀·모의 평가자·질문자 역할을 맡는다. 자료에서 확인된 사실, 교육용 기준 제안, 추가 확인이 필요한 내용을 구분하고 근거의 사례 번호·표 제목을 표시한다. 센서 이름이 다르다고 독립성을 확정하지 않는다. 없는 수치·시간·서명·승인·실제 성과를 만들지 않는다. 관측 불가를 부재로 바꾸거나 미래 자료를 과거 판단에 넣지 않는다. 최종 판단과 직접 브리핑은 내가 한다. 내가 실제 기록을 주지 않은 실행·발표·평가를 완료했다고 적지 않는다. 실습 중 결론을 대신 결정하지 말고 내 판단을 기다린다.

## 미션별 요청과 본인이 할 행동

| --- | --- | --- |

| M2 | 관찰 가능한 지표·6단계 기준 초안, 고정 기준의 모의 판정 | T1~T5 계산·사전 판정, 블라인드 검토, 불일치 기준 수정 |
| M3 | W1~W4의 단정 지점과 수정 표현 제안 | 당시 알 수 있던 자료와 후속 사실 분리, 8개 공백 요인 검증 |
| M4 | 원본 25칸의 조건별 센서 수 검산, 기준의 반례 지적 | 원본 격자 직접 대조, 가중치·미제공 항목 처리와 점수 재계산 |
| M5 | 본인의 트리로 B1~B5를 추적하고 승인 우회 경로 지적 | 분기·책임·권한을 확정하고 최종 모의 결정과 근거 직접 기록 |
| M6 | 원문 보고에서 사실·추측·조치 분리, 기준의 누락 구간 지적 | 결측률 재계산, 독립성 미확인 표시, 3개 보고의 분류 판단 |
| M7 | 공개된 현재 장애 카드만으로 질문·모의 수신 회신 | 카드마다 직접 판단·한계 보고, 25분 실제 진행과 발표 기록 |
| M8 | 제공 AAR의 원인 가설·레드팀 비판 | 당시 기록과 후속 사실 분리, 비판 5건의 채택·반박·수정 결정 |
| M9 | 고정 기록의 전후 차이 검토, 브리핑 질의 3건 제시 | B1~B5·A·B 재검증, 1페이지 편집, 실제 3분 발표와 답변 |
| M10 | 교리·법무·작전 역할별 모의 문서 심의 | 조항별 근거 확인, 지적 사항 반영, 미해결 검토·개정 책임 기록 |

## 독립 검토를 흉내 낼 때

M2·M7은 기준을 먼저 고정합니다. 새 대화 A와 B에 같은 자료·같은 루브릭만 전달합니다. 서로의 점수·정답·합의 목표를 전달하지 않습니다. 원문을 저장한 뒤 비교합니다. 기준을 고친 재채점은 최초 채점과 다른 회차로 남깁니다. AI 모의 결과를 실제 평가자 두 사람의 결과라고 쓰지 않습니다.

## M7 실행 순서

1. 브리핑 담당은 `ISR07_M07_장애카드_실습.html`을 브라우저에서 열어 시작합니다. 파일은 인터넷 연결 없이 사용할 수 있습니다.
2. 현재 공개된 카드 내용만 AI 대화에 복사합니다. 미래 카드 전체를 AI에게 주지 않습니다. 통제관 메모는 교관 파일에 따로 있습니다.
3. 학습자가 상태·알 수 없는 사항·한계 문장·다음 확인 요청을 직접 입력합니다. AI는 현재 자료를 요약하거나 질문하고 요청한 모의 수신만 회신합니다. 임의로 센서를 복구하거나 승인하지 않습니다.
4. 실제 카드 공개 시각·본인 행동·AI 응답 대기·25분 종료를 기록합니다. 카드가 늦게 공개됐으면 지연을 남깁니다.
5. 공개기록을 다운로드하고 최초 브리핑·최종 브리핑·평가 원문과 함께 제출합니다. HTML 도구의 시간 기록은 카드 공개 로그일 뿐 발표나 모든 행동의 완료 증거는 아닙니다.

직접 발표를 녹음할 필요는 없습니다. 실제 타이머·발표자 메모로 측정할 수 있습니다. 공개 카드의 원문은 수정하지 않습니다. 도구를 재시작하면 새 회차이며 이전 기록은 먼저 다운로드합니다.
