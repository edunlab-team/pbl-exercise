# LOG05 공통 작성 안내

**무인 보급장비 투입 전 상태·책임·중지조건 체크리스트**는 문서·분석형입니다. 가상 제 7수송중대 무인보급반의 제공 기록을 읽고 AI와 체크리스트·근거 분류·모의 역할 대화·보고·지침서를 작성합니다. 실제 장비를 구동하지 않습니다. 부대·장비·구간·수치·직책은 원본의 교육용 가상 설정입니다.

## 진행 순서

1. 각 lesson의 자료를 읽고 forms 복사본에 확인한 사실, 모르는 사항, AI에게 맡길 일을 먼저 적습니다. 답변을 먼저 봤으면 ‘답변 열람 후 작성’을 표시합니다.
2. 해당 미션 자료·이전 기준 버전·원하는 결과·추정 금지를 AI에 전달하고 실제 요청·첫 답변을 보존합니다.
3. AI의 주장 3건 이상을 원자료·본인 계산·실습 기록과 대조합니다. 맞는 내용도 유지 이유를 적고 필요한 수정을 직접 요청합니다.
4. 보완 답변을 다시 확인하고 본인이 채택·수정·보류를 결정합니다. 최종 파일과 반영 위치를 남깁니다.
5. 이전 미션의 결과·기준·미확인을 다음 미션에 전달합니다. M10에는 원본의 8개 장과 부록을 통합합니다. 원본 선택 M4·M6·M8도 전체 사이클에서는 수행합니다.

Why〔본인 계획·AI 위임 이유〕, How〔실제 대화·근거 대조·보완·직접 실습〕, What〔최종 결과·본인 판단·반영 위치〕를 평가합니다. AI가 만든 완성 보고만 제출하면 과정 완료가 아닙니다.

## 기록과 판단의 구분

- 신뢰도는 G1이 가장 강하고 G6이 가장 약합니다. LOG05의 단계 이름은 다른 프로젝트와 다르므로 이 원본의 이름을 사용합니다. ‘G3 이상’은 G1·G2·G3, ‘G4 이하’는 G4·G5·G6으로 명시합니다.
- 높은 근거 신뢰도와 점검 합격은 다릅니다. R1의 잔량 82% 는 G1 근거여도 원본 예시의 출발 잔량 90% 기준을 충족하지 못합니다. 실제 장비 기준이 아닌 이 실습의 가상 예시입니다.
- 점검표 예시의 ‘예비 전력 포함 왕복 가능’은 잔량만으로 확인되지 않습니다. 소요 전력 자료가 없으면 추가 확인 사항입니다. 계측값·시각·조건·다른 확인자의 근거를 구분합니다.
- 투입 주판정은 승인·보류 유지·추가 확인 요청 중 하나입니다. 주판정과 병행 자료 요청은 별도로 남깁니다. 점수·등급·AI 답변은 사람의 승인을 대신하지 않습니다.
- 임무 중 처리 이름은 원본의 계속, 감속·경로 유지, 제자리 안전 정지, 복귀, 원격 회수 요청, 임무 취소를 유지합니다. ‘중지’는 모든 처리의 구체적 뜻을 대신하는 단어가 아닙니다. 검증된 가상 조건과 사람 역할의 결정을 연결합니다.
- 서명·복창·명령 전달·수신·이행 완료는 서로 다릅니다. 복창이 있다고 실제 장비가 정지한 것으로 쓰지 않습니다. 링크가 끊긴 상태에서는 명령 수신을 임의로 완료 표시하지 않습니다.
- 장비 파괴·무력화 조치와 통신 방해 기법은 설계하지 않습니다. 해당 쟁점은 원본대로 지휘관·기술·법무 검토에 연결합니다. 실제 교전 판단은 교전수칙·지휘계통에 따릅니다.

## 조별과 개인+AI

원본은 4~6명 조별 실습과 실제 평가자 2명을 전제로 합니다. 개인은 학습자가 분석 책임·최종 판단을 하고 AI가 검토자·레드팀·모의 역할을 맡습니다. AI 모의 일치율을 실제 조원·평가자 일치로 쓰지 않습니다. 실제 사람이 없는 항목은 미실시와 모의 결과를 함께 기록하며 대체 인정은 의뢰처 검토 사항입니다.

원본·새 Git 편성은 27시간입니다. M7은 카드별 판단 2분 이내, M9는 문서 점검 20분·A4 1페이지·3분 발표를 직접 확인합니다. 문서 판독 시간은 실제 장비 점검 시간과 다릅니다. 원본 실습가이드의 개별 활동 시간 합과 미션 예상시간이 일부 다르므로 계획치이며 실제 측정 결과로 쓰지 않습니다.

## 원본 보완 사항

M5는 트리 5단계와 책임표 4칸을 5개 매핑으로 맞췄습니다. M7에는 서로 다른 장비가 등장하므로 카드의 장비별 상태를 분리하고, 식별자가 없는 카드는 추가 확인합니다. 해당 카드에는 잔량 값·복귀 소요 자료가 없어 복귀 가능 여부를 확정할 수 없습니다. 해당 카드의 정식 위임자는 원본에 없어 제안과 실제 확인을 구분합니다. M8은 20회 원시 기록이 아니라 3개 안의 집계표만 제공되므로 새 임계값의 결과를 생성하지 않습니다.
