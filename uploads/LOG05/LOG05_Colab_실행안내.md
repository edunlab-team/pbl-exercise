# LOG05 워크북 실행 안내

1. LOG05_workbook.ipynb를 Colab에서 열고 준비 셀에 LOG05_실습프로젝트.zip을 올립니다. 전체제작본 ZIP과 구분합니다. 준비 셀 재실행은 기존 작성 폴더를 덮어쓰지 않습니다.
2. 공통 AI 역할 안내와 Lesson을 읽고 본인 사전 판단·의문·AI에 맡길 일을 먼저 적습니다. 별도 AI 창에서 실제 요청·답변을 주고받습니다. API 키는 필요 없습니다. 교관 답·미래 카드·실제 장비나 부대 정보는 AI에 입력하지 않습니다.
3. RESULT 문자열의 양식을 채우고 save_result의 주석을 해제해 실행합니다. 외부 편집기로 동일 제출 경로의 문서를 작성해도 됩니다. 한 곳에서 작성하고 실제 근거·미확인·본인 최종 선택을 남깁니다.
4. save_ai_dialogue로 실제 요청·답변 원문을 각각 보존합니다. 초안·보완·모의 회신·질문을 구분합니다. Why/How/What의 계획·검토·결과는 forms에 작성합니다. 도구는 대화 진위와 판단의 옳고 그름을 인증하지 않습니다.
5. 원본 예시의 기준과 근거 품질은 별개입니다. R1은 G1 근거여도 잔량82%가 예시90% 기준을 충족하지 않습니다. 높은 등급·점수·AI 회신을 사람의 최종 승인으로 쓰지 않습니다. 소요 자료가 없으면 왕복 가능이나 중지 완료를 확정하지 않습니다.
6. M7 다운로드 셀로 LOG05_M07_순서형카드_실습.html을 내려받아 자신의 브라우저에서 엽니다. 현재 카드만 AI에게 전달합니다. 카드 공개부터2분 이내 본인의 첫 판단·기준·근거를 입력해 ‘첫 판단 저장’을 누릅니다. 이후 별도 AI 대화에서 모의 명령·회신을 받아 두 칸을 작성하고 다음 카드를 공개합니다.
7. M7 첫 판단은 저장 후 덮어쓰지 않으며 보완은 후속 기록에 남깁니다.2분 초과는 이유가 있어도 원본 시간 기준을 충족한 것으로 표시하지 않습니다. 두 장비 UD-1·UV-2의 상태를 분리하고 대상·잔량·위임 미확인은 그대로 둡니다. 모의 복창을 실제 장비의 수신·정지로 기록하지 않습니다. 카드 소스에는 미래 카드가 있어 미리 읽지 않으며 시험 보안 도구로 사용하지 않습니다.
8. 마지막 카드 후 HTML의 로그 다운로드 버튼을 사용합니다. 내려받은 로그를 project의 해당 미션 증거 폴더에 저장하면 최종 제출에 포함됩니다. mark_actual_time은 셀 실행 시각만 기록하므로2분 판단 검증은 HTML 로그/실제 타이머와 본인 행동 기록을 사용합니다.
9. M8의20회 집계표에서 불필요 중지와 지연 손실 비율을 각각 검산합니다. 원시20행·사건 중복 여부·새 임계값의 시험 결과는 미제공이며 도구가 생성하지 않습니다. M7의5영역 채점은 원문을 먼저 고정하고 일치율을 확인합니다. AI 모의와 실제 평가자2명을 구분합니다.
10. M9는 V1~V7의 원본 이전판정과 본인 재검증·실측을 구분합니다. 문서 점검20분·실제 발표3분·질의3건을 확인합니다. 발표 원고만 A4 1페이지로 편집하며 전체 작성 양식은1페이지일 필요가 없습니다. 문서 점검을 실제 장비 점검으로 표현하지 않습니다.
11. 한 사이클은 선택 M4·M6·M8을 포함해10개 모두 수행합니다. 작성본·AI 원문·직접 검토·카드 로그·발표 기록을 보존하고 마지막 셀에서 uploads/LOG05.zip을 생성합니다. 초기 빈 양식과 AI 원문 누락은 차단하지만 내용 충실도·원본 평가 충족·교관 승인은 별도입니다. 런타임 초기화 전에 내려받습니다.
