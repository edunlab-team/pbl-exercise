# [AMM02_M01] 작전 단계별 탄약 및 유류 기준 소모율(CSR) 데이터 정의 실습 가이드

## 1. 미션 개요 및 핵심 목표
* **미션 식별자:** `AMM02_M01`
* **필수 산출물:** `docs/amm02_logistics_domain_spec.md` (프로세스 맵 및 데이터 딕셔너리)
* **핵심 달성 목표:** 5단계 업무 프로세스 맵 정의, 7개 그룹 23개 필드 스키마 구축, 6대 결함 주입 100% 탐지

## 2. 세부 실습 절차
1. 5단계 군수 보급 프로세스(보고수집 -> 소모량산출 -> DOS계산 -> 재보급결재 -> 저장배치) 맵 작성
2. 7개 그룹 23개 필드 Pydantic 데이터 모델 작성 및 국방 표준 코드 정규표현식 검증 로직 구현
3. 정상 데이터 30건 무오류 통과 및 인위 주입 결함 6건(자료형, 범위, 누락 등) 전원 탐지 검증
4. 저장칸 온도 상태(`temp_state`) 필드 확장 및 비정상 입력 차단 시험

## 3. PASS/FAIL 판정 체크포인트
- [ ] **[필수]** 정의된 필드 수가 20개 이상(목표 23개) 완비되었는가?
- [ ] **[필수]** 정상 30건에 대한 오탐 0건, 오류 6건에 대한 탐지율 100%를 달성하였는가?
- [ ] **[필수]** 군수 프로세스 5단계가 상태 머신 관점에서 논리적으로 명세되었는가?
