# 📘 [미션 05] 실습 및 검증 가이드
## 모의 침투 시뮬레이션 기반 차폐 밀폐성 교차검증

### 1. 실습 개요
실제 결함 카드와 허위·오류 카드 12건(E1~E12)을 대상으로 4대 다중 교차 확인 규칙을 적용하여 허위 경보를 필터링하고 식별 성공률(85% 이상)을 입증합니다.

### 2. 혼동 행렬(Confusion Matrix) 평가 지표
| 구분 | 실제 결함 (Positive) | 정상/기만 (Negative) |
| :--- | :--- | :--- |
| **판정 결함** | 정탐 (True Positive) | 오경보 (False Positive) |
| **판정 정상** | 미탐 (False Negative) | 정판정 (True Negative) |

### 3. 판정 불일치 시 Fail-safe 에스컬레이션 경로
1. 1차 점검관과 2차 점검관의 판정 대조
2. 불일치 발생 시 즉시 점검반장에게 '판정 보류' 구두 보고
