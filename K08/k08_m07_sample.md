# [K08_M07] 근거 조항을 붙여 답하기 실습 가이드 및 작성 서식

## 1. 실습 개요 및 목표
- **과제명**: K08 군 규정 검색 AI - 근거 조항을 붙여 답하기
- **핵심 목표**: 검색된 조항의 원문과 장·조 번호를 인용하는 신뢰 답변 서식을 렌더링하고, 유사도 기준 미달 시 안내를 안전 거절하는 Fallback을 구축합니다.

## 2. 근거 인용 답변 생성 결과 점검표
- 15개 질문 대상 근거 조항 정답률: (   )/15 (기준: 14/15, 93.3%)
- 필수 서식 항목 준수 여부:
  - 1) 장·조 번호 표기: [ PASS / FAIL ]
  - 2) 조 제목 명기: [ PASS / FAIL ]
  - 3) 본문 원문 발췌 인용: [ PASS / FAIL ]
  - 4) 인간 최종 확인 안내문: [ PASS / FAIL ]
