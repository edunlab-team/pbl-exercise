# [K07_M10] 공지 자동 요약 도우미 완성하기 실습 가이드 및 작성 서식

## 1. 실습 목적 및 개요
- **과제명**: K07 군 공지 자동 요약 - 공지 자동 요약 도우미 완성하기
- **핵심 가이드**: 엔드투엔드(End-to-End) 소프트웨어 클래스 통합 및 생성형 AI 연계 검토 프롬프트 체계화
- **보안 주의사항**: 반드시 제공된 교육용 가상 데이터셋만 활용하며 실제 군사 비밀 및 개인정보는 절대 입력하지 않습니다.

## 1. NoticeAssistant 통합 클래스 실행 결과 카드
- 전체 12건 일괄 처리 공지 카드 출력본

## 2. 자체 점검 체크리스트 (6대 항목 평가표)
| 번호 | 점검 항목 | 기준 | 실행 결과 | 판정 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 형식 검사 오류 차단 | 3건 차단 | 3건 차단 | PASS |
| 2 | 문장 분리 예외 처리 | 2.5점 보존 | 정상 보존 | PASS |
| 3 | 기한/연락처 추출 | 정확도 >= 80% | 83% 달성 | PASS |
| 4 | 하이브리드 요약 | 보존율 >= 90% | 92% 달성 | PASS |
| 5 | 공지 분류 및 우선순위 | 12건 매핑 | 완료 | PASS |
| 6 | 변경 공지 최신 갱신 | 2건 연결 | 2건 완료 | PASS |
- 최종 결과: [ 6 / 6 ] 항목 통과 (ALL PASS)
