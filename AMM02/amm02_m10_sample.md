# [AMM02_M10] 탄약/유류 시뮬레이터 E2E 통합 완성 및 운영 패키징 실습 가이드

## 1. 미션 개요 및 핵심 목표
* **미션 식별자:** `AMM02_M10`
* **필수 산출물:** `pipeline/amm02_retrain.py`, `docs/amm02_operations_guide.md`
* **핵심 달성 목표:** 7단계 E2E 파이프라인 무오류 완주, Champion/Challenger 자동 롤오버, 자체점검표 All-PASS

## 2. 세부 실습 절차
1. 데이터 수집 -> 정제 -> 피처추출 -> 소모예측 -> DOS산출 -> 저장최적화 -> HITL결재 7단계 일원화 스크립트 실행
2. 신규 훈련 데이터 기반 챌린저(v2)와 기존 챔피언(v1)의 MAPE 비교(15.5% 개선) 및 자동 롤오버 파이프라인 구현
3. 데이터 무결성, 모델 성능, 최적화 효과 등 8대 체크리스트 전수 점검 및 All-PASS 달성
4. 지휘관 보고용 4줄 핵심 브리핑 요약문 자동 생성 및 국방 군수 정보체계(DELIIS 등) 연계 API 규격 명세

## 3. PASS/FAIL 판정 체크포인트
- [ ] **[필수]** 7단계 파이프라인이 단일 스크립트로 중단 없이 정상 완주(Return Code 0)되는가?
- [ ] **[필수]** 챔피언/챌린저 모델 성능 검증 기반의 안전한 자동 교체(롤오버)가 동작하는가?
- [ ] **[필수]** 10개 장 실무 운영 가이드와 4줄 지휘관 브리핑 수치 정합성이 100% 일치하는가?
