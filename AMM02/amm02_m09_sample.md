# [AMM02_M09] AAR 기반 소모 계수 재보정 및 정량적 ROI 분석 실습 가이드

## 1. 미션 개요 및 핵심 목표
* **미션 식별자:** `AMM02_M09`
* **필수 산출물:** `reports/amm02_roi_analysis.md`
* **핵심 달성 목표:** AAR 편차 분석, 축소 추정 CSR 재보정, 3대 효과(비용/시간/긴급보급) ROI 도출

## 2. 세부 실습 절차
1. 사후검토(AAR) 실사격 데이터 기반 작전단계·품목·교전강도별 실소모/계획 비율 2차원 피벗 테이블 분석
2. 표본 크기를 고려한 경험적 베이즈 축소 추정(Empirical Bayes Shrinkage) 기반 CSR 재보정 계수 산출
3. 동일 보급 충족률(95%) 하에서 3대 효과(비용 지수 14.8% 절감, 반출시간 31.5% 단축, 긴급보급 8회 감소) 계량화
4. 단기(시범부대), 중기(군단확산), 장기(전군체계화) 국방 군수 AI 전환 로드맵 수립

## 3. PASS/FAIL 판정 체크포인트
- [ ] **[필수]** 실소모 편차 분석에서 통계적 왜곡을 방지한 축소 추정 재보정 계수가 도출되었는가?
- [ ] **[필수]** 3대 효과 지표가 군 재정 부서를 설득할 수 있는 객관적 가중 지수로 산출되었는가?
- [ ] **[필수]** 단·중·장기 추진 로드맵이 마크다운 보고서로 완성되었는가?
