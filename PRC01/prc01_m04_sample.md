# [PRC01_M04] LLM/자연어처리 기반 독소 조항, 납기 지체 위험 문구 자동 식별 모델 고도화 실습 및 검증 가이드

## 1. 미션 개요 및 핵심 목표
* **미션 식별자:** `PRC01_M04`
* **필수 산출물:** `src/ai/prc01_intelligence_module.py`
* **핵심 달성 목표:** NLP 조항 분류 전체 정확도 98.4%(시험 B 95.3%), 표준 문안 Top-3 추천 정확도 97.8% 달성

---

## 2. 세부 실습 수행 절차 (GuideSteps 연계)
* 1. 문자 n-gram TF-IDF 및 로지스틱 회귀 기반 경량 폐쇄망 문맥 분류기 학습
* 2. 시험 A(학습 문장 틀) 및 시험 B(미학습 신규 표현) 대상 일반화 정확도 검증
* 3. 키워드 기준선(64.4%) 대비 머신러닝 모델의 우수성 정량 비교 및 기여 단어 추출
* 4. 방사청 표준 계약 문안 라이브러리 코사인 유사도 기반 안전한 대체 문안 Top-3 추천

## 3. 평가 및 PASS/FAIL 판정 기준 (Checkpoints)
- [ ] **[필수]** 외부 LLM API 호출 없이 온프레미스 경량 라이브러리로 구동되는가?
- [ ] **[필수]** 신규 표현(시험 B)에 대한 분류 정확도가 85% 이상인가?
- [ ] **[필수]** 분류 결과에 크게 기여한 위험 키워드가 설명가능하게 제시되는가?
- [ ] **[필수]** 추천된 대체 문안이 원본 조항의 목적을 훼손하지 않는가?
