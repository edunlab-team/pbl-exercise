# [QLT04_M07] 군수참모처 HITL 정책 결정 모듈 실습 가이드

## 1. 미션 개요 및 배경
AI 추천 기반 정비 우선순위에 대해 4단계 결재선(정비담당-정비관-품질검사관-군수참모) 상태 머신을 구축하고, SHA-256 해시체인 감사 로그를 구현합니다.

## 2. 제공 데이터셋 안내 (`qlt04_m07_dataset.json`)
- `sample_proposals`: 자원 투입 추천 안건 12건의 결재선 이력 데이터
- `rbac_bypass_tests`: 직권 승인, 절차 건너뛰기 등 13종 권한 우회 테스트 케이스
- `hash_chain_sample`: 블록체인형 SHA-256 감사 로그 체인 데이터

## 3. 핵심 수행 단계
1. **결재 워크플로우 구현**: 상신-1차검토-기술심사-최종승인의 4단계 상태 전이 및 반려 사유 의무 기재
2. **RBAC 보안 검증**: 권한 없는 직책의 대리 승인 및 절차 우회 시도 13종 전수 차단(100%)
3. **해시체인 무결성 검증**: 과거 10번째 결재 기록 임의 수정 시 체인 불일치 및 위·변조 실시간 탐지 입증
4. **도전 과제**: 참모 결재 큐 자동 상신 점수 임계값 튜닝

## 4. 핵심 판정 지표 (PASS 기준)
- 이력 기록 무결성 100%, 승인 권한 우회 시도 차단율 100%
- 결재선 승인/반려 시뮬레이션 및 감사 로그 정상 생성
- 산출물: `src/workflow/qlt04_approval_system.py`
