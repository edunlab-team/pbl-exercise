# [QLT04_M08] 전군 일괄 분석 스트레스 테스트 및 성능 검증 실습 가이드

## 1. 미션 개요 및 배경
12개월치 전군 장비 가동률 빅데이터를 4단계(적재-검증-분석-보고)로 처리하는 월간 배치 파이프라인을 구축하고, 500% 과부하 및 오류 주입 환경에서 안정성을 검증합니다.

## 2. 제공 데이터셋 안내 (`qlt04_m08_dataset.json`)
- `execution_benchmarks`: 100% / 200% / 500% 부하별 처리 시간 및 유실률
- `chaos_test_scenario`: 6월 데이터 지속 장애 주입 시 결함 격리(Skip & Isolate) 시나리오
- `roi_analysis`: 수작업 대비 연간 공수 절감(84% 절감) 분석표

## 3. 핵심 수행 단계
1. **배치 파이프라인 구축**: 12개월 x 4단계 = 48단계 파이프라인 자동 실행 및 진행률(Progress) 표시
2. **장애 격리 테스트**: 6월 지속 장애 발생 시 해당 월만 건너뛰고 7~12월 무중단 완주(47/48 성공) 확인
3. **과부하 스트레스 검증**: 500% 대용량 부하 환경에서 데이터 유실 0건 및 5분 이내 완주 확인
4. **도전 과제**: 건당 수작업 확인 시간 기준(6분➔12분) 변경에 따른 ROI 재산출

## 4. 핵심 판정 지표 (PASS 기준)
- 전체 배치 파이프라인 실행 시간 5분 이내, 자동화 성공률 99% 이상
- 수작업 대비 업무 소요 시간 80% 이상 절감
- 산출물: `src/pipeline/qlt04_batch_runner.py`
