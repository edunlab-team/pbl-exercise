# [MOV01_M05] 우회 소요·유류 산출 엔진 및 앙상블 모델 실습 가이드

## 1. 미션 개요 및 배경
증분 배정(Incremental Assignment)으로 우회 기동 시 대당 추가 시간과 유류 소모량을 물리적으로 산출하고, GBR/RF 앙상블 회귀 모델로 예측 오차를 극소화합니다.

## 2. 제공 데이터셋 안내 (`mov01_m05_dataset.json`)
- `a2_closure_metrics`: A2 교량 폐쇄 시 대당 추가 시간(+3.96분) 및 유류 소모(+0.81L)
- `fuel_coefficients`: 5톤 차량 주행 연비(3.2km/L) 및 정체 공회전 계수(0.08L/분)
- `target_metrics`: 앙상블 Hold-out 30일 목표 (MAE 0.475분, R2 0.983, 개선율 73%)

## 3. 핵심 수행 단계
1. **우회 유류 산출**: 추가 거리와 정체 공회전 시간을 결합한 일일 유류 소비량(485.7L) 계산
2. **앙상블 모델 학습**: GBR과 Random Forest 가중 평균 모델 구축 및 하이퍼파라미터 튜닝
3. **조건별 오차 분석**: 정비일, 긴급 불출일 등 비정형 수요에서의 오차 개선율 입증
4. **도전 과제**: L_IDLE=0.16 튜닝 시 정체 가중치 변화 민감도 분석

## 4. 핵심 판정 지표 (PASS 기준)
- 우회 수송 시 대당/일일 추가 시간·유류 소모량 물리 모델링 완성
- 기준 모델 대비 MAE/RMSE 20% 이상 개선 (실측 73% 개선)
- Hold-out 테스트셋 R2 Score 0.85 이상 달성 (실측 0.983)
