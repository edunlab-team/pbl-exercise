# [MOV01_M06] 혼잡도 관제 대시보드 및 XAI 설명기 구현 실습 가이드

## 1. 미션 개요 및 배경
실시간 보급로 상태를 조망하는 2x2 C4I 관제 대시보드를 구축하고, SHAP/특성 기여도 분해를 통해 지체 유발 상위 3대 원인을 지휘관용 자연어로 자동 해설합니다.

## 2. 제공 데이터셋 안내 (`mov01_m06_dataset.json`)
- `xai_target`: 300건 테스트 케이스에 대한 상위 3대 인자 100% 자동 산출 명세
- `dashboard_layout`: 4분할 화면(히트맵, 경보 상태판, 배정 비교, XAI 워터폴)
- `bypass_effectiveness`: 고정 배분(91.4분) 대비 우회 배정(44.9분)의 51% 단축 실증

## 3. 핵심 수행 단계
1. **XAI 파이프라인**: 건별 상위 3개 요인(계획량, 정비, 우천 등) 자동 산출 (300/300 달성)
2. **자연어 브리핑 생성**: 지체 상위 4건에 대해 군수 실무자가 납득 가능한 요약문 생성
3. **2x2 대시보드 렌더링**: 히트맵, 경보 상태판, 51% 단축 우회 배정 비교 시각화
4. **도전 과제**: 경보 기준 5분에서 3분 강화 시 상태판 경보 반응 분석

## 4. 핵심 판정 지표 (PASS 기준)
- 주요 예측 건당 기여도 상위 3개 인자 자동 산출률 100%
- 군수 실무 맞춤형 자연어 설명 생성 및 XAI 리포트 완성
- 고정 배분 대비 51% 지체 단축 비교 시각화 완비
