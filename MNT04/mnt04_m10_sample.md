# [MNT04_M10] 예지정비 시스템 E2E 통합 완성 실습 가이드

## 1. 미션 개요
센서 정제부터 XAI, HITL 승인, PBL 부품 소요 예고, 챔피언-도전자 재학습까지 전 과정을 단일 아키텍처로 통합하고 지휘관 브리핑을 완성합니다.

## 2. 주요 데이터셋 안내 (`mnt04_m10_dataset.json`)
- `champion_challenger_metrics`: 신규 데이터 재학습 도전자 모델 F1 개선 지표
- `health_checks`: 8대 서브시스템 통합 자체 점검 체크리스트

## 3. 핵심 수행 단계
1. **챔피언-도전자 재학습**: 도전자 F1 성능 검증 후 무중단 모델 교체 배포
2. **시스템 헬스체크**: 8대 점검 100% 통과 및 장애 시 룰 기반 Fallback 가동
3. **지휘관 브리핑**: 5분 보고용 Executive Summary 1장 요약문 작성
4. **심화 튜닝**: 교체 허용오차(retrain_tolerance) 튜닝

## 4. 핵심 판정 기준
- 도전자 모델 F1 기준치(0.88 이상) 충족 시 자동 교체
- 시스템 헬스체크 8/8 통과 및 7개 장 운영 가이드 완비
- 산출물: `docs/mnt04_operations_guide.md` 및 `pipeline/mnt04_retrain.py`
