# WEL03_M01 실습 및 검증 가이드
## 야전 급수원 가상 수질검사 항목 데이터셋 정의

### 1. 미션 목표
- 야전 급수원 8개소의 15개 핵심 필드(급수원 식별, 수질 5개 항목, 센서 상태, 전술 파라미터) JSON Schema를 정의합니다.
- Draft-07 표준 검증기를 구현하여 20건 정상 샘플의 파싱 성공과 5종 오류 주입 검출을 입증합니다.
- 데이터 명세 요약서(`docs/wel03_data_spec.md`)를 작성합니다.

### 2. 가상 데이터셋 안내
- 파일명: `wel03_m01_dataset.json`
- `sources`: 급수차(W01, W02), 정수시설(W03, W04), 우물(W05, W06), 하천(W07, W08) 제원
- `normal_samples_20`: 정상 범위 내 20건 가상 센서 레코드
- `fault_injection_tests_5`: 5종 입력 결함(범위 이탈, 형식 오류, 누락 등) 테스트 데이터

### 3. 세부 단계별 수행 가이드
1. **스키마 정의**: `data/schema/wel03_input_schema.json`에 15개 필드의 타입, 단위, 제약조건을 기술합니다.
2. **무결성 검증**: 정상 샘플 20건 검증 오류 0건 및 주입 결함 5종 100% 검출을 확인합니다.
3. **명세서 작성**: 수질 지표별 군 작전 기준치와 센서 오차율을 요약 정리합니다.
4. **심화 튜닝**: 수온(temp_c, 0~60℃) 필드 추가 후 스키마 확장성을 검증합니다.

### 4. 핵심 검증 지표 (PASS 기준)
- 스키마 필드 정의 완성도 15/15(100%)
- 정상 샘플 20건 오류 0건
- 결함 주입 5종 모두 정확한 ValidationError로 포착
