# WEL03_M10 실습 및 검증 가이드
## 가상 수질검사 데이터 위험 신호 대시보드 시스템 통합 패키지 완성

### 1. 미션 목표
- 가상 수질검사 데이터 위험 신호 대시보드 시스템 통합 패키지 완성 과업을 완수하여 군사적 신뢰도와 시스템 안전성을 검증합니다.
- 주피터 노트북(`WEL03_student.ipynb`)을 활용하여 단계별 기능을 구현하고 테스트합니다.
- 요구된 핵심 산출물 및 지표를 산출하여 PASS 판정을 획득합니다.

### 2. 가상 데이터셋 안내
- 데이터 파일: `wel03_m10_dataset.json`
- 주요 수질 파라미터: pH, 탁도(NTU), 잔류염소(ppm), 중금속(ppm), 대장균(CFU)
- 환경 및 벤치마크 케이스: 5종 핵심 테스트 케이스 및 전술 상황 변수 수록

### 3. 세부 단계별 수행 가이드
1. **데이터셋 로드 및 요건 분석**: 가상 데이터셋을 호출하고 입력 변수의 정합성을 점검합니다.
2. **AI 코파일럿 협업 및 코드 작성**: 제안된 프롬프트 질의 예시를 활용해 모듈을 구현합니다.
3. **지표 검증 및 단위 테스트**: 정량 기준과 군 실무 타당성 기준을 충족하는지 대조 확인합니다.
4. **파라미터 튜닝 및 최적화**: 도전과제를 수행하고 조건 변경에 따른 성능 변화를 분석합니다.

### 4. 핵심 검증 지표 (PASS 기준)
- 정량 성능 지표 100% 충족
- 단위 테스트 및 회귀 테스트 무결성 확인
- 필수 산출물 파일 작성 완료
