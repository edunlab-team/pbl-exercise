# MOV02_M05 실습 및 검증 가이드
## 수송선단 생존 확률 및 정시 도착 신뢰도 점수 산출 엔진 개발

### 1. 미션 목표
- 후보 경로별 위협 노출도 기반 생존확률과 도로 변수 반영 몬테카를로 시뮬레이션으로 정시 도착 확률 및 0~100점 신뢰도 점수를 산출합니다.
- 콘솔 UI에서 입력-분석-검토-결과 4단계 화면 흐름과 상태별 뱃지(승인대기, 반려, 완료) 필터링을 구축합니다.
- 가상 운행 60건 기반 정시 도착 예측의 Brier 점수를 측정하여 0.1 이하(달성치 0.086)로 예측 신뢰도를 입증합니다.

### 2. 가상 데이터셋 안내
- 파일명: `mov02_m05_dataset.json`
- `candidate_routes_eval`: 후보 경로 4개(R1, R2, R3, R4)의 소요시간, 생존확률, 정시도착률, 종합 신뢰도 점수
- `operations_60_records`: 실제 운행 60건의 예측 정시확률과 실제 정시 도착 결과 (Brier Score 검증용)
- `ui_steps_definition`: 4단계 관제 콘솔 화면 명세(화면 1: 요청 접수, 화면 2: 경로 분석, 화면 3: 검토 및 승인, 화면 4: 종합 결과)
- `deadline_sensitivity_samples`: 기한 조건 변동(70분 vs 100분)에 따른 신뢰도 점수 및 등급 전이 데이터

### 3. 검증 지표
- 추천 R2 경로 95.1점(신뢰 등급) 산출
- 4단계 화면 콘솔 UI 네비게이션 및 상태별 필터링 기능 검증
- 60건 운행 예측 Brier 점수 0.086 달성 (목표 0.10 이하, 무정보 0.25 대비 우수)
