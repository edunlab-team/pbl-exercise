# DAT06_M06 실습 및 검증 가이드
## 군수 결산 보고서 생성 및 승인/반려 관리 대화형 웹 대시보드

### 1. 미션 목표
- 보고서 상태 전이(DRAFT -> SUBMITTED -> APPROVED / REJECTED) 현황판과 차트를 구현합니다.
- 10종의 극단 예외 상황을 주입했을 때 크래시 0건 및 에러 로그 기록률 100%를 달성합니다.
- 사용자 조치 안내 메시지와 상태별 뱃지 필터링 기능을 검증합니다.

### 2. 가상 데이터셋 안내
- 파일명: `dat06_m06_dataset.json`
- `reports_12`: 12개 부대 보고서 상태 레코드 (승인 8, 반려 2, 제출 2)
- `exceptions_10`: 방어적 검증기 테스트를 위한 10종 예외 케이스

### 3. 검증 지표
- 보고서 12건 상태 전이 정상 처리
- 예외 10종 주입 테스트 크래시 0건
- 에러 로그 기록률 100%
